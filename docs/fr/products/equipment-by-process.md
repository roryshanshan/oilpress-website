# Équipements d'huilerie par étape

Une ligne d'huile compte six étapes : préparer la graine, la presser, clarifier l'huile, la raffiner si votre marché l'exige, la mettre en bouteille et déplacer la matière entre les machines. Chaque étape liste les machines que nous fournissons. Pour une ligne complète, utilisez le [configurateur de ligne](/fr/products/line-builder).
