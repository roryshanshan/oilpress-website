GFP-30H publishes 30 filling heads, a 7,000 bottles/hour reference, 2.5 kW total power and 2100 x 2170 x 2200 mm dimensions. Its head count should not be converted directly into a guaranteed line output. Low-vacuum constant-level filling meters to a visible level rather than to mass. The published 7,000 bottles/hour figure is a reference condition, not a guaranteed complete-line result.

## Product and package screening for 30H

Treat GFP-30H as a low-vacuum level-filler candidate only when the package is rigid and the beverage or condiment is non-carbonated. Valve sealing, bottle-mouth quality and the relation between neck geometry and target level have to be proven. Foaming liquids can be investigated, but viscosity, fill temperature and surfactants must be represented in the sample.

Gas-bearing products need an appropriate pressure process. Suspended material, pulp and crystals call for a passage designed for solids; high viscosity may favor pump or piston dosing; and mass-controlled sales need a weighing approach. Do not force those applications into the GFP selection.

## Model-specific purchasing checks

- Use the 7,000 bottles/hour figure only as a reference point and request a sustained-rate calculation for each approved bottle and liquid.
- List labeler and packer constraints early; an unstable wet bottle or insufficient drying section can become the practical limit after filling.
- Price future formats now if they are known, including guides, lifting parts, filling-height range and the storage method for change parts.

Thirty heads must not be translated into a linear capacity formula. Use the supplier's test data for each format and count only bottles meeting the acceptance rule.

## Line interfaces and changeover plan

The control narrative should explain how GFP-30H slows, stops and restarts when the labeler or closing machine is unavailable. Define buffer length and reject handling rather than relying on head count to absorb line interruptions.

For GFP-30H, document how a labeler or bottle dryer recovers after the filler changes speed. The line description should state accumulation zones, discharge spacing, reject route, coder trigger and the interlocks with corking or capping. Upstream, define filtration, product availability, feed condition and ownership of the buffer vessel.

A changeover sheet should list parts, reference settings and sanitation actions by SKU. Include gasket compatibility, drainability, retained-product handling and the method used to verify that cleaning is complete before the next batch.
