# DF-T200 Semi-Automatic Round Bottle Labeler

![DF-T200 Semi-Automatic Round Bottle Labeler](/images/filling-products/df-t200-round-bottle-labeler.webp)

The DF-T200 is a semi-automatic labeling station for pressure-sensitive labels on compatible round containers. It suits lower-volume or multi-format work where an operator loads each container, but label roll geometry and bottle surface condition still determine the achievable result.

## Application and purchasing fit

- Product family: [Labeling machine series](/en/solutions/labeling/)
- Parameter reference: [Filling and packaging equipment parameter library](/en/products/filling-equipment)
- Check the published product-diameter and label-size ranges against the complete container, not only the nominal body diameter.
- Allow for the operator’s loading and unloading method when estimating practical cycle time.
- Confirm whether one wrap label, partial wrap labeling or a registration feature is required.

## What to provide for a manufacturer quotation

- Round-container samples, diameter tolerance, label panel condition and any seams or surface features.
- Label roll, liner, core, winding direction, label dimensions and required placement.
- Expected batch size, changeover frequency, operator arrangement and available electrical supply.
- Acceptance limits for skew, overlap or gap, position and repeatability using production samples.

Use representative samples for the factory acceptance test whenever practical. The agreed test material, run duration, sampling method and pass limits should be written into the purchase specification.

Manufacturer pricing depends on the confirmed machine configuration, format parts, controls, guarding, line interfaces, utilities and destination.
