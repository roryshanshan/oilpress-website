# Linear 10-25 L Filling Machine

![Linear 10-25 L Filling Machine](/images/filling-products/linear-filling-machine.webp)

This linear filler is configured for medium and large containers in the published 10-25 L range. Large-pack filling must account for product flow, container stability, nozzle travel and filled-container handling, so the fastest model is not automatically the best fit.

## Application and purchasing fit

- Product family: [Filling machine series](/en/solutions/filling/)
- Parameter reference: [Filling and packaging equipment parameter library](/en/products/filling-equipment)
- Choose the number of filling positions from the required rate at the actual volume and liquid temperature.
- Confirm whether containers arrive manually or by conveyor and how they are centered under each nozzle.
- Plan filled-container discharge, capping and weight or fill verification around the higher package mass.

## What to provide for a manufacturer quotation

- Liquid density, viscosity, temperature, foaming behavior and required wetted materials.
- Container samples, neck opening, fill-volume range, gross weight and target tolerance.
- Required output at each volume, feed method, conveyor and downstream capping arrangement.
- Cleaning procedure, drip-control requirement, FAT test liquid and written acceptance method.

Use representative samples for the factory acceptance test whenever practical. The agreed test material, run duration, sampling method and pass limits should be written into the purchase specification.
