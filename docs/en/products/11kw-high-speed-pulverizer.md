# 11Kw High-Speed Pulverizer
![High-Speed Pulverizer](/images/external/products-11kw-high-speed-pulverizer-2f354a64.webp)
## Product Overview

This machine uses a flywheel structure with interchangeable screens. The achievable particle-size distribution depends on the material, feed condition, screen, wear state, and test method; any micron-level target requires a representative sample test and an agreed sieve or laser-particle analysis.
Candidate materials include camellia seed, walnut, avocado, and other hard materials, subject to confirmation of shell content, foreign-matter removal, and feed preparation.
The supplier also lists a 15KW option at `3T/h` under specific test conditions. This is a supplier reference value, not guaranteed capacity.

## Reference output and acceptance

The table value `750kg/h` and the optional `3T/h` value must be verified separately for the quoted model. Before FAT/SAT, define the raw-material species and lot, shell or impurity content, feed particle size, feed moisture, target particle-size distribution, screen aperture, feeding method, and the complete cycle including feeding, grinding, discharge, screen cleaning, and restart. The protocol must state continuous test duration, allowed stoppages, scale and instrument calibration, sampling frequency, analysis method, acceptance tolerance, utilities, and operator actions. Neither value is a guarantee unless these conditions and the acceptance boundary are written into the signed contract.

## Procurement and service scope

The manufacturer quotation should identify the exact 11KW or 15KW configuration, voltage and frequency, screen set, contact materials, dust-control interface, guards, spare wearing parts, packing, delivery, warranty, and after-sales channels. FAT and SAT are separate scopes. Remote support and any on-site installation or training require written agreement on region, travel, visas, lodging, fees, duration, work content, buyer utilities, and acceptance responsibility; unlisted services are not included.
