# 榨油生产线配置工具

选择油料和压榨工艺，勾选需要的可选设备，把清单发给我们报价。必需的设备已默认勾选，带链接的设备可以点进产品页。

<LineBuilder />

## 发送清单之后

1. 工程师根据您的油料、工艺和每天处理量核对设备，确定每种设备需要几台，并把整线产能配平。
2. 我们发出整线报价，写明各设备型号、功率、占地面积、包装运输方式和交货期，方便您和当地团队评估投资。
3. 如果油料比较特殊或含杂较多，我们会请您寄送样品，在工厂试榨、试选，确认出油率和设备参数后再下单，降低采购风险。
