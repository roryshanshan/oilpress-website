# 配套设备

本页用于梳理采购范围，不代表固定的设备套餐。配套设备应围绕原料、榨油机型号、完整批次节拍、目标油品阶段、公用工程和车间布局进行匹配。

## 1. 原料预处理

- [芝麻筛选机](/zh/products/sesame-screening-machine)：用于芝麻等小颗粒油料干式筛分和风选；用实际样料确认筛孔及大杂、净料、细料的出料比例。
- [11kW 高速粉碎机](/zh/products/11kw-high-speed-pulverizer)：用于适配硬质籽仁的粒度准备；核对原料硬度、目标粒度、温升和换料清洗方式。
- [27kW 电蒸锅](/zh/products/27kw-electric-steamer)与[柴火蒸锅](/zh/products/wood-fired-steamer)：服务于明确的热榨调质配方；确认单批装料、热源和测温方式。
- [全自动滚筒炒锅](/zh/products/automatic-drum-roaster)与[导热油平底炒锅](/zh/products/heat-conducting-oil-flat-bottom-frying-pan)：使用买方原料比较传热、搅拌、出料和配方控制。
- [上料/粉碎/炒制一体机](/zh/products/feeding-crushing-frying-integrated-machine)：仅在组合布局及清洗换料方案适合项目时选用。
- [预榨机](/zh/products/pre-press-machine)：适用于特定原料和工艺的独立模块，不是所有液压榨油机的必备附件。

工艺选择可继续查看[榨油预处理设备采购指南](/zh/products/pre-treatment)。

## 2. 压榨与物料输送

确定预处理、单批装料、完整周期和榨桶配置后，再选择[液压榨油机型号](/zh/products/)。输送机、提升机和缓冲仓应按整线最慢工序配套，并预留清理、检查和换料空间。

饼粕后续可评估[粉饼机](/zh/products/cake-pulverizer)或[包饼机](/zh/products/cake-wrapping-machine)。询价前应写明饼粕尺寸、温度、用途、粉尘控制和包装方式。

## 3. 油品澄清、精炼与储存

- [气压千层滤油机](/zh/products/pneumatic-filter-press)：根据含渣量、黏度、油温和单批油量选择过滤面积与滤板结构。
- [过滤设备](/zh/products/filtration-equipment)：区分沉降、粗滤和精细澄清，不把所有除杂要求合并为一个设备名称。
- [食用油精炼设备](/zh/products/edible-oil-refining-equipment)：根据毛油化验和目标油品确定精炼模块。
- [精炼脱蜡设备](/zh/products/refining-and-dewaxing-equipment)：核对降温负荷、结晶养晶、过滤和低温澄清要求。

储油罐、泵和管路应按油品阶段、材质、清洗方式、温度和输送距离选型。具体边界见[油品后处理设备指南](/zh/products/post-treatment)。

## 4. 灌装与包装

[灌装与包装设备目录](/zh/products/filling-equipment)涵盖洗瓶、灌装、灯检、封口、打塞、缩帽、干燥、贴标、打码、装箱和码垛。报价需要液体性质、瓶盖样品、灌装范围、目标线速、标签与喷码要求、公用工程以及自动化边界。

## 5. 采购与验收清单

1. 提交原料、目标成品、代表性样品和计划工艺流程。
2. 写明单批、小时或日产目标、工作时间、清洗时间和换料频率。
3. 确认电压、热源、压缩空气、水、通风、排水和可用场地。
4. 在报价中拆分主机、选配模块、控制、管路、安装、调试、培训、备件和运输。
5. 约定 FAT/SAT 对处理量、周期、温度、压力、输送、清洗、安全联锁和产品指标的记录方法。
