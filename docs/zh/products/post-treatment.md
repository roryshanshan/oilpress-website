# 油品后处理设备

后处理设备必须从目标油品阶段倒推。沉降和过滤主要去除悬浮固体，精炼、脱蜡和脱臭是另外的工艺决策；单独购买过滤机或精炼模块，并不等于油品自动符合所有食品法规或市场标准。

## 按目标油品阶段选型

| 目标阶段 | 需要核对的典型范围 |
| --- | --- |
| 压榨毛油 | 带盖沉降罐、受控转移和明确的取样点 |
| 澄清或过滤油 | 缓冲罐，以及按含渣量、黏度、温度和批次节拍选择的过滤设备 |
| 精炼油 | 根据化验数据选择脱胶、碱炼或物理精炼、脱色和脱臭模块 |
| 脱蜡或冬化油 | 根据油种和低温澄清要求确定降温、结晶、养晶和过滤 |
| 瓶装成品 | 成品油罐、卫生级输送、灌装、封口、贴标和打码 |

## 设备入口

- 在[气压千层滤油机](/zh/products/pneumatic-filter-press)页面核对过滤面积、滤板结构、工作压力和清洗方式。
- 以除渣和澄清为主要需求时，先查看[过滤设备总览](/zh/products/filtration-equipment)。
- 需要精炼线报价前，对照[食用油精炼设备](/zh/products/edible-oil-refining-equipment)和[精炼脱蜡设备](/zh/products/refining-and-dewaxing-equipment)的工艺边界。
- 根据瓶型、盖型、灌装范围和线速选择[灌装与包装设备](/zh/products/filling-equipment)。

## 获取价格与配置需要提供

1. 油种、前端工艺，以及来油是毛油、沉降油还是已过滤油。
2. 有条件时提供水分及挥发物、不溶性杂质、酸价、过氧化值、磷、蜡和色泽等代表性化验数据。
3. 日处理量、单批量、工作时间和换油频率。
4. 目标油品阶段、当地食品或工业标准、包装形式及记录要求。
5. 蒸汽、电、水、冷却、压缩空气、场地、储罐以及废水和副产物处理条件。

## 出厂与现场验收

订货前约定试验油样、取样方法和记录表。根据供货范围记录流量稳定性、压力、过滤周期、截留固体、清洗时间、罐体损失、温度曲线、公用工程消耗及约定化验指标。最终保质期和法规符合性仍需在买方完整工艺、包装与储存条件下验证。
