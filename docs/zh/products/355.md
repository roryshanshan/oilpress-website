## 粉碎后直接冷榨的试料与验收记录

355-500 系列侧重原料清理、必要时低温干燥、粉碎后直接进入液压榨桶冷榨。选型不能套用通用出油率表，应使用买方实际原料和目标油品进行验证。

| 试料字段 | 验收前需记录的内容 |
| --- | --- |
| 原料路线 | 核桃、沙棘籽、紫苏籽、椰子、茶籽、火麻籽、亚麻籽、杏仁、松子或南瓜籽，并标明具体批次 |
| 进料状态 | 清理结果、实测含水率、必要时的低温干燥、粉碎粒度范围和进料温度 |
| 设备设定 | 榨桶直径、实际装料量、压力程序、保压时间、卸料时间和完整周期 |
| 油品结果 | 按约定沉降或过滤终点称量净油，记录油温并扣除容器皮重 |
| 饼粕结果 | 记录饼粕质量、状态，并按约定实验室方法检测残油 |
| 验收口径 | 同批原料重复试压，统一取样、计量器具、计算公式和书面验收限值 |

废白土、活性炭脱色剂等工业物料必须单独审核 SDS，并确定密闭收集、人员防护和合规处置方案；不得与食品油冷榨共用同一套验收结论。

## 355机型：先把冷榨配方从试料做成稳定批次

355系列适合把原料试压逐步转为可重复的小中批量冷榨。基础路线为：**筛选 -> 清理 -> 必要时低温干燥 -> 高速粉碎 -> 直接液压压榨 -> 沉降或过滤**，该路线不设置蒸炒环节。

### 建议优先验证的原料

- **核桃与杏仁**：记录仁料完整度、储存氧化、含水率和粉碎均匀度。
- **紫苏籽与亚麻籽**：核对清理、细粉损失、粉碎升温和过滤介质负荷。
- **沙棘籽**：确认与果肉的分离方式、干燥历史及实际含油部分。
- **南瓜籽与松子**：说明是否去壳，并记录预处理中的仁料破损。

### 355报价需要确认的项目

明确单桶、双桶或大小子母桶配置，实际装料量、粉碎能力、过滤方法、不同原料之间的清洗方式及同批试料验收记录。榨桶放大必须通过装料、排油、完整周期和饼粕残油验证，不能换算成固定增产承诺。

### 工业物料边界

废白土、活性炭脱色剂必须提供SDS，并核对溶剂与挥发物、密闭收集、人员防护和合规处置路线。工业物料不得与食品油共线验收，应单独试料和报价。
