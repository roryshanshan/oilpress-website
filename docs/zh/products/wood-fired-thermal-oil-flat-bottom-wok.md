# 烧柴导热油平底炒锅

![烧柴导热油平底炒锅](/images/external/products-wood-fired-thermal-oil-flat-bottom-wok-cc178b06.webp)
## 产品概述

该设备由炉膛、导热油换热夹层、搅拌和出料结构组成，用于热榨油料的炒制或调质。导热油有助于沿锅体传热，但批次均匀性仍取决于燃料、火力控制、导热油液位、搅拌、装料和工艺配方。

- 柴或天然气应结合当地燃料供应、排放、通风和消防要求确定。
- 选配鼓风机会改变助燃空气和升温速度，应与炉膛、烟道及现场条件一起核对。
- 岩棉保温和不锈钢外包属于订货图纸中需要确认的结构范围。
- 可调刮刀在间隙设置正确时可减少积料，但不能保证所有原料和配方都不粘锅或不焦糊。
