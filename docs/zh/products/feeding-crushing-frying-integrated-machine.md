# 上料/粉碎/炒制一体机
![上料/粉碎/炒制一体机](/images/external/products-feeding-crushing-frying-integrated-machin-3abcbed4.webp)
## 产品概述

这类设备把定量上料、粒度处理和加热调质组织在同一套预处理单元中，主要用于需要炒制或加热的热榨路线。它不是所有油料都通用的标准配置：原料粒度、含水状态、加热方式和各模块处理节拍必须相互匹配。

对于本站的 300、325 热榨机型，可在样料试验确认后讨论与该单元衔接。355–500 机型侧重清理、必要时低温干燥、粉碎后直接冷榨，通常不应默认加入炒制段；是否需要旁路或独立预处理设备，应写入工艺方案。

## 采购前需要确认

- **原料条件：** 油料名称、入料形态、杂质、水分和是否已经脱壳。
- **粉碎要求：** 目标粒度、允许细粉比例，以及不同原料切换时的清理方式。
- **加热边界：** 热源、温度控制方式、排湿或排烟要求，以及接触物料材质。
- **生产节拍：** 目标批次或小时工作量、后端榨油机装料节拍和计划运行时间。
- **现场条件：** 电压、频率、可用热源、设备布置、除尘、消防和维护通道。

## 报价与验收范围

厂家报价应分别列明上料、粉碎和炒制模块的配置，说明输送、控制柜、热源、除尘接口、安装材料和备件是否包含。价格会随原料、处理要求、自动化范围和现场条件变化，不能只按“一体机”名称比较。

验收方案宜使用约定样料，检查连续上料、粒度一致性、加热均匀性、排料衔接和清理便利性。质保、安装指导、调试、易损件和售后响应范围以正式合同与技术附件为准。
