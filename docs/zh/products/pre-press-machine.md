# 预榨机

![预榨机](/images/external/products-pre-press-machine-c62a58a9.webp)
## 产品概述

该螺旋预榨机应作为后续工艺前的原料处理或预压榨模块进行评估。是否适用取决于原料状态、进料粒度、目标出料或饼粕状态、后续设备、易损件计划和整线产能平衡。

## 采购核对要点

- **工艺作用：** 明确项目需要粉碎、预榨还是两者兼有，以及出料如何进入下一台设备。
- **代表性原料：** 菜籽、大豆、亚麻籽、芝麻、核桃、花生等应分别试料，不能用一套设置覆盖所有原料。
- **进料与出料：** 记录进料粒度、水分、允许杂质、出料温度以及饼粕或碎料状态。
- **传动与易损件：** 核对电机、减速机、螺旋、榨膛、轴承、润滑点和报价中的备件清单。
- **噪声与振动：** 按约定试验条件测量，不使用无条件的低噪声或稳定运行承诺。

## 获取价格与报价需要提供

提交原料、样料状态、需要的工艺作用、目标处理量、后续设备、电压、工作时间和目的地。报价应拆分主机、电机减速机配置、易损件、控制、运输、安装支持和质保范围。

## 验收记录

订货前约定投料量、试验时间和测量方法，记录实际处理量、电流、温度、振动、噪声、出料状态、堵料、清洗时间和易损件检查结果，按签字试机记录及订货规格验收。
