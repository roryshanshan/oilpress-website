## 粉碎后直接冷榨的试料与验收记录

355-500 系列侧重原料清理、必要时低温干燥、粉碎后直接进入液压榨桶冷榨。选型不能套用通用出油率表，应使用买方实际原料和目标油品进行验证。

| 试料字段 | 验收前需记录的内容 |
| --- | --- |
| 原料路线 | 核桃、沙棘籽、紫苏籽、椰子、茶籽、火麻籽、亚麻籽、杏仁、松子或南瓜籽，并标明具体批次 |
| 进料状态 | 清理结果、实测含水率、必要时的低温干燥、粉碎粒度范围和进料温度 |
| 设备设定 | 榨桶直径、实际装料量、压力程序、保压时间、卸料时间和完整周期 |
| 油品结果 | 按约定沉降或过滤终点称量净油，记录油温并扣除容器皮重 |
| 饼粕结果 | 记录饼粕质量、状态，并按约定实验室方法检测残油 |
| 验收口径 | 同批原料重复试压，统一取样、计量器具、计算公式和书面验收限值 |

废白土、活性炭脱色剂等工业物料必须单独审核 SDS，并确定密闭收集、人员防护和合规处置方案；不得与食品油冷榨共用同一套验收结论。

## 426机型：按物料状态选择榨桶直径

426系列公开配置包含多种榨桶直径以及单桶、双桶方案。选型应依据物料堆积密度、装料状态、排油和周期进行匹配，不能假定一个榨桶适合全部原料，也不能把大直径直接等同于更多净油。

### 冷榨示例

- **紫苏籽**：清理后稳定含水率，控制粉碎升温，再直接入桶压榨。
- **火麻籽**：核对籽料清洁度、储存状态、粒度和防氧化要求。
- **杏仁**：同批试料前记录仁料等级、含水率和粉碎均匀度。
- **南瓜籽**：说明壳仁状态，并约定净滤油与饼粕残油的检测方法。

![紫苏籽直接冷榨准备](/images/an-overview-of-the-cold-pressing-process-of-perill-76371f15c4.webp)

![南瓜籽直接冷榨准备](/images/an-overview-of-the-cold-pressing-process-of-pumpki-c206ee35aa.webp)

### 换料与验收

多原料生产线应在报价中明确榨桶选择、清洗通道、交叉接触控制、粉碎筛网更换、过滤耗材和分区储存。每一类原料都要单独进行可重复试压，不能把核桃、芝麻或其他油料的结果直接套用。

### 工业配置

失效白土和活性炭脱色剂按工业进料评估。需要SDS审核、密闭液体收集，并根据风险设置防爆或职业暴露控制和书面废物处理边界。
