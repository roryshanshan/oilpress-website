# 柴火蒸锅
![柴火蒸锅](/images/external/products-wood-fired-steamer-f4d44ffc.webp)
## 产品概述

柴火蒸锅用于热榨前对已清理、破碎或其他预处理后的油料进行加热和水分调质。公开结构包括 Q355B 碳钢灶体、内部集热管、带底部排水口的一体式水箱和 304 不锈钢锅体；参数表列有煤、柴、气三种燃料，但具体燃烧器、炉膛和控制配置应以订货方案为准。

该设备可在原料、批次方式和目标调质状态明确后，与 300、325 热榨路线配套讨论。355–500 机型侧重粉碎后直接冷榨，不应默认配置蒸制加热段，以免与成品油温度要求冲突。

## 选型与现场条件

- 油料名称、入料水分、颗粒状态和单批装料量；
- 目标调质方式、工作温度范围、停留时间和出料方式；
- 可用燃料、烟囱走向、通风、当地消防要求和操作防护；
- 供水、排水、水质、蒸汽或湿气排放及清洗方式；
- 控制用电、车间布置、维护通道以及与下一工序的衔接。

## 厂家报价与验收

报价应列明灶体、锅体、水箱、烟囱组件、控制或仪表、安装材料和可选附件的供货范围。价格会随燃料方案、接触材质、现场公用工程和交付边界变化。

验收应核对订货材质和尺寸，检查盛水与排水、约定燃料下的加热运行、出料和清洗通道，并使用约定样料确认调质结果。安装指导、调试、备件、质保和售后服务以签署的报价单与技术协议为准。
