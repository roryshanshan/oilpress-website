## 粉碎后直接冷榨的试料与验收记录

355-500 系列侧重原料清理、必要时低温干燥、粉碎后直接进入液压榨桶冷榨。选型不能套用通用出油率表，应使用买方实际原料和目标油品进行验证。

| 试料字段 | 验收前需记录的内容 |
| --- | --- |
| 原料路线 | 核桃、沙棘籽、紫苏籽、椰子、茶籽、火麻籽、亚麻籽、杏仁、松子或南瓜籽，并标明具体批次 |
| 进料状态 | 清理结果、实测含水率、必要时的低温干燥、粉碎粒度范围和进料温度 |
| 设备设定 | 榨桶直径、实际装料量、压力程序、保压时间、卸料时间和完整周期 |
| 油品结果 | 按约定沉降或过滤终点称量净油，记录油温并扣除容器皮重 |
| 饼粕结果 | 记录饼粕质量、状态，并按约定实验室方法检测残油 |
| 验收口径 | 同批原料重复试压，统一取样、计量器具、计算公式和书面验收限值 |

废白土、活性炭脱色剂等工业物料必须单独审核 SDS，并确定密闭收集、人员防护和合规处置方案；不得与食品油冷榨共用同一套验收结论。

## 480机型：规划更大批次的冷榨节拍

480系列面向更大批次和更密集的冷榨排产。工艺仍是原料清理、粉碎后直接压榨，但项目重点会转向上料与出饼、批次缓冲、过滤能力、吊装检修空间和计划维护。

### 代表性项目原料

- **核桃与松子**：控制仁料氧化，记录储存时间并保持粉碎均匀。
- **沙棘籽**：记录分离、干燥和实际含油部分，再确定批次装料。
- **火麻籽与亚麻籽**：管理细粉、粉尘、粉碎升温和过滤负荷。
- **杏仁**：核对仁料等级、杂质，以及批次之间的清洗方式。

### 480整线核对

询价应包含上料与出料方式、操作通道、地面荷载、装机功率、吊装方法、缓冲容量、过滤面积、储油和每班计划周期。验收需记录完整周期而不是只记录保压时间，日产量应由见证试机结果计算。

### 独立工业工况

如项目处理废白土或失效活性炭，应明确物料危害、溶剂或挥发物、密闭收集、清洗、人员防护和处置方式，不能与食品油共用验收方案。
