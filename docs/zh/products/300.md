## 热榨试料与验收记录

出油结果不是机型的固定数值。300/325 热榨项目应使用同一批原料进行重复试压，并完整记录蒸炒或调质条件，不能用通用出油率表代替项目验证。

| 试料字段 | 验收前需记录的内容 |
| --- | --- |
| 原料 | 品种、供应批次、清理后投料质量、杂质率和实测含水率 |
| 预处理 | 粉碎粒度、蒸炒或调质温度、保温时间和入榨温度 |
| 压榨周期 | 榨桶规格、实际装料量、压力程序、保压时间、卸料时间和完整周期 |
| 油品结果 | 按约定沉降或过滤终点称量净油，并扣除容器皮重 |
| 饼粕结果 | 记录饼粕质量，并按约定实验室方法检测残油 |
| 比较口径 | 同批原料至少进行两次可重复试验，统一计算公式和计量器具 |

> 投料基准出油率与按原料实测含油量计算的提取率不是同一指标。报价和验收文件必须写明采用的计算口径；未完成有代表性的见证试验前，不承诺固定百分比。

+ 标准桶规格为：
  - 直径：390mm
  - 长度：800mm
  - 容积： 95.6 升（可放粉碎后的物料100kg左右,不断压实投放）
  - 油料与榨桶是否适配，须针对拟采用的热榨路线用代表性物料试验确认，不能仅凭桶径判断。
