# 榨油预处理设备

预处理不是固定的设备套餐。厂家配置应根据原料种类、来料杂质、水分、目标粒度、热榨或冷榨路线、榨油机装料节拍以及成品油要求确定。

## 先确定工艺，再确定设备

- **小颗粒干籽：** 压榨前去除粉尘、大杂、石块和金属。芝麻、菜籽、亚麻籽、紫苏籽等可先查看[芝麻筛选机](/zh/products/sesame-screening-machine)，并用实际样料确认筛孔和各出料口比例。
- **坚果与硬质籽仁：** 先确认是否脱壳、分级及榨油机要求的粒度，再通过样料判断[11kW 高速粉碎机](/zh/products/11kw-high-speed-pulverizer)或其他粉碎设备是否匹配。
- **300/325 热榨项目：** 清理、粉碎后按配方进行蒸制、调质或炒制，可比较[27kW 电蒸锅](/zh/products/27kw-electric-steamer)、[柴火蒸锅](/zh/products/wood-fired-steamer)和[全自动滚筒炒锅](/zh/products/automatic-drum-roaster)的批量、热源和测温方式。
- **355-500 冷榨项目：** 清理后仅在必要时低温干燥，粉碎后直接进入液压榨桶；除非买方明确改变工艺，冷榨报价中不应默认加入高温蒸炒。
- **鲜果、油棕果、牛油果和米糠：** 需要单独核对保鲜、灭酶、脱果肉或稳定化等前段工艺，不能套用普通干籽方案。

## 常见预处理模块

| 模块 | 采购时应核对 |
| --- | --- |
| 筛分、风选、去石和除铁 | 来料洁净度、筛孔、粉尘接口及各出料口用途 |
| 脱壳与壳仁分离 | 是否必须脱壳、壳仁分离率及壳、仁、细料的收集方式 |
| 粉碎、轧胚或研磨 | 目标粒度、温升、实际处理量及换料清洗方式 |
| 蒸制、调质或炒制 | 热榨配方、热源、单批装料、测温和出料方式 |
| 输送与缓冲 | 按整线最慢工序和榨油机完整周期配套，而不是只看铭牌产能 |

[上料/粉碎/炒制一体机](/zh/products/feeding-crushing-frying-integrated-machine)和[预榨机](/zh/products/pre-press-machine)属于可选工艺模块，不是每条液压榨油线的必选设备。

## 获取厂家报价需要提供

1. 原料名称、照片或样品、杂质、水分以及是否带壳。
2. 计划采用热榨还是冷榨，以及需要毛油、过滤油还是后续精炼油。
3. 单批、每班或日产目标，以及换料和清洗频率。
4. 已选榨油机型号、场地、电压、热源、除尘和当地公用工程限制。
5. 采购边界：单机或整线、控制系统、安装支持、备件和技术文件。

## 验收依据

使用买方代表性原料记录来料状态、除杂损失、粒度设置、适用时的温度、实际处理量、输送稳定性、清洗维护空间和安全联锁。出油率和油品指标属于原料与完整工艺的综合结果，不能由某一台预处理设备单独保证。
