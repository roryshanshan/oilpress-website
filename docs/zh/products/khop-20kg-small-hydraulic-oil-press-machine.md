# KHOP-20KG 小型液压榨油机

![KHOP-20KG 小型液压榨油机](/images/korean-type-small-press/korean-type-side.webp)

KHOP-20KG 是该韩式小型液压系列中的 20 kg 批次级别机型，面向前店展示加后场处理的芝麻油项目。它是本系列页面中列出的较大装料级别，实际日产需按原料、完整周期和连续测试条件验收。

## 核心优势

- 20 kg 批次级别装料结构
- 液压系统和控制界面按该型号配置
- 压榨循环功能以书面供货清单为准
- 机架和维护点可在 FAT 中检查
- 适合零售展示加后场压榨的布局

## 推荐原料

适用原料包括：

- 芝麻，首选推荐
- 核桃仁
- 茶籽
- 松子
- 杏仁

如果项目已经转向工厂型多油料批量加工，可升级对比 [325系列](/zh/products/325) 或 [355系列](/zh/products/355)。

### 参考产能与验收边界

本页所列 `1.0、1.8、2.1 t/24h` 均为供应商在特定测试条件下的参考值，不构成产量保证。报价和合同签署前，应书面记录原料品种与批次、预处理方式及粒度分布、进料含水率、单批重量，以及从上料、压榨、沥油、出饼、清洁到再次启动的完整周期。FAT/SAT 方案还应约定连续测试时间、允许停机情形、称量与校准方法、取样或实验室方法、验收公差、计入的公用工程和操作人员动作。只有写入已签署合同的指标才构成验收依据。

“自动液压压榨”仅描述液压循环和控制配置；上料、装筒、出饼、清洁和物料搬运仍可能需要操作人员。
