## 粉碎后直接冷榨的试料与验收记录

355-500 系列侧重原料清理、必要时低温干燥、粉碎后直接进入液压榨桶冷榨。选型不能套用通用出油率表，应使用买方实际原料和目标油品进行验证。

| 试料字段 | 验收前需记录的内容 |
| --- | --- |
| 原料路线 | 核桃、沙棘籽、紫苏籽、椰子、茶籽、火麻籽、亚麻籽、杏仁、松子或南瓜籽，并标明具体批次 |
| 进料状态 | 清理结果、实测含水率、必要时的低温干燥、粉碎粒度范围和进料温度 |
| 设备设定 | 榨桶直径、实际装料量、压力程序、保压时间、卸料时间和完整周期 |
| 油品结果 | 按约定沉降或过滤终点称量净油，记录油温并扣除容器皮重 |
| 饼粕结果 | 记录饼粕质量、状态，并按约定实验室方法检测残油 |
| 验收口径 | 同批原料重复试压，统一取样、计量器具、计算公式和书面验收限值 |

废白土、活性炭脱色剂等工业物料必须单独审核 SDS，并确定密闭收集、人员防护和合规处置方案；不得与食品油冷榨共用同一套验收结论。

## 500机型：先定义高负载项目的验收边界

500型是公开355-500系列中总压力最高的机型。只有在买方已经确认原料路线、真实批次需求、现场物料搬运，并比较“一台大机”与“多台较小机型”的节拍和经济性后，才适合确定该型号。冷榨路线仍为：**清理 -> 必要时调整含水率 -> 粉碎 -> 直接入桶压榨 -> 受控沉降或过滤**。

### 建议见证试压的原料

- **松子与核桃**：记录仁料质量、氧化暴露、含水率、粉碎和净滤油。
- **南瓜籽与杏仁**：说明壳仁状态、批次装料、出饼和清洗时间。
- **火麻籽、亚麻籽与紫苏籽**：控制粉尘、细粉损失、粉碎温度和过滤终点。
- **茶籽与椰子**：先定义进料准备和含水率限值，再确认榨桶与周期。

### 合同与交付关口

下单前确认主机与榨桶配置、基础和吊装条件、公用工程、上游粉碎能力、下游过滤与储油、备件、出口包装、安装责任和验收不合格处理。多机项目应演示错峰周期和操作人员工作量，不能简单乘以名义单批数值。

### 工业残余物项目

化工废白土和活性炭脱色剂必须依据SDS和代表性样品单独进行工程评估。合同需明确围护、人员防护、清洗、分离液处理和合法处置责任。
