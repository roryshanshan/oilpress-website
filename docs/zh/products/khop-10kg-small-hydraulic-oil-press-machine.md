# KHOP-10KG 小型液压榨油机

![KHOP-10KG 小型液压榨油机](/images/korean-type-small-press/khop-10kg.webp)

KHOP-10KG 是面向芝麻油门店、鲜榨油柜台和样品试压型精品油项目的小批量液压压榨设备。液压循环和门店展示布局可减少部分人工压榨动作，但上料、装筒、出饼、清洁和物料搬运是否需要人工，取决于书面报价中的实际配置。

## 核心优势

- 液压缸与小批量装料结构
- 液压循环和控制界面可按配置确认
- 压榨区域可观察，便于记录过程
- 结构紧凑，适合门店和柜台摆放
- 原料适用性以代表性样品试压确认

## 推荐原料

本机型主要适合以下高附加值原料：

- 芝麻，优先推荐
- 核桃仁
- 茶籽
- 去壳松子
- 杏仁

如需更高产能的批量项目，可对比 [300系列](/zh/products/300)。

### 参考产能与验收边界

本页所列 `1.0、1.8、2.1 t/24h` 均为供应商在特定测试条件下的参考值，不构成产量保证。报价和合同签署前，应书面记录原料品种与批次、预处理方式及粒度分布、进料含水率、单批重量，以及从上料、压榨、沥油、出饼、清洁到再次启动的完整周期。FAT/SAT 方案还应约定连续测试时间、允许停机情形、称量与校准方法、取样或实验室方法、验收公差、计入的公用工程和操作人员动作。只有写入已签署合同的指标才构成验收依据。

参数表中的“自动液压压榨”仅描述液压循环和控制配置，不表示上料、卸料、清洁及全部物料搬运均可无人完成。
