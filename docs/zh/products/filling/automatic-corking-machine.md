# 全自动打塞机

![全自动打塞机](/images/filling-products/automatic-corking-machine.webp)

全自动打塞机是本系列面向连续包装线的配置：灌装后的玻璃瓶由上游送入，设备按连续机循环完成打塞，再把成品瓶交给后续缩帽或贴标工序。公开资料列出 DS-1、DS-4、DS-6 作为参考机型，因此采购时不能只比较打塞头数，还要把供瓶、供塞和前后段输送一起界定。

## 连续线的自动化边界

一份完整的全自动方案，应明确上瓶、上塞、压塞和出瓶四段动作由谁完成。

- **上瓶：**正常连续生产不应由操作员逐瓶放入打塞位。报价图纸要标出与灌装机或输送线的交接点、瓶距控制、导向和缓冲是否供货。
- **上塞：**厂家应说明软木塞怎样储存、整理、定向并送到压塞位置。料斗、提升或理塞机构未写入清单时，不应默认包含。
- **压塞与出瓶：**瓶体转移和压塞属于设备循环，出瓶端需要明确接缓存输送还是直接交给下游设备。
- **操作员任务：**补充瓶塞、启停和巡检、抽查入塞状态，并按操作规程处理停机；稳定运行时不应逐瓶搬运。

## 节拍组织与人员配置

整线实际节拍由最慢的连接工序决定，而不是打塞机单机名义值。灌装机出瓶、缓存长度、供塞连续性、打塞循环以及缩帽或贴标进瓶都要匹配。向厂家询价时，应要求写明产能数据的适用条件，并说明缺瓶、缺塞、上游停机和下游堵瓶时如何联动；这些功能不能仅凭“全自动”名称推定。

## 样瓶样塞与换型证明

定型前提供实际生产瓶和瓶塞。样品应覆盖瓶高、底部稳定性、瓶口外形和内孔，以及瓶塞类型、直径与长度。若有多个 SKU，提交规格矩阵，让厂家逐项说明哪些导向、输送件、供塞件或打塞头设定需要调整或更换，并把随设备提供的换型件、调整方法和验收时的换型演示写入报价。

## 布局、设备接口与公用工程

要求厂家提供总布置图，标出进出瓶方向与高度、防护门和电柜开启空间、补塞位置、维护通道及前后缓存。灌装机到打塞机之间既要明确机械交接，也要明确运行、就绪、停机或故障信号由谁提供。下游缩帽设备应接收瓶塞已压到约定位置且输送稳定的瓶子；只有报价明确包含时，才能把直接同步控制计入供货。

公用工程按实际方案确认电压、相数和频率，并询问是否需要压缩空气、真空或其他介质。厂家报价应给出连接点和用量，不让采购方自行猜测。

## 厂家报价范围与 FAT/SAT

便于比价的报价应把主机、理塞供塞、输送与导向、瓶型件、防护和控制、随机备件、说明书、出口包装、安装调试、培训及售后服务分别列出，同时注明不含项、交货边界和买方自备设备。

FAT 前由双方确认样瓶样塞、测试规格、持续时间、观察项目和通过条件。现场应检查连续交接、供塞、入塞状态、计划停机和重新启动，但不能把公开参数表直接当作无条件保证。SAT 则在实际公用工程和灌装、下游设备接通后重复约定项目，并记录尚未关闭的接口问题。
