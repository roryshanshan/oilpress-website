# 自动单头封口机

![自动单头封口机](/images/filling-products/single-head-sealing-machine.webp)

SY 自动单头封口机以一个封口工位完成瓶盖闭合，适合在公开瓶型和瓶口范围内做初步筛选。设备名称并未说明具体盖型和封口动作，采购前必须用样瓶样盖确认封口头、供盖方式、瓶体定位和验收方法。

## 适用与不适用边界

- 所属系列：[封口机系列](/zh/solutions/sealing/)
- 参数总览入口：[灌装包装设备参数库](/zh/products/filling-equipment#seal-single)
- 适合节拍能够与单头循环协调、瓶体可稳定定位的封口工位。
- 可接在灌装与放盖之后，并在下游配置封口检查、贴标或装箱。
- 若需要多头高速连续封口、特殊防盗盖成形或多种盖型频繁切换，应重新核算工位数量和专用工装，不能只按公开最大产能选型。

## 采购与厂家报价资料

- 提供瓶体和瓶盖样品、图纸及公差，说明封口后的目标高度、外观、密封和开启要求。
- 说明瓶盖如何理盖、输送和放置，以及缺盖、歪盖或卡盖时的处理要求。
- 提供目标节拍、输送线高度、方向、瓶间距、现场电源和前后设备清单。
- 在报价中确认封口原理、封口头、瓶型导向件、换型件、防护、控制接口及随机备件。

## FAT、SAT 与服务边界

FAT 应按约定样品数量连续验证定位、封口、出瓶、异常停机和换型复现，并用双方认可的方法检查盖体水平度、损伤、泄漏或开启力。SAT 重点检查现场输送接口、联机节拍和安全回路。交付周期、出口包装、安装调试、培训、质保期限及起算点、易损件、远程支持、现场服务费和差旅均以书面报价和合同为准。

单头结构的实际产量还受瓶体分度、封口停留和供盖恢复影响。采购方应要求厂家说明公开 `6000 瓶/小时`对应的瓶盖组合和连续试机条件，并确认下游积放在短暂停机时是否足够。

建议备件清单至少按最终结构列出封口头接触件、瓶体导向或托具、传动和检测相关易损件；具体数量、价格与交期由合同确认，不预设统一保修或免费更换范围。
