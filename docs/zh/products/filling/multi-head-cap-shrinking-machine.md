# 多头胶帽热缩机

![多头胶帽热缩机](/images/filling-products/multi-head-cap-shrinking-machine.webp)

多头机的选型核心是头数与整线节拍，而不是把整个 `2000-6000 p/h` 区间当成一台设备的通用产量。现有表格中，RS-1 为 1 头、2000 p/h，RS-6 为 6 头、6000 p/h；本页的多头采购重点应落在 RS-6 行，RS-1 仅作为单头对照。

## 多头节拍与线体匹配

- **工作节拍：**六头配置对应表内更高的公开产量。报价应把型号、头数和目标节拍绑定，不能只写“多头机”或引用系列区间。
- **适用瓶帽：**公开范围为瓶高 180-350、瓶径 60-100、PVC 胶帽长 30-70、直径 30-35。单位与最终样品适配应在技术协议中复核，范围本身不代表所有规格共用一套换型件。
- **工艺边界：**该页描述的是胶帽热缩，不包含碾帽功能。若采购需求同时要求瓶口外观碾压处理，应另行核对[碾帽/收缩两用机](/zh/products/filling/cap-rolling-shrinking-machine)并在报价中明确组件。
- **热源配置：**现有页面未指定蒸汽、电热或热风为标准方案，也未公布加热原理。采购文件需要写明实际热源、现场条件和供货接口，不能按行业习惯代替厂家确认。
- **联机节拍：**多头缩帽通常位于[打塞机系列](/zh/solutions/corking/)之后、[贴标机系列](/zh/solutions/labeling/)之前。上游打塞与胶帽放置、下游贴标都要能承接合同节拍；公开页没有说明供帽、缓存、剔除或具体联机信号是否包含。

## 多头机询价与换型清单

向厂家索取价格和采购报价时，应提供目标产量、现有输送线速度、样瓶样帽、瓶帽尺寸图、胶帽材质、上游打塞机、胶帽放置方式及下游贴标机资料。只有尺寸没有实物时，报价应注明后续样品确认节点。

报价需逐项列出所选型号与头数、加热配置、各瓶帽规格的换型件数量、各头位是否需要成套部件、输送及联机控制、备件、出口包装和售后范围。还应说明上帽或供帽装置是否在供货清单内，避免把缩帽机价格误解为完整瓶口包装段价格。

## 多头 FAT/SAT 的验收重点

- FAT 使用双方确认的样瓶样帽，并覆盖合同中列出的每个供货头位和换型规格。
- 验收记录应按批准样品比较各头位的胶帽外观，同时记录目标节拍下的进出瓶交接、停机再启动和已购信号接口；不把未签约功能加入结果承诺。
- SAT 在现场与实际打塞、供帽和贴标设备联机后复核节拍、热源条件及换型。产量、测试时长和合格判据应预先写入协议，而不是在到货后临时定义。
