# 智能定量灌装机

![智能定量灌装机](/images/filling-products/intelligent-quantitative-filling-machine.webp)

DK 系列用于定量灌装，并可按项目衔接提盖、理盖、扣盖和封盖工位。“智能”不等于所有后段功能都包含在基础机内，采购时应逐项核对供盖方式、盖型工装、检测和故障恢复范围。

## 适用与不适用边界

- 所属系列：[灌装机系列](/zh/solutions/filling/)
- 参数总览入口：[灌装包装设备参数库](/zh/products/filling-equipment#fill-dk)
- 适合公开瓶型范围内、能够按约定计量方式灌装，并使用可自动整理和闭合盖型的项目。
- 上游需要稳定供瓶和供液，下游可接封口检查、贴标、打码和装箱。
- 特殊异形盖、多组件盖、含气或难流动物料，以及频繁人工换盖的场景，应先验证供盖和缓冲方案。

## 公开型号说明

- 覆盖 `DK-12` 到 `DK-36` 机型
- 参考效率 `4000-13000 瓶/小时`
- 是否包含理盖、扣盖或最终封口，应以具体型号的供货清单为准。

## 型号采购判断

- 可按 `DK-12 / DK-18`、`DK-24 / DK-30` 和 `DK-36` 比较公开头数及机身尺寸。
- 最终选择需以实际瓶型、灌装量、盖型、换产频次和整线持续节拍核算，不能由头数直接推定自动化完整度。

## 获取厂家报价需要提供

- 物料性质、灌装量范围、目标偏差、清洗方法和接液材质。
- 每种瓶与盖的样品、图纸和公差，以及盖体整理、扣放、旋紧或封口要求。
- 目标节拍、输送接口、现场布局和公用工程，及上下游理瓶、贴标、装箱配置。
- 需要包含的提盖、理盖、检测剔除、换型件、缓存、整线控制和备件。

## FAT、SAT 与合同验收

FAT 应把灌装与盖处理作为连续流程验证，检查计量抽样、供盖、盖体定位、封口结果、缺瓶缺盖、卡料恢复和换型复现。SAT 在现场确认瓶液盖供应、输送积放和上下游信号。公开精度和产量只在约定样品、容量及测试条件下作为验收依据。

报价应按主机、供盖和封口模块、瓶型件、检测、防护、电控和备件拆分。出口包装、交付、安装调试、培训、质保、易损件、远程支持和现场费用均以合同为准。
