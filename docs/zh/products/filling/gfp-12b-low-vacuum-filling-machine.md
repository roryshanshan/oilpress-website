# GFP-12B低真空灌装机

![GFP-12B低真空灌装机](/images/filling-products/gfp-12b-low-vacuum-filling-machine.webp)

`GFP-12B` 与 `GFP-12A` 同属公开 12 头、`3000 瓶/小时` 参数段。由于现有表格中的头数、功率和外形尺寸相同，采购时更需要厂家书面说明 A/B 版本的结构、阀、瓶型件和控制差异，不能只凭型号字母判断升级关系。

## 工艺边界

本机面向兼容硬质瓶的不含气液体定液位灌装。是否适合葡萄酒、黄酒、酱油或醋，要通过实际液体观察泡沫、液位、回液和清洗。含气、高黏、含颗粒物料、软瓶或要求按重量交付的项目，不属于低真空液位机的默认范围。

## 核心参数

| 项目 | 参数 |
| --- | --- |
| 型号 | GFP-12B |
| 灌装头数 | 12 |

| 总功率 | 1.12 kW |
| 外形尺寸 | 1045×1050×2200 mm |
| 灌装方式 | 低真空 / 定液位灌装 |
| 适用液体 | 葡萄酒、黄酒、酱油、醋等易起泡液体 |

## 这台设备是做什么的

GFP-12B 以低真空和贴壁进液实现定液位灌装，可作为单机，也可布置在过滤或冲瓶之后，再连接打塞、缩帽和贴标。实际整线效果取决于供液、瓶颈和前后段节拍匹配。

## 公开结构与需验证项

- 低真空贴壁灌装的泡沫和液位表现需按客户液体、温度与瓶型试验。
- 托瓶、无瓶不灌装及瓶口异常识别范围，须在厂家功能清单中写明。
- 占地适配还要计算操作、清洗、检修和后续扩线空间，不能只看主机外形尺寸。

## 采购定位

- 适合先评估 12 头配置、以后可能增加打塞或封盖工位的中小型项目。
- 若采购用于调味液体，应确认液体黏度、盐分或酸度对接液件和清洗的影响。
- 与 12A 比价时，应让两份报价采用相同样品、验收节拍和服务边界，否则基础价格没有可比性。

## 报价输入与验收

提供实际液体、瓶样、瓶颈公差、目标液位、各规格节拍、清洗方式和下游工序。FAT 应覆盖连续灌装、液位抽样、泡沫、滴漏、瓶体交接、换型和停机恢复；SAT 验证现场供液、过滤、输送及后段接口。运行时间、抽样数量和合格限值写入技术协议。

报价需明确 12B 与 12A 的差异、真空和供液范围、瓶型件、防护、电控、备件和文件。出口包装、交期、安装调试、培训、质保、易损件、远程与现场售后以合同为准。
