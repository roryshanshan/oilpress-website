# 自动折盖封箱机

![自动折盖封箱机](/images/filling-products/carton-sealing-machine.webp)

自动折盖封箱机在后包装段将已装货、底部已封好的规则瓦楞纸箱上盖折合，并使用胶带完成顶部封箱。纸箱长宽高只是第一层筛选，纸板挺度、装箱后的重心、箱盖状态和胶带规格同样会影响连续封箱效果。

## 适用与不适用边界

- 所属系列：[装箱、码垛](/zh/solutions/packing-palletizing/)
- 参数总览入口：[灌装包装设备参数库](/zh/products/filling-equipment#pack-seal)
- 适合箱规相对稳定、上盖折线清晰且进入设备前箱体方正的规则纸箱。
- 上游通常是人工或自动装箱工位，下游可接称重、捆扎、喷码、码垛或托盘缠膜。
- 严重变形、潮湿、超出公开尺寸范围的纸箱，或需要随机箱规自动调整的项目，不应按标准配置直接报价。

## 采购判断

行业名称不能替代样箱验证。选型重点是纸箱能否顺利折盖、胶带在接缝处是否压实，以及封箱后是否影响标签、条码和搬运区域。

## 厂家报价需要的资料

- 最小和最大箱规、毛重、纸板材质与厚度、楞型、箱盖折线和装箱后的顶部状态。
- 胶带材质、宽度、卷芯和希望的前后搭接长度，并标出必须避开的印刷或标签区域。
- 目标箱数、箱间距、输送高度与方向，以及上游装箱和下游码垛的接口条件。
- 是否需要人工调节、多规格换型、缺胶带报警、前后段积放、护栏和整线控制信号。

## FAT、SAT 与验收

FAT 应使用量产代表性纸箱和实际胶带，连续检查折盖顺序、胶带居中、压贴、切断、箱体卡滞和约定节拍；不同箱规需分别验证。SAT 在现场确认输送高度、箱体交接、积放、急停和与码垛段的联机逻辑。验收限值应写明胶带偏移、翘边、开口、箱体损伤和抽样数量。

## 价格、交付和售后边界

报价应说明基础封箱机、前后输送、自动调节、检测报警、护栏和控制接口是否包含。出口包装、交付周期、安装调试、培训、胶带切刀和传动件等易损件、随机备件、质保起算点、远程支持及现场费用，以合同为准。
