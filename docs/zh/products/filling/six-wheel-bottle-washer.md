# 六轮式冲瓶机

![六轮式冲瓶机](/images/filling-products/six-wheel-bottle-washer.webp)

六轮式冲瓶机以套筒滚子链组织瓶子输送。循环水段同时采用跟踪喷冲和固定管道喷冲，清水段由分水器跟踪喷冲；这套喷冲组合是它区别于普通链轨式和回转式 QSP-6A 的关键。原资料没有说明翻瓶、毛刷、喷头数量或清洗结果，因此这些不能作为默认配置。

## 链传动与喷冲组织

套筒滚子链让瓶子按确定的节距通过各喷冲区。跟踪喷冲需要与瓶位同步，固定管道喷冲则覆盖一段固定路径，两者共同完成循环水段；末段清水由分水器跟随瓶位喷冲。连续链路要求瓶子在导向和承托中保持稳定，也要求前后输送速度协调，避免入口挤瓶或出口堆瓶。

循环水和清水是两个不同责任点。报价时应确认水箱、泵、过滤、补水、溢流、排污和管路中哪些随主机供货，不能因页面提到循环水就默认整套水处理系统包含在内。

## 玻璃瓶、PET 瓶与换型

表列适用范围为瓶径 50-100 mm、瓶高 100-320 mm，材料可选玻璃或 PET。范围内的瓶子仍可能因瓶肩、底部、刚度和重心不同而需要专用导向或承托。尤其是轻量 PET 瓶，应通过样瓶试验确认夹持和喷冲时不会失稳。

采购方需提供各瓶型样瓶及目标节拍，制造方据此列出链节或瓶托、导向、喷冲跟踪位置等换型项目，并说明 QSP-6A 与 QSP-6B 分别适配哪些瓶型。该页的 QSP-6A 与回转式 QSP-6A 同名，采购合同必须写全产品名称、能力范围、功率和外形尺寸。

## 接口、水源和车间条件

上游应连续提供排列稳定的空瓶，下游应具备接瓶及后续沥水或吹干能力。总图中要确认输送高度、方向、链速基准、启停联锁、积放长度和检修侧。表列外形尺寸之外还需预留操作通道、换型空间、管路和地漏。

原参数表没有给出用水量、供水压力或接口口径。采购方负责按最终公用工程清单提供清水、可能需要的循环水补水、电源和排水；制造方负责给出设备端条件。若采用热水、清洗剂或消毒介质，买方应提供成分、浓度、温度、安全及排放资料，卖方确认接液部件兼容性。介质制备和废水处理须在供货范围中明确。

## 采购价格、验收与服务

QSP-6A 和 QSP-6B 的采购价格不能只按产量比较。瓶型件、跟踪喷冲配置、水路范围、电控标准、前后输送、备件、出口包装、安装和调试都会影响总价。报价应逐项列出主机、瓶型件、分水器及水路、控制、工具、文件、FAT、包装和服务边界，并标明买方自备项目。

FAT 应用代表性玻璃瓶和/或 PET 瓶检查链传动、瓶位同步、循环水跟踪喷冲、固定管道喷冲、清水跟踪喷冲、换型及合同节拍。SAT 在现场供水排水和上下游联机完成后验证实际瓶流、接口信号与连续运行。清洗效果如需量化，必须预先约定污染样本和检查方法，不能补写未经验证的洁净度。

售后条款应明确质保时间和起算点、链条、瓶托、喷嘴、密封等易损件范围、远程支持、现场服务费和差旅、备件供应及培训。水质、化学介质、错误换型或外部输送造成的故障责任也应写入合同。
