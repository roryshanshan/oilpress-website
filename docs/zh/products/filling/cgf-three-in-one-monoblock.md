# 冲瓶、灌装、封口三联机

![冲瓶、灌装、封口三联机](/images/filling-products/cgf-three-in-one-monoblock.webp)

CGF 三联机在同一联动平台上完成硬质瓶冲洗、量杯定量灌装和封盖。它能减少三段之间的输送转接，但并不代表任意液体、瓶型和盖型都能直接套用；冲洗介质、排水、灌装量、瓶口结构和供盖方式必须在报价前确认。

## 适用与不适用边界

- 所属系列：[灌装包装联体机与整线方案](/zh/solutions/filling-packages)
- 参数总览入口：[灌装包装设备参数库](/zh/products/filling-equipment#fp-cgf)
- 适合能稳定夹持或承托、可按约定方式冲洗的硬质瓶，以及通过样品试验确认的非含气流动性液体。
- 上游需要稳定供应空瓶；下游可连接液位或封盖检查、贴标、喷码、装箱和码垛。
- 软包装、不能倒置或冲洗的容器、含气物料、高黏或含颗粒物料，以及特殊洁净或防爆要求，应单独设计，不能仅按 CGF 头数组合采购。

## 三段工艺需要分别确认

- **冲洗段**：说明冲洗介质、压力或流量要求、接触时间、回收与排水方式，以及瓶内残液验收方法。
- **灌装段**：提供物料性质、灌装量范围和允许偏差，确认量杯定量方式是否适合实际产品。
- **封盖段**：提供盖型、供盖状态和封口结果要求，明确理盖、上盖、封盖头与检测功能是否包含。

## 报价、FAT 与 SAT 资料

询价时应提交物料数据、瓶盖样品、全部规格、公用工程和现场布局，并说明冲洗水处理、液体供给、理盖和下游包装的责任边界。厂家报价需列明接液材质、三段头数组合、换型件、检测、安全防护、控制接口和随机备件。

FAT 应以约定样品连续验证冲洗覆盖与排水、灌装抽样、封盖结果、无瓶动作、卡瓶恢复和不同规格换型。SAT 在现场验证真实水源、排水、物料供给、输送标高和上下游联机。安装调试、培训、出口包装、交期、质保、易损件、备件价格、远程与现场售后范围必须写入合同。
