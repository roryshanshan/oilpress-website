# 直线式双标签全自动贴标机

![直线式双标签全自动贴标机](/images/filling-products/double-label-automatic-labeling-machine.webp)

直线式双标签贴标机用于在一个连续工位对瓶体两个指定面或两个区域贴标。采购时必须先确认瓶体截面、标签材质和实际上胶或贴附方式；“双标签”只说明标签数量，不能代表圆瓶、扁瓶、方瓶或不同胶黏工艺天然兼容。

## 适用与不适用边界

- 所属系列：[贴标机系列](/zh/solutions/labeling/)
- 参数总览入口：[灌装包装设备参数库](/zh/products/filling-equipment#label-double)
- 适合瓶体能够稳定导向、两处贴标面明确且标签规格在公开范围内的项目。
- 上游需要稳定分瓶和必要的瓶身定向，下游可接打码、标签检查、装箱和码垛。
- 异形瓶、透明标签、湿瓶或高低温表面，以及需要环绕、定向或多面组合贴标的项目，须通过样品试贴确认额外机构。

## 标签与胶黏方式先确认

公开参数提到树脂胶，因此报价前应明确该机具体采用的标签与上胶方式，不能直接按通用不干胶双面贴标机理解。需要提供标签纸、胶黏剂要求和清洗方式，并确认真空泵、上胶部件及耗材是否属于供货范围。

## 获取厂家报价需要提供

- 全部瓶型样品与图纸，标出正背面或两处标签区域、基准面、瓶体公差和表面状态。
- 两套标签样品、尺寸、材质、印刷方向、储存条件，以及胶黏剂或贴附工艺要求。
- 目标节拍、分瓶间距、输送高度与方向、是否需要瓶身定向、在线打码和标签检测。
- 允许的位置偏差、偏斜、皱褶、气泡、翘边和溢胶限值，以及换型件和清洗要求。

## FAT、SAT 与验收

FAT 应用实际瓶、两套标签和约定胶黏材料连续试机，检查分瓶、定向、两标相对位置、上胶或贴附状态、换型和停机恢复。SAT 在现场验证输送接口、环境温湿度、胶黏材料管理及与打码装箱设备的联机。公开产量需在对应瓶签和测试条件下复核。

## 价格、交付与服务边界

报价应列明两套贴标机构、分瓶与定向、真空或上胶系统、检测、换型件、防护和控制接口。出口包装、交期、安装调试、培训、胶辊或刮胶件等易损件、备件、质保和现场售后费用，以合同为准。
