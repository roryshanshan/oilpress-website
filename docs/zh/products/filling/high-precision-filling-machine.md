# 高精度定量灌装机

![高精度定量灌装机](/images/filling-products/high-precision-filling-machine.webp)

GDP 高精度定量灌装机面向把计量一致性作为主要采购指标的瓶装液体项目。公开表中的精度是在特定标定容量下的参考值；实际精度和持续节拍必须以客户液体、灌装量、容器和双方约定的测量方法验证。

## 适用与不适用边界

- 所属系列：[灌装机系列](/zh/solutions/filling/)
- 参数总览入口：[灌装包装设备参数库](/zh/products/filling-equipment#fill-high-precision)
- 适合公开容量和瓶型范围内、流动性及计量方式经样品试验确认的液体。
- 上游可接理瓶、冲瓶或储液供给，下游可接封盖、重量或液位复检、贴标和装箱。
- 含明显颗粒、高黏、强起泡、含气或腐蚀性物料不能仅凭“高精度”名称套用，需要另选阀、泵和接液材料。

## 公开资料摘要

- 标定容量 `500 ml` 时，参考精度 `±1.5 ml`
- 公开机型覆盖 `GDP-12B` 到 `GDP-40H`
- 常见灌装量范围 `100-750 ml`

## 型号采购判断

- `12-18 头`、`24-30 头`、`36-40 头`可作为头数和公开产量的比较区间。
- 最终型号应按每种灌装量的持续节拍、换型频次、清洗时间和下游封盖能力核算，不能只按最大瓶数放大或缩小。

## 获取厂家报价需要提供

- 液体密度、黏度、温度、起泡情况、接液材质和清洗方式。
- 全部瓶型样品、灌装量范围、目标偏差，以及按重量、体积或液位进行验收的方法。
- 每种规格的持续节拍、班次、输送高度与方向、上游供液和下游封盖检查接口。
- 配方或瓶型切换需求、校准方式、配方存储、单头调整、换型件和随机备件。

## FAT、SAT 与精度验收

FAT 不应只抽取少量合格瓶，而应在稳定运行后按约定数量和时间分布取样，记录平均值、离散情况和超差瓶，并确认测试液温度与密度。还需验证启停、缺瓶、换型和清洗后复现。SAT 在现场供液与整线节拍下使用相同方法复核，公开 `500 ml` 精度不能直接外推到全部容量。
