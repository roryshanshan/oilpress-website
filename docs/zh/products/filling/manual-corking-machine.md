# 手动打塞机

![手动打塞机](/images/filling-products/manual-corking-machine.webp)

手动打塞机是面向试样、短批次和低速生产的逐瓶工位。它的边界小、操作员可以直接控制每只瓶子的定位与压塞过程，但不能按连续输送设备理解。现有公开资料只确认其面向软木塞玻璃瓶，没有给出可据此承诺的手动产能或通用瓶型范围。

## 手动工位的动作边界

在具体结构图未说明其他配置时，采购应按以下分工理解：

- **上瓶：**操作员从托盘或缓存处取已灌装瓶，放到支承位置，并把瓶口对正打塞位。
- **上塞：**每个循环由操作员选择并放置一只瓶塞；自动理塞和送塞不属于手动边界，除非报价单独列出。
- **压塞：**操作员按实际机构直接提供或启动压塞动作。报价需要写清手柄、踏板或其他实际驱动方式，不能仅凭名称推断。
- **下瓶：**操作员取走瓶子，检查入塞位置，再交给下一道批处理工序。

## 人员任务决定逐瓶节拍

一个完整循环包含取瓶、定位、放塞、压塞、取瓶和目视检查。实际速度受操作员动作、瓶子搬运和瓶塞配合影响，应使用买方样品实测，不能套用本页自动 DS 机型的数字。手动工位与灌装之间更需要稳定的托盘或小缓存，而不是连续输送同步。

## 兼容性与换型确认

采购前寄送代表性瓶样和匹配瓶塞，核对瓶高、瓶底稳定性、瓶口形状与内孔，以及瓶塞类型、直径和长度。计划多种规格时，要求厂家说明瓶托、导向、机头高度或行程设定、接触瓶塞的零件是否调整或更换，并列明随机换型件及仍需试样确认的规格。

## 工位布局与前后段衔接

布局图要说明设备是台式还是落地安装、操作面、安全手部空间、待打塞瓶和瓶塞摆放区、成品瓶区域及调整通道。已灌装瓶可以来自小型灌装机或产线缓存，但手动打塞机不应被视为与灌装机同步的接口。瓶塞达到约定位置后，瓶子再由人工转入独立的缩帽工序。

“手动”也不等于必然没有公用工程。向供应商确认所报机构是纯机械式，还是需要电源、压缩空气或其他介质；如有需要，应在报价中列出接口条件。

## 报价范围和样品验收

比价时分别列出主机、机架或安装件、瓶托、随附工具、换型件、首批易损或备件、说明书、出口包装和售后联系人；安装培训、运费、税费及现场工作要明确含或不含。

FAT 使用双方确认的瓶塞组合，演示上瓶、对中、完整压塞、取瓶及重复操作，并记录可接受的入塞状态和人员调整方式。SAT 检查安装稳固性、操作可达性、现场公用工程以及灌装到打塞、打塞到缩帽的人工物流。除非双方先定义规格、人员、时间和判定方法，否则不要增加小时产量验收值。
