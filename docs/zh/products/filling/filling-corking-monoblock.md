# 灌装、打塞两联机

![灌装、打塞两联机](/images/filling-products/filling-corking-monoblock.webp)

葡萄酒灌装、打塞两联机把低真空灌装与软木塞压缩插入布置在同一设备内，减少灌装后玻璃瓶在两台单机之间的转接。采购重点不是“二联”名称，而是酒液起泡和液位表现、瓶口尺寸、软木塞规格及灌装后到打塞之间的控制条件。

## 适用与不适用边界

- 所属系列：[酿酒设备系列](/zh/solutions/brewing/)
- 参数总览入口：[灌装包装设备参数库](/zh/products/filling-equipment#brew-dual)
- 适合经试验确认可采用低真空定液位灌装，并使用兼容天然塞或技术塞的葡萄酒、果酒项目。
- 上游可接冲瓶、过滤和储液系统；下游通常接液位或异物检查、缩帽、贴标和装箱。
- 含气酒、明显高黏或含果肉产品、螺纹盖或铝制防盗盖包装，不属于本两联机的默认应用。

## 两个工位的采购重点

低真空灌装部分应通过实际酒液和玻璃瓶确认液位、泡沫、回液和清洗方式；打塞部分则需核对瓶口内径与公差、软木塞直径和长度、压缩状态、插入深度及瓶体承托。两段中任一条件不匹配，都会影响最终成品，不应只凭公开头数选型。

## 获取厂家报价需要提供

- 酒液性质、灌装温度、起泡情况、目标液位或灌装量，以及接液和清洗要求。
- 每种玻璃瓶与软木塞的图纸、量产样品和公差，说明塞入深度、允许破损及密封验收方法。
- 目标节拍、输送方向和高度、瓶型范围、公用工程、上游冲瓶与下游缩帽贴标配置。
- FAT 样品数量、抽样方法、换型件、备件、出口包装和现场服务需求。

## FAT、SAT 与合同边界

FAT 应连续检查进瓶、低真空灌装液位、滴漏、软木塞供给、压缩与插入、瓶口或塞体损伤和停机恢复。需要用双方约定的方法记录液位偏差、塞入深度、泄漏或保持结果，并验证每种规格换型。SAT 重点确认过滤或储液接口、现场输送、缩帽贴标衔接和整线节拍。

报价要列明灌装阀、打塞头、供塞系统、瓶型件、防护、电控和备件范围。交付周期、安装调试、培训、质保起算点、密封与夹持易损件、远程支持、现场费用和差旅均以书面合同为准。
