# 半自动打塞机

![半自动打塞机](/images/filling-products/semi-automatic-corking-machine.webp)

半自动打塞机位于人工手动工位与连续自动线之间，适合中小批次：设备承担可重复的单次压塞循环，操作员仍负责至少一部分瓶子和瓶塞搬运。“半自动”本身不能证明包含自动上瓶、理塞或输送，询价时必须把这些动作逐项写清。

## 半自动从哪里开始

若厂家提供的配置图没有另行说明，可按以下边界核价：

- **上瓶：**操作员逐瓶放到工作位置；自动进瓶属于选配或联机范围，不能默认包含。
- **上塞：**可能由人员逐只放塞，也可能由人员给辅助供塞机构补料。报价要说明采用哪一种，并列出是否有理塞定向机构。
- **压塞：**操作员触发后，设备完成一次压塞并复位，等待下一只瓶子。
- **下瓶：**通常由操作员取走或放行并检查入塞；如含自动出瓶，应在图纸和清单中单独体现。

## 人机共同组织节拍

这个工位按“从灌装缓存取瓶、定位、供塞、启动、取瓶、检查、送往下一工序”的单瓶循环运行。可持续节拍受整个动作链和人员覆盖影响，不只取决于压塞动作。排班前应用样品试机，确认一名操作员能否同时补塞和转运瓶子，且不会形成不安全或不稳定的堆积。

## 样品、换型与公用工程

提供实际瓶子和瓶塞，核对瓶高、瓶底、瓶颈和瓶口内孔与瓶塞类型、直径、长度的配合。每个 SKU 都应说明瓶托、瓶口对中、入塞深度和上塞位置用哪些设定或零件，换型过程应在验收中演示，而不是只写“多瓶型通用”。

由于压塞循环由设备辅助完成，需按实际配置确认电压、相数、频率以及是否需要压缩空气或其他介质，并取得用量与接口位置。

## 与灌装、缩帽设备的接口

半自动机可以布置在灌装机后面，但不代表两者机械同步。上游应设置能保护已灌装瓶、便于人员取瓶的缓存；下游按项目设置接瓶台、周转架或明确报价的输送线，再进入缩帽。需要输送时，应约定方向、高度、瓶距、检测元件及控制责任。只有瓶塞达到双方约定状态后，才能进入缩帽工序。

布局还应标出操作员上下瓶位置、瓶塞存放、护罩开启、维护通道和公用工程接点。这些信息决定厂家报的是可使用工位还是只有裸机。

## 报价边界及 FAT/SAT

报价中将主机价格与供塞选项、瓶托和换型件、机架或输送、防护、控制、备件、资料、出口包装、安装调试、培训及售后服务分列，并说明运费、现场施工和前后段设备的责任方。

FAT 采用约定样瓶样塞做多次人工上瓶循环，记录上塞方式、入塞状态、启动方式、防护动作、换型调整和正常停机后的恢复。SAT 核对现场公用工程、人员操作路径、上游缓存及下游交接。若要验收产量，必须先共同确定瓶型、瓶塞、人员数量、测试时长和判定规则，不能只引用公开表格。
