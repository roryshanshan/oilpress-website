# 灯检机

![灯检机](/images/filling-products/light-inspection-machine.webp)

灯检机通过受控光源和瓶体翻转或夹持，为液位、可见异物、瓶盖和封口状态检查提供观察条件。瓶子进出、夹持和翻转可以自动完成，但缺陷判断究竟由操作人员、相机还是其他检测系统承担，必须在厂家报价中明确。

## 适用与不适用边界

- 所属系列：[灯检机系列](/zh/solutions/light-inspection/)
- 参数总览入口：[灌装包装设备参数库](/zh/products/filling-equipment#light-standard)
- 适合透明或具有可观察区域的硬质瓶，以及能够承受所采用夹持和翻转方式的瓶盖组合。
- 可放在灌装封口后、贴标前，便于观察瓶内和封口状态；下游剔除、返工和记录流程应一并规划。
- 深色或不透明瓶、浑浊液体、不能倒置的包装，以及需要识别微小或不可见缺陷的项目，不能只靠普通灯检工位解决。

## 工位配置与采购判断

- 公开结构包含进瓶、夹瓶、翻瓶和出瓶动作；剔除是否自动、由谁触发及不合格品去向应按最终控制方案确认。
- 倒立观察可改变瓶内可见物的位置，但检测能力取决于液体颜色、透明度、光源、观察时间和缺陷标准，不能表述为无条件准确。
- 夹头和钳口需按瓶口或瓶盖外形配置，并通过样瓶试验确认不会产生超出约定限值的划伤、松盖或泄漏。
- 若采用人工观察，应评估岗位、照明眩光、观察时间和轮岗；若采用视觉系统，则需明确相机、算法、缺陷样本、剔除与数据记录范围。

## 获取厂家报价需要提供

- 瓶和盖样品、液体颜色与透明度、正常液位，以及希望识别的缺陷清单。
- 可接受和不可接受的挑战样，包括异物、低液位、歪盖、破损或其他约定缺陷。
- 目标节拍、允许观察时间、瓶体翻转限制、输送高度与前后设备接口。
- 人工或视觉检测方式、报警与剔除逻辑、数据记录、安全防护和现场岗位要求。

## FAT、SAT 与服务边界

FAT 应用正常样和盲测挑战样验证夹持翻转、观察条件、检出与剔除逻辑、误剔处理和连续节拍，并记录样本数量及结果。SAT 在真实液体、照明环境和现场人员或视觉系统条件下复核。报价需列明夹具、光源、视觉或人工工位、剔除、防护、换型件和备件；安装、培训、质保及售后费用以合同为准。

若由人工判断，厂家应说明设备只提供瓶体呈现与照明，不应把人员检验结果包装成设备固定准确率；若采用视觉系统，则需单独报价相机、算法验证和缺陷样本维护。
