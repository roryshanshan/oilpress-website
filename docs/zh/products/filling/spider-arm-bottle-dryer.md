# 蜘蛛手节能吹干机

![蜘蛛手节能吹干机](/images/filling-products/spider-arm-bottle-dryer.webp)

HG-A/HG-B 蜘蛛手吹干机更适合固定风刀难以连续覆盖瓶肩、腰线、凹面或把手周边的瓶型。摆臂风口沿通过中的瓶体表面跟随吹扫，因此选型应以真实瓶型、换型频次和机械空间为依据，不能只看公开产能。

## 机型定位

- 所属系列：[复杂瓶型吹干方案](/zh/solutions/drying/)
- 公开参数：[HG-A/HG-B 参数库条目](/zh/products/filling-equipment#dry-spider)
- 适用场景：复杂瓶型或频繁换型，利用摆臂贴近并跟随瓶体轮廓；每种规格都需核对摆臂行程和机械间隙。

## 摆臂跟随与复杂瓶型覆盖

蜘蛛手结构不是依赖单条固定风幕，而是让多个吹扫点围绕通过中的瓶体布置，更容易照顾瓶口过渡、瓶肩、把手、腰线和凹陷面。实际效果仍受瓶体稳定性、瓶间距、线速及冲洗后残水位置影响，应以约定的残水状态作为目标，不能笼统承诺所有瓶型“完全干燥”。

换型时需逐项确认摆臂位置与行程、导瓶件、输送带宽度，以及摆臂与瓶盖、瓶口支撑环、把手和防护罩之间的间隙。试机应包含最难覆盖的瓶型；圆瓶上可用的设置，不代表换到异形瓶后仍有足够覆盖和机械余量。

## 瓶样、报价与验收

- 蜘蛛手方案报价前，优先提供瓶肩、凹面或把手区域最难覆盖的量产样瓶，也可提交尺寸图；同时说明瓶体材质、空瓶或实装状态、目标线速与瓶间距，并标出贴标喷码或包装前需核查的残水位置。
- 同时确认输送高度、宽度与方向、上下游接口、电源和安装空间。报价应列明摆臂方案、换型件、调节范围、防护、所需公用条件、备件或易损件及安装调试边界。
- 在技术协议中写明 FAT/SAT：每种约定瓶型按目标线速连续运行，在规定运行后检查标记的残水区域，验证换型复现性和机械间隙，并记录接口与安全检查。验收应依据可观察、可记录的约定标准，不以“完全吹干”的泛化承诺代替。
