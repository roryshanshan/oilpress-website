# 低真空灌装机

![低真空灌装机](/images/filling-products/low-vacuum-filling-machine.webp)

GFP 系列以低真空方式对兼容的不含气液体进行定液位灌装，常见于葡萄酒、黄酒以及经样品确认的酱油、醋等易起泡液体。型号选择应先看液体与瓶颈条件，再用头数和公开产量筛选，不能仅按目标瓶数下单。

## 适用与不适用边界

- 所属系列：[酿酒设备系列](/zh/solutions/brewing/)
- 参数总览入口：[灌装包装设备参数库](/zh/products/filling-equipment#brew-vacuum)
- 适合不含气、可采用低真空定液位方式并具有兼容瓶口结构的液体和硬质瓶。
- 上游通常是过滤、储液和冲瓶，下游根据包装选择打塞或封盖、缩帽、贴标和装箱。
- 含气饮料、软包装、高黏或含颗粒物料，以及要求以重量精确控制而非外观液位的项目，应选择其他灌装方案。

## 采购时需要先做的试验

用实际液体和目标玻璃瓶观察灌装时的泡沫、贴壁流动、回液、最终液位和瓶口密封条件。相同头数的 12A 与 12B 不能仅凭名称判断结构差异，需由厂家在报价中列明具体配置和适用边界。

## 型号采购判断

- 按 `12 / 18 / 24 / 30 / 36 / 40 / 48 / 60` 头和公开产量做第一轮筛选。
- 再按实际灌装量、泡沫、瓶口、班次、清洗和后段打塞或封盖能力核算持续节拍。
- 高头数机型需要同步确认供瓶积放、占地、公用工程和后段包装能力，不应只比较主机价格。

## 获取厂家报价需要提供

- 液体种类、黏度、温度、酒精度或酸度、起泡和清洗要求。
- 瓶样、瓶颈尺寸与公差、目标液位或容量、全部瓶型及允许偏差。
- 各规格目标节拍、输送高度和方向、过滤储液条件、下游打塞或封盖方式。
- FAT 测试液或替代液、抽样方法、换型件、出口包装、安装和培训需求。

## FAT、SAT 与价格边界

FAT 应在稳定供液下连续检查液位、泡沫、滴漏、无瓶动作、瓶损、停机恢复和换型，并写明测试瓶型、灌装量、运行时间及合格限值。SAT 复核现场过滤储液、输送、打塞封盖和整线节拍。报价应列明主机、真空与供液系统、瓶型件、防护、电控和备件；交付、安装调试、质保及售后以合同为准。
