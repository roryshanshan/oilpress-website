# 自动开箱、纸箱成型、装箱机

![自动开箱、纸箱成型、装箱机](/images/filling-products/case-erector-packing-machine.webp)

这类设备用于把平放纸箱坯展开成箱，并按项目配置完成底部折合、胶带或热熔胶封底以及产品装箱。比较厂家报价时必须先分清是单独开箱机、产品装箱机，还是包含两者及输送缓存的组合单元，否则相同名称下的供货范围可能完全不同。

## 适用与不适用边界

- 所属系列：[装箱、码垛](/zh/solutions/packing-palletizing/)
- 参数总览入口：[灌装包装设备参数库](/zh/products/filling-equipment#pack-case)
- 适合箱坯尺寸、压痕和纸板质量可控，产品能够按约定姿态成组进入装箱工位的项目。
- 上游需明确产品分道、排列或抓取方式；下游通常接折盖封箱、称重、码垛和缠膜。
- 软袋、异形瓶、裸瓶或多种混装方案不能只按纸箱尺寸选择，需要单独设计分组和抓取机构。

## 供货范围先拆清

询价时应逐项确认箱坯仓、取箱开箱、底部折盖、胶带或热熔胶封底、产品分组、装箱动作、异常报警和成箱输出。公开资料提到 PLC 与显示屏以及缺胶带、缺纸箱报警，但最终配置应以报价清单和电气方案为准。

## 厂家报价需要的资料

- 箱坯图纸和实物样箱：纸板材质、楞型、压痕方向、尺寸公差、印刷面和底部封合方式。
- 被装产品的尺寸、重量、重心、表面状态、排列数量、入箱方向，以及是否需要隔板或衬垫。
- 目标节拍、箱坯仓补料周期、现场布局、输送标高，以及热熔胶或胶带规格和公用工程。
- 需要包含的分组、抓取、检测剔除、防护、整线信号、换型件与随机备件。

## FAT、SAT 与验收点

FAT 应用具有代表性的箱坯和产品连续运行，检查开箱方正度、封底、装箱排列、卡箱恢复、缺料报警和换型复现。验收节拍必须注明箱规、装箱数量和供料状态。SAT 则验证现场前后段输送、积放、热熔胶或气源条件、安全联锁及成箱进入封箱、码垛工位的稳定性。

## 价格、交付与售后边界

厂家报价应把开箱、装箱、封底、输送、防护和控制接口分别列出，并注明哪些规格包含专用夹具或换型件。出口包装、交付周期、安装调试、培训、胶带切刀、吸盘、密封件或抓具接触件等易损件，及质保、远程支持、现场服务和差旅责任，以书面合同为准。
