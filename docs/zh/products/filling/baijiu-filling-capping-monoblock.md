# 白酒灌装二联机

![白酒灌装二联机](/images/filling-products/baijiu-filling-capping-monoblock.webp)

白酒灌装二联机把量杯定量灌装与封盖布置在同一联动设备内，主要面向不含气白酒及经样品确认的相近流动性液体。联体结构可减少灌装瓶在两台单机之间的转接，但型号选择仍取决于酒液、瓶型、盖型、灌装量和整线持续节拍。

## 适用与不适用边界

- 所属系列：[灌装包装联体机与整线方案](/zh/solutions/filling-packages)
- 参数总览入口：[灌装包装设备参数库](/zh/products/filling-equipment#fp-baijiu-dual)
- 适合采用兼容量杯定量灌装、瓶型规则且盖型能够配置相应封盖头的不含气液体项目。
- 上游通常接空瓶整理、冲洗或吹瓶，后段可接灯检、贴标、装箱和码垛。
- 含气饮料、明显高黏度或颗粒物料、易挥发产品及特殊防爆环境，不能根据“白酒二联机”名称直接套用，应单独评估灌装原理和安全要求。

## 采购判断

GF24-6 至 GF60-15 的头数组合和公开产量用于初筛。厂家选型应以实际瓶型、灌装量和持续运行要求为准，并写明封盖动作、供盖范围和每种规格的换型件，而不是只按最大瓶数比较价格。

## 获取厂家报价需要提供

- 酒液或其他物料名称、密度、温度、酒精度、起泡情况、灌装量范围和接液材质要求。
- 每种瓶和盖的图纸、量产样品、公差，以及目标灌装量、允许偏差和封盖验收方法。
- 目标节拍、班次、输送高度与方向、现场平面、电源、气源，以及上游冲瓶和下游贴标装箱配置。
- 是否包含理盖、上盖、缺盖检测、液位或重量检查、整线控制接口和换型件。

## FAT、SAT 与验收点

FAT 应用代表性酒液或书面认可的替代液、样瓶和样盖连续运行，按约定抽样方式核对灌装量、漏液、封盖外观或开启指标、无瓶动作、卡瓶恢复和换型复现。SAT 在现场确认公用工程、输送接口、前后设备联机和实际包装材料下的持续节拍。公开产量不能替代双方签署的测试条件与合格限值。

## 价格、交付和售后书面范围

厂家报价应列明具体 GF 型号、灌装和封盖头数、接液件、供盖系统、瓶型件、防护、电控接口及备件，避免把裸机价格与完整二联机工位比较。出口包装、交付周期、安装调试、培训、质保期限及起算点、易损件、远程支持、现场服务费和差旅，以报价单和合同为准。
