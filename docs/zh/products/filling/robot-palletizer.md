# 机器人码垛机

![机器人码垛机](/images/filling-products/robot-palletizer.webp)

机器人码垛单元按既定垛型把纸箱、袋装、罐箱或其他约定包装搬运到托盘上。机器人本体只是系统的一部分，抓具、来料整理、空托盘供应、满托盘输出、安全围栏和控制逻辑共同决定项目价格与可用性。

## 机型定位

- 所属系列：[装箱、码垛](/zh/solutions/packing-palletizing/)
- 参数总览入口：[灌装包装设备参数库](/zh/products/filling-equipment#pack-robot)
- 适用场景：适合中大型出货场景自动码垛。

## 公开资料摘要

本机适用于化工、饮料、食品、酒类等生产企业对纸箱、袋装、罐装、盒装、瓶装等各种形状的成品进行装箱和码垛。

## 公开要点

- **选型依据**：选型前需确认包装物尺寸、重量、表面状态、托盘规格、码垛垛型及目标线速，再确定机器人、抓具和输送配置。
- **布局与控制**：设备占地、安全防护、输送接口、公用工程以及触摸屏和PLC功能，应结合现场布局与报价配置确认。
- **供料与栈板**：公开配置采用受控供箱方式，并配置可容纳12-15个空栈板的栈板库；实际容量、兼容托盘尺寸和可用垛型以选定配置及验收文件为准。
- **运行与用工核算**：可实现的运行时长、岗位调整和年度人工成本变化，取决于班次、上下游开机率、换产、维护计划及当地用工成本；未完成项目测算前，不预设全天候可用率或固定年度节省金额。
- **验收依据**：工厂或现场验收应使用有代表性的包装物和约定垛型，并将节拍、码放稳定性、故障恢复、栈板供应及安全联锁列入验收指标。
- **服务边界**：维护通道、备件、安装调试、培训和售后支持，以报价单和合同明确的供货及服务范围为准。

## 获取厂家报价需要提供

- 每种包装的样品或图纸、重量范围、重心、表面摩擦和允许夹持或吸附的位置。
- 托盘尺寸与质量标准、每层排列、层数、隔板、最大垛高、允许悬边及成品垛搬运方式。
- 上游实际节拍、来料方向和姿态、积放空间、现场平面与净高，以及满托盘下线方向。
- 安全区域、护栏门、急停、与输送线或仓储系统的信号接口，以及需要演示的故障恢复场景。

## FAT、SAT 与采购验收

FAT 应按约定包装、托盘和全部主要垛型连续验证抓取、层型切换、空托盘补给、满垛输出、停机恢复和安全联锁。节拍验收要包含来料整理和托盘交换时间，不能只计算机器人单次动作。SAT 在现场复核地面承载、围栏范围、输送接口、叉车通道和与前后工序的联动。

## 价格、交付和售后书面范围

比较厂家报价时，应确认机器人品牌与型号、抓具、托盘仓、输送机、隔板处理、防护、电控、安装底座和程序范围是否一致。出口包装、交付周期、现场安装调试、操作与维护培训、吸盘或夹持件等备件、质保、远程诊断、工程师到场费用和差旅责任，均以报价和合同为准。
