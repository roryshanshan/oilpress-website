# GDP36DK-10-10 全自动智能型灌装扣盖封口联体机

![GDP36DK-10-10 全自动智能型灌装扣盖封口联体机](/images/filling-products/gdp36dk-filling-capping-sealing-monoblock.webp)

GDP 系列联体机把定量灌装、扣盖或上盖以及约定的封口动作集中在一段设备中。型号代码反映公开头数组合，但不能替代对液体、瓶型、盖型和封口原理的确认；尤其是 GDP36-10 与 GDP36-10-10，报价中应写清两段或三段功能的实际配置。

## 适用与不适用边界

- 所属系列：[灌装包装联体机与整线方案](/zh/solutions/filling-packages)
- 参数总览入口：[灌装包装设备参数库](/zh/products/filling-equipment#fp-gdp36dk)
- 适合公开瓶型和容量范围内，并能通过样品确认定量灌装、盖体定位及封口结果的不含气液体项目。
- 上游可接空瓶整理或冲洗，下游可接灯检、贴标、喷码、装箱和码垛。
- 含气、高黏、含颗粒、腐蚀性物料以及特殊防爆或洁净项目，需要重新评估灌装与材料方案，不能因设备名称含“智能型”而默认适用。

## 采购时先确认功能定义

报价应逐项说明液体如何计量、瓶盖如何整理和扣放、封口采用何种动作，以及缺瓶、缺盖、歪盖和异常停机如何处理。不能用“全自动”“智能型”替代传感器、执行机构、检测范围和人工上料责任的具体清单。

## 厂家报价需要的输入

- 物料名称、密度、黏度、温度、起泡情况、灌装量范围和接液材质要求。
- 每种瓶盖组合的图纸、量产样品、公差，以及灌装、扣盖和封口的合格限值。
- 各规格目标节拍、输送标高、现场布局、电源气源、上游供瓶和下游包装设备。
- 理盖、上盖、检测剔除、换型件、防护、整线控制、FAT 样品和现场调试是否计入价格。

## FAT、SAT 与采购验收

FAT 应用代表性液体或认可替代液和全部主要包装规格，连续验证灌装抽样、盖体定位、封口结果、卡瓶恢复、联锁和换型复现。参数表中的公开精度与产量须结合对应测试容量、瓶型和运行条件使用。SAT 则验证现场供液、输送接口、上下游信号和实际班次所需的持续节拍。

厂家报价需列明主机、各功能头、供盖系统、接液件、瓶型件、防护、电控和备件。出口包装、交期、安装调试、培训、质保、易损件、远程支持、现场服务费及差旅，以书面合同为准。
