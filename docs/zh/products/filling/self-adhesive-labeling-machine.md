# 全自动不干胶贴标机

![全自动不干胶贴标机](/images/filling-products/self-adhesive-labeling-machine.webp)

TD-5、TD-6 立式不干胶贴标机用于连续输送中的兼容圆瓶标签贴附。瓶体圆度、贴标面、标签底纸和产品间距会共同影响出标与压标，因此公开瓶径和速度只用于型号初筛，最终配置应由实际瓶签试验确定。

## 适用与不适用边界

- 所属系列：[贴标机系列](/zh/solutions/labeling/)
- 参数总览入口：[灌装包装设备参数库](/zh/products/filling-equipment#label-adhesive)
- 适合具有稳定圆柱贴标面的瓶体，可按项目实现局部环绕或整周贴标。
- 上游需完成吹干并稳定分瓶，下游可接日期打码、标签检查和装箱。
- 方瓶、椭圆瓶、锥形瓶、湿瓶、软瓶或需要图案定向的项目，应增加相应机构并经试贴确认。

## TD-5 与 TD-6 如何比较

不要只按公开速度选择。应同时核对标签最大高度、气源、电源、输送节拍、瓶体稳定性和预留空间，并确认日期打码、缺标检测、剔除和上下游控制接口是否属于报价配置。

## 厂家报价需要的资料

- 每种瓶型样品、直径与高度公差、贴标面长度、材质、表面干燥和清洁状态。
- 标签卷样品：标签与底纸尺寸、卷芯、卷向、间距、透明或印刷定位标记。
- 目标节拍、瓶间距、输送高度和方向，以及上游吹干、下游打码装箱的接口。
- 贴标位置、偏斜、起皱、气泡、搭接或留缝的验收限值和抽样方法。

## FAT、SAT 与采购边界

FAT 应覆盖最小、最大和主要瓶签规格，连续检查分瓶、出标、压标、停机恢复和换型复现。SAT 在现场验证输送速度、瓶体表面、传感器触发及与打码或检测设备的联机。公开速度不应脱离对应瓶签尺寸和供料状态作为合同节拍。

报价应列明贴标头、输送、分瓶、打码或检测选项、换型件、防护和备件。交付、出口包装、安装调试、培训、压标带或剥标件等易损件、质保起算点、远程支持和现场服务费用以合同为准。
