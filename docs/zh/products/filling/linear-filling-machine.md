# 直线式灌装机

![直线式灌装机](/images/filling-products/linear-filling-machine.webp)

ZGP 直线式灌装机面向公开 10-25 L 容量段的中大容器定量灌装。大包装项目需要同时考虑液体流量、容器承托、灌装嘴行程和满桶输送，因此同一头数在 10 L 与 25 L、低黏与高黏液体下的实际节拍不会相同。

## 适用与不适用边界

- 所属系列：[灌装机系列](/zh/solutions/filling/)
- 参数总览入口：[灌装包装设备参数库](/zh/products/filling-equipment#fill-linear)
- 适合容器能稳定定位、瓶口或桶口与灌装嘴匹配，并经样液确认计量方式的 10-25 L 项目。
- 上游可人工或输送供桶，下游需规划压盖或旋盖、重量复检、贴标和满桶搬运。
- 强腐蚀、易燃挥发、高泡或含颗粒物料，需要专项接液、防护或防爆配置，不应只按公开大桶参数选型。

## 公开资料摘要

- 公开机型覆盖 `ZGP-4 / ZGP-6 / ZGP-8 / ZGP-10`
- 灌装范围 `10-25 L`
- 参考精度 `≤0.2%`

## 型号采购判断

- `ZGP-4 / ZGP-6 / ZGP-8 / ZGP-10`可按灌装位数量和公开 10 L 参考产量进行初筛。
- 采购型号应按实际容量、液温黏度、灌装阶段、满桶输送和下游封盖节拍核算，不能把 10 L 产量直接用于 25 L。

## 获取厂家报价需要提供

- 液体密度、黏度、温度、起泡、接液材料及清洗或换产方式。
- 容器样品、桶口、空桶和满桶重量、灌装范围、目标偏差与允许滴漏标准。
- 每种容量的持续节拍、人工或自动供桶方式、输送高度、封盖和重量复检配置。
- 灌装嘴或下潜要求、气源电源、现场布局、防护、换型件和备件需求。

## FAT、SAT 与采购验收

FAT 应按实际容量分别验证计量、快慢速灌装切换、桶口定位、滴漏、满桶出料和连续节拍，测量方法和样本数量写入协议。SAT 需在现场供液压力、输送和封盖设备就绪后复核。公开精度与产量均需结合测试液、容量和环境条件使用。

## 价格、交付和售后范围

厂家报价应列明具体 ZGP 型号、计量与阀组、灌装嘴、输送、定位、检测、防护和备件。出口包装、交期、安装调试、校准培训、质保、密封或阀件易损件、远程支持和现场服务费用，以合同为准。
