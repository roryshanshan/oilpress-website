# 葡萄酒冲瓶灌装打塞联体机

![葡萄酒冲瓶灌装打塞联体机](/images/filling-products/wine-rinsing-filling-corking-monoblock.webp)

葡萄酒冲瓶、灌装、打塞联体机在同一平台上完成玻璃瓶冲洗、低真空灌装和软木塞插入，适合希望减少三段中间转运的酒类包装项目。是否适用仍取决于冲洗规范、酒液起泡、瓶口和软木塞组合，不能只按公开产量采购。

## 适用与不适用边界

- 所属系列：[酿酒设备系列](/zh/solutions/brewing/)
- 参数总览入口：[灌装包装设备参数库](/zh/products/filling-equipment#brew-triple)
- 适合可按约定方式翻转或夹持冲洗、采用低真空灌装并使用软木塞的葡萄酒或经试验确认的果酒玻璃瓶。
- 上游通常连接空瓶输送和过滤储液系统，下游接液位或异物检查、缩帽、贴标、装箱和码垛。
- 含气酒、螺纹盖包装、不能倒置的瓶型或含明显颗粒的物料，不属于默认适用范围。

## 三段工艺的确认重点

- **冲瓶**：冲洗介质、接触时间、排水或回收、瓶夹接触位置和瓶内残液标准。
- **低真空灌装**：酒液温度、起泡、目标液位或灌装量、回液和清洗方式。
- **打塞**：瓶口内径、公差、塞径与长度、压缩和插入深度，以及瓶口和塞体损伤限值。

## 获取厂家报价需要提供

- 酒液数据、冲洗和清洗要求、瓶与软木塞样品及全部规格公差。
- 目标液位或容量、允许偏差、软木塞插入深度和密封或保持验收方法。
- 每种规格目标节拍、输送高度与方向、公用工程、场地尺寸和下游缩帽贴标配置。
- 是否包含水处理或回收接口、供塞、检测、换型件、防护、备件及整线电控。

## FAT、SAT 与合同范围

FAT 应以代表性样品连续检查冲洗和排水、灌装液位、滴漏、供塞与打塞、瓶体损伤、卡瓶恢复和换型复现。SAT 在真实水源、酒液供给和上下游设备就绪后，确认接口与联机节拍。抽样数量、测试介质、运行时间和合格限值应写入技术协议。

比较价格时需核对三段头数组合、接液材质、瓶夹、灌装阀、供塞和打塞头、检测、防护及备件是否一致。出口包装、交付、安装调试、培训、质保、易损件、远程支持和现场服务费用均以书面报价和合同为准。
