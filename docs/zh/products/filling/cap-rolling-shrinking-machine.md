# 碾帽/收缩两用机

![碾帽/收缩两用机](/images/filling-products/cap-rolling-shrinking-machine.webp)

这不是单头或多头热缩机的同名版本。该机型的采购边界是“碾帽 + 收缩”两项瓶口处理：公开资料明确其适用于 PVC 热缩胶帽，并兼顾收缩与瓶口外观处理，但没有公布碾帽机构形式、专用产能或两项功能的运行组合。询价时应让厂家把碾帽组件、热缩组件及各自的换型范围分项确认。

## 碾帽与缩帽的结构边界

- **双功能定位：**碾帽用于公开资料所述的瓶口外观处理，热缩用于打塞后 PVC 胶帽的收缩；不要把本页理解为只有热缩头数不同的 RS 机型。
- **工序接口：**常见项目位置是打塞和胶帽放置之后、贴标之前。公开页没有说明胶帽由人工、独立上帽机还是本机放置，因此报价不得默认包含上帽功能。
- **系列参数边界：**下表保留 RS-1 与 RS-6 的系列对照，用于核对瓶型和胶帽范围；它没有给出碾帽组件的独立参数，也不能单独证明两用机在任一工况下的产量。
- **热源边界：**公开页没有把蒸汽、电热或热风中的任何一种写成标准配置。厂家报价应注明实际供货的加热方式、现场公用工程要求和控制范围，未写入报价的热源方式不应按标配理解。
- **上下游衔接：**软木塞项目应与[打塞机系列](/zh/solutions/corking/)核对出瓶节拍和输送接口；后续进入[贴标机系列](/zh/solutions/labeling/)时，应确认交接节拍与瓶体通过条件。两用机本身不等于包含打塞或贴标设备。

## 双功能机报价资料与换型件

申请设备价格或厂家报价时，建议提交计划使用的样瓶、样帽或尺寸图，注明瓶高、瓶径、瓶口与胶帽尺寸、胶帽材质、目标节拍及期望的瓶口外观。尺寸落在公开范围内不等于无需换型，也不代表未经样品测试即可确认效果。

报价单应分别列明基础机、碾帽部分、热缩部分、瓶帽换型件、胶帽放置或供帽范围、输送与联机控制、随机备件、包装，以及 FAT/SAT。安装、调试、培训和售后响应方式只按书面供货范围判断；采购方不应从“厂家报价”一词推定这些服务全部包含。

两用机的换型清单尤其要区分碾帽与热缩所需部件，并写明每种样瓶样帽对应的调整项。若蒸汽、电热、热风或其他加热方案可选，也应以最终技术协议中的实际配置为准，不根据名称猜测工作原理。

## 样瓶样帽与 FAT/SAT 验收

- **FAT 前：**双方确认代表性样瓶样帽、合同功能模式、测试节拍、连续测试条件、外观判定样和不合格处理方式。
- **FAT 中：**按合同约定分别核对碾帽、收缩或组合模式，记录瓶体输送、胶帽位置、换型步骤、成品外观以及已购联机信号；只验收报价中包含的功能。
- **SAT 中：**在现场实际热源与上下游设备条件下复核接口、节拍和换型。表格中的公开数值只有被写入合同与验收协议后，才构成项目验收条件。
