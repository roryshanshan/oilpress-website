# 干法花生脱红衣机（200 kg/h）

![干法花生脱红衣机，不锈钢料斗和风机](/images/peanut-peeling/dry-peanut-peeling-machine.webp)

干法脱皮机用柔性橡胶辊搓掉熟花生（烘烤或油炸）的红衣，再由风机吹走。不用浸泡、不用水煮，脱完的花生米保持干燥，直接进入磨酱、油炸或切碎工序。在花生酱生产线里，它位于炒锅和磨酱机之间。

## 工作原理

![两台烤漆机架款，可见搓皮辊床](/images/peanut-peeling/dry-peanut-peeling-machine-painted-frame.webp)

- **搓皮：**花生米从料斗落到柔性橡胶辊床上，橡胶辊把烤脆的红衣搓松而不压碎花生米，间隙可按颗粒大小调节。
- **分离：**风机把搓下的红衣吸走吹入收集袋，脱皮后的花生米从出料口流出，不用人工筛皮。
- **一人操作：**开电机和风机，倒料，红衣袋满了更换即可。

## 下单前确认

- **先烘烤。**这是干法脱皮机，只适用于熟花生。生花生需要湿法（浸泡）脱皮机。
- **温料入机，不要烫料。**刚出锅的花生发软易碎，先在冷却盘上晾一下。
- **做酱和食品才脱皮，榨油不用。**榨油不需要脱红衣；花生酱、花生酥、油炸花生、花生碎、花生乳才需要。
- **和磨酱机匹配。**200 kg/h 约是一台 50 kg/h 磨酱机的四倍，一台脱皮机可以供好几台磨酱机。
