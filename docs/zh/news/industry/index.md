# 食用油市场、法规与采购研判

本栏目用于检查榨油机或食用油生产线项目背后的关键假设。市场增长不等于当地订单，设备报价不等于完整投资，政策摘要也不代表某个场地已经获得批准。真正可用于采购的成果，应是一份带来源和日期的证据档案，把需求、原料、合规、工艺范围和成本连接到具体项目。

## 分四轮建立项目决策资料

### 第一轮：明确产品与市场问题

写清油料、成品油等级、包装规格、目标客户、销售区域和证据时间段。油料产量、毛油产量、精炼油消费、进口数量、零售金额和设备需求属于不同口径，不能相互替代。引用数据时，应保存原发布方、表格或文件、发布日期、单位、币种、地区、产品定义、统计方法和修订状态。

### 第二轮：在项目所在地核验原料与需求

将公共数据与实际原料供应商的报价或合同、季节性、仓储条件、样品质量、运输距离和付款条件交叉核对。需求侧优先收集目标买方的质量规格、包装要求、渠道条件和可核验的采购意向。商业测算采用高、中、低情景，不把单一预测直接作为开工率或销量保证。

### 第三轮：先查法规，再锁定设备规格

确认项目所在地负责企业登记、食品安全、产品标准、标签、环保、废水和固废、电气安装、消防、安全生产、海关和税务的主管部门。以现行正式文件和当地解释为准，记录生效日期、适用地区、强制条款、申请主体、审批周期和合规证据。涉及压力、起重或其他特种设备时，再按当地规则单独核验。

### 第四轮：把结论转成询价书和风险台账

将产品与法规要求转换为接触材质、清洗方式、工艺温度、过滤目标、控制、电气标准、技术文件、包装、现场工程和验收项目。每个尚未确认的假设都应写明责任人、截止时间、核验方法和对价格或交付的影响。

## 比较完整项目预算

| 预算模块 | 应收集的证据 | 常见采购风险 |
| --- | --- | --- |
| 原料与流动资金 | 供应报价、季节性、质量范围、仓储损耗假设、付款条件和最小采购量 | 使用与实际采购季节或质量不符的年均价格 |
| 工艺设备 | 分项设备表、选配、工装、控制、公用工程、备件、耗材和排除项 | 把单台榨油机价格与整线价格直接比较 |
| 场地与合规 | 平面布置、土建、电力、给排水、通风、消防、环保、化验和许可要求 | 订购后才发现强制性的现场工程 |
| 物流与进口 | 包装、内陆运输、运费基础、保险、关税、税费、港杂、清关文件和本地运输 | 把出厂价或FOB价当成落地总成本 |
| 启动与支持 | 安装边界、调试条件、培训、试料、差旅、住宿、翻译、质保文字和配件路径 | 默认合同中未写明的服务内容或费用 |

## 下单前的采购风险门槛

1. **来源门槛：** 重要市场和政策判断都有可追溯的一手来源与日期。
2. **试料门槛：** 采用代表性原料和书面试验方法核验拟定工艺。
3. **范围门槛：** 各厂家按相同设备边界、选配、公用工程、文件和交付基础报价。
4. **验收门槛：** FAT与SAT步骤、公差、仪器、责任和失败处理已经约定。
5. **交付门槛：** 里程碑、包装、文件、贸易术语、发货放行、安装前提和延期处理已书面化。
6. **售后门槛：** 质保文字、排除项、远程支持、现场条件、配件供应和联系路径对应本订单。

::: tip 把核验结果变成厂家询价资料
