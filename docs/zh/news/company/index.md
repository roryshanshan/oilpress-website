# 榨油机厂家与工厂核验

本栏目帮助采购方判断合同主体、设备配置、制造过程和交付计划是否相互对应。这里不把展会成果、客户数量、厂区规模、认证或服务年限作为既定事实；每一项内容都是针对拟采购设备应索取和复核的证据。

## 按采购阶段推进核验

### 1. 联系或预约验厂前

先明确买卖双方主体、目标机型或生产线范围、原料、目的地、文件语言和验厂方式。询问哪一主体负责出具报价、签订合同、收款、制造和出口申报；如主体不同，应在商务评审前说明各自责任及文件关系。

### 2. 展会看机后

使用[展会设备核验清单](/zh/news/company/2023-exhibition)记录展示设备的铭牌、配置、控制、工装、附件和运行状态，再索取本次拟购型号的当前规格与报价。展示机与销售配置可能不同，应逐项列出差异，不能只依赖照片或口头介绍。

### 3. 现场或远程验厂时

按照[工厂验机指南](/zh/news/company/new-factory)，从图纸和采购件开始，追踪机加工、焊接、液压与电气装配、测试、防护、包装和发运文件。远程验厂应提前约定订单或设备编号、镜头顺序、测试步骤、测量工具及会后交付的记录文件。

### 4. 发货及尾款节点前

将完工设备与签署的配置表、批准图纸、电气标准、附件表、备件表、标识、说明书和装箱单逐项对应。未关闭的问题应写明整改内容、责任人、完成证据以及是否影响付款或放行发货。

## 各阶段应索取的制造与交付证据

| 阶段 | 建议核对的资料 | 支持的采购判断 |
| --- | --- | --- |
| 供应商资格 | 法律主体、报价方、合同方、收款账户、制造地址和出口文件责任 | 商务与交付主体是否清晰一致 |
| 技术评审 | 型号资料、配置表、图纸、约定的材质或部件要求、公用工程和排除项 | 各家报价是否覆盖相同设备边界 |
| 样品试料 | 样品标识、前处理、运行设置、完整周期、测量结果、仪器、留样和签字记录 | 工艺路线是否在明确条件下得到验证 |
| 制造跟进 | 订单对应图纸、生产节点、部件清单、检验记录和带日期的进度证据 | 进度证据是否属于所购设备 |
| 工厂验收与包装 | 书面测试方案、验收公差、结果、不合格项关闭证据、装箱单、防护和唛头 | 是否达到合同约定的发货条件 |
| 交付与售后 | 发运文件、说明书、安装边界、调试前提、培训、质保文字、备件和联系路径 | 到货后的责任、费用和支持方式是否明确 |

## 工厂验收测试需要提前问清

- 被测试设备的编号和配置是否与订单一致？
- 使用什么原料、数量、含水、前处理方法和测试时长？
- 安全、液压、电气、控制、噪声、泄漏、温度、周期和油品质量分别检查什么？
- 样品、公用工程、测量仪器、操作人员、耗材和测试备件由谁提供？
- 验收公差是什么，失败项如何整改，由什么证据关闭？
- 哪些文件应在包装前和发货前批准？

## 准备报价与合同资料

请提供原料及样品情况、目标油品和工艺路线、计划工时、现场电压与公用工程、整线设备范围、灌装或包装边界、目的地、贸易术语、所需文件和验收测试。要求厂家分别列出主机、选配、工装、前处理、过滤、包装、运输、安装、调试、培训、备件和耗材的价格及交期前提。

售后条款应写明联系路径、远程支持范围、现场服务条件、差旅和当地费用、响应流程、配件供应方式、质保起点、排除项及具有约束力的合同文件。不能从网站上的一般说明推定具体订单的售后责任。
