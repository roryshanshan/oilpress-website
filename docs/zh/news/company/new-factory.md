# 液压榨油机工厂验机清单

*发布时间：2023年3月20日*
*分类：公司动态*

本页用于采购方评估生产场所。厂房面积、设备数量、月产能、自动化比例、合格率、节能、收入、就业和扩建目标，均不应在缺少当前记录和明确计算口径时采信。

## 参观前索取

- 当前营业执照、工厂地址、签约主体、收款主体和出口主体
- 分项报价、型号清单、总图、公用工程清单和初步物料清单
- 拟议检验测试计划、样品试料流程和工厂验收标准
- 方案引用的证书或资格文件副本
- 交付计划、包装方式、目的地电压与频率、贸易术语和售后范围草案

## 应检查的制造范围

### 材料与制造
- 钢材和零部件标识、储存、约定的材质证明及进料检验记录
- 下料、机加工、机架制作、焊接工艺、适用的热处理和尺寸检查
- 外协工序和外购总成的控制方式

### 液压与电气装配
- 油缸、泵、阀、软管或管路、压力仪表、液压油规格、清洁度和泄漏控制
- 电机、电控柜、接线、接地、传感器、报警、联锁、急停和目的地电气标准
- 零部件品牌及型号与已批准物料清单一致

### 总装、测试与包装
- 对照已批准图纸和报价核对设备配置
- 铭牌、防护、说明书、电气与液压图、备件、工具和标签
- 测试仪器标识及校准状态
- 出口包装、防潮、吊点、装箱单和装柜计划

## 核验产能与交期

不能从厂房面积、设备数量或增长比例推定制造能力。应索取与订单相关的证据：

- 隐去客户机密信息的当前排产
- 同类型号带日期的完工与发运记录
- 机加工、焊接、液压装配、电气装配、测试和包装的瓶颈说明
- 关键外购件可用性及实际供应周期
- 写入合同的开工、验货、整改、包装和发运日期

## 工厂验收测试

FAT 应覆盖所购配置和约定风险：

1. 核对型号、尺寸、材质、零部件、附件、电压和文件。
2. 空载运行并检查噪声、振动、油温、泄漏、控制和报警。
3. 记录液压压力、保压时间、溢流设定、回程顺序和安全功能。
4. 测试联锁、急停、防护和手动后备操作。
5. 出油、处理量、饼状态、油品质量或脱水结果影响验收时，进行代表性样品试料。
6. 记录偏差、整改、复测、签字、包装放行和留存证据。

## 证书与文件核对

如引用 ISO 9001、ISO 14001、CE、专利、绿色工厂或其他资格，应索取载有持有人、编号、颁发机构、范围、覆盖场所或产品及有效期的文件，并向颁发机构或官方数据库核验。管理体系证书不能证明所购设备的具体性能。

## 出口项目文件包

明确商业发票、装箱单、HS 编码、合同包含时的原产地证、目的地要求的检验证书、适用时的欧盟符合性声明或目的地文件、说明书、图纸、目的地语言标签、保险、运费、清关和安装记录由哪一方负责。

## 预约验厂与报价

请提供原料、代表性样品、目标产品、计划工时、产线范围、现场公用工程、目的地、验收测试、包装和所需文件。
