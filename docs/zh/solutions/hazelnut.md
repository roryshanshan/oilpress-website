# 榛子油压榨方案

榛子油设备按脱壳后的可用核仁选型。带壳重量、壳比例、碎仁和分选剔除量都会改变实际进料；目标产品也决定试料使用生核仁还是另设烘烤配方。

![榛子核仁低温压榨工艺参考](/images/an-overview-of-the-cold-pressing-process-of-hazeln-98e165898b.webp)

## 原料与产能口径

请注明带壳榛子或核仁、品种、产地、壳比例、含水状态和储存记录，并剔除霉变、虫蛀、焦糊、变色或酸败核仁。盐焗、调味或已烘烤零食料属于另一进料规格，需要单独做污染与清洁评估。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 压榨进料 | 清洁生核仁或明确配方的烘烤核仁 |
| 产能基准 | 可用核仁，不以带壳重量核算 |
| 产品路线 | 低温轻味油，或独立的轻烘烤风味油 |
| 选型依据 | 装料密度、批次重量、周期、出饼和净滤油 |
| 供货边界 | 破壳、分选、粉碎、压榨、过滤、储罐和灌装 |

## 推荐前处理

1. 破壳并避免尖锐壳片进入粉碎机。
2. 分选、清理核仁，按需要配置金属检测。
3. 实测含水状态，仅在需要时缓和干燥或调质。
4. 每批装料前均匀破碎。
5. 烘烤与未烘烤试料分别处理。

## 压榨路线与配置边界

轻味食品或化妆品油可先评估液压批次低温压榨；需要更强坚果香时，可另做轻烘烤试料。机型应依据样品堆积状态、装料、周期、出饼和净滤油记录确定。

## 过滤与成品油目标

应确认沉降或精滤、取样时间、可见沉淀、澄清度、色泽、坚果香和氧化相关检测。储罐和包装需符合约定的避光、控氧及批次间残油清除要求。

## 报价所需资料

- 带壳或核仁样品、壳比例、含水状态、剔除比例、储存时间和异味情况
- 每批或每日可用核仁投入、班次及破壳/分选范围
- 低温或烘烤风味目标及食品/化妆品用途
- 过滤等级、储罐、包装和油品检测要求
- 电源、场地、卫生要求、目的地和交货条款

## FAT/SAT 与书面验收

记录批准批次、去壳和剔除重量、核仁含水状态、破碎粒度、装料量、周期、油温、毛油、净滤油和饼粕。FAT 应写明带料批次数和取样时间；SAT 如实施，应核对沉降/过滤后的澄清度、色泽、坚果香、焦糊或酸败气味、产品残留和清洗结果。
