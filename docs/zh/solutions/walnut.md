# 核桃油压榨方案

核桃油设备按可用核桃仁选型，不按整核桃重量选型。壳比例、深色或酸败核仁，以及脱壳后到压榨的等待时间都会影响可用进料和成品油目标。

![核桃仁低温压榨工艺参考](/images/process-image-647a0e9868.webp)

## 原料与产能口径

请注明整核桃或核桃仁、品种、产地、壳比例、含水状态和储存情况，并剔除霉变、虫蛀、深色、焦糊或酸败核仁。已烘烤或调味核仁属于另一产品规格，需要单独试料和清洁方案。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 压榨进料 | 清洁核桃仁及约定破碎粒度 |
| 产能基准 | 可用核仁，不以带壳重量核算 |
| 产品路线 | 低温轻味油，或独立轻烘烤风味油 |
| 氧化控制 | 脱壳、破碎、压榨、过滤到封罐的时间 |
| 成品目标 | 沉降/精滤、色泽、气味、氧化检测和避光包装 |

## 推荐前处理

1. 破壳并去除硬壳碎片。
2. 按核仁状态分选并去除异物。
3. 实测并均衡含水状态，避免激烈加热。
4. 临近压榨时均匀破碎。
5. 缩短破碎后的等待和开放暴露。

## 压榨路线与配置边界

轻味核桃油可优先做液压批次低温试料；需要更强核桃香时另做温和烘烤对照。机型根据样品堆积状态、装料、周期、出饼和净滤油记录选择。

## 过滤与成品油目标

设定允许沉降时间、过滤等级、可见沉淀、澄清度、色泽、气味和氧化相关检测。需要时配置密闭储罐和避光包装，并规定清除上一批氧化残油的清洁终点。

## 报价所需资料

- 整核桃或核桃仁样品、壳比例、含水状态、深色/受损比例、储存时间和气味
- 每批或每日可用核仁投入、班次及破壳/分选范围
- 低温或轻烘烤目标、用途和油温记录要求
- 沉降、过滤、储罐、包装和取样要求
- 电、场地、卫生方案、目的地和交货条款

## FAT/SAT 与书面验收

记录壳和剔除重量、核仁含水状态、破碎粒度、装料、周期、油温、毛油、净滤油、饼粕及过滤前等待时间，并检查澄清度、色泽、焦糊/酸败气味、密闭储存、产品残留、出饼和清洗。FAT/SAT 的样料批次、过滤时点和留样方法应在合同中先确定。
