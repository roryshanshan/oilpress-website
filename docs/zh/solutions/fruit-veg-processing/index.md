# 果蔬前处理设备

![果蔬前处理生产线](/images/filling-solutions/fruit-veg-processing.webp)

果蔬前处理把到厂原料转换为适合提取、打浆、发酵、热处理或其他后续工艺的稳定进料。设备清单取决于原料到厂时的真实状态，而不只是最终产品名称。

## 在生产线中的位置

项目流程可按需要组合：

**原料接收 → 检查分选 → 清洗 → 修整或破碎 → 输送 → 提取或打浆 → 产品处理 → 灌装**

只应采购经工艺确认确实需要的环节。废水、剔除物、果皮、果核、果渣等副产物如何收集和处理，也要写入项目边界。

## 需要记录的原料条件

- 果蔬品类、品种、成熟度和加工季节
- 来料形态、田间污染和杂物负荷
- 原料尺寸、易损性和允许的机械损伤
- 需要的分选、清洗、修整、破碎或输送步骤
- 水质、循环用水和废水限制
- 后端要求的进料尺寸、温度和连续性
- 清洗、食品接触和当地卫生要求

## 影响报价的采购判断

- 旺季原料量及产量基准
- 人工检查，还是机械分选与输送
- 清洗和前处理工序数量
- 接触材质及清洁检修空间
- 水路、泵、罐、输送和控制范围
- 废物与废水收集是否包含
- 与提取、发酵、巴氏处理或灌装的连接

## 报价资料

请提供原料照片，并在条件允许时提供代表性样品；同时提交来料状态、目标出料、处理量基准、生产季节与班次、工艺流程、公用工程、布局、废弃物方案和目的地。现场已有设备及进出料高度也要标明。

## 验收、交付与售后边界

FAT应使用约定原料或书面认可的替代物，并明确机械损伤、输送稳定性、清洗便利性和接口检查方法。季节原料表现、最终产品质量和副产物得率，只有在合同约定测试方法时才构成承诺。运输、安装、当地水电排水、调试、培训、备件和服务条款必须在商务报价中列明。
