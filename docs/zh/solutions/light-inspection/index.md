# 瓶装液体灯检机系列

![瓶装液体灯检设备实拍](/images/filling-solutions/light-inspection.webp)

灯检机为已灌装容器提供受控的观察或检测位置，可用于检查双方约定的可见异物、液位、瓶体或封口外观。采购时必须明确缺陷清单和检测方式；“灯检机”这个名称本身不代表所有缺陷都会自动识别和剔除。

## 在包装线中的位置

可根据工艺布置在：

- 灌装后、封口前，在安全和卫生条件允许时检查开口产品
- 压盖或封口后，组合检查液位和包装状态
- 贴标前，保留完整瓶壁观察区域
- 装箱前，作为人工或自动检测的最后节点

安装位置会影响照明、瓶体旋转、污染控制和是否需要剔除机构。

## 先定义检测任务

采购文件应写明：

- 物料颜色、透明度和允许的自然差异
- 瓶体材质、颜色、纹路和可观察区域
- 需要检查的缺陷及代表性缺陷样品
- 人工目视、传感器或相机检测方式
- 瓶体是否需要旋转、分距和背景
- 是否包含剔除确认和不合格品收集
- 是否需要数据记录或停机信号

## 影响设备价格的配置

- 观察输送、辅助灯检或自动检测范围
- 瓶体旋转和稳定方式
- 光源、防护罩和操作工位
- 剔除机构、剔除确认和收集区
- 与灌装、封口或贴标设备的控制通信
- 包装规格、项目电制和服务范围

## 报价资料清单

请提供空瓶、合格成品瓶和缺陷参考样品、物料说明、目标产量、检测位置、前后设备、剔除逻辑、数据要求、布局、公用工程和目的地，并标出哪些缺陷属于关键质量项目及其验证责任。

## FAT与售后边界

FAT应按书面挑战方法使用确认后的合格与缺陷样品，记录可见性或识别标准、适用时的误剔除、过瓶、换型和联锁。验证、当地质量批准、安装、差旅、培训、光源或传感器备件和支持条款，必须在报价和合同中明确。
