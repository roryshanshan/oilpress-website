# 玻璃瓶打塞机系列

![全自动打塞机实拍](/images/filling-solutions/corking.webp)

打塞位于灌装之后，为葡萄酒、果酒及其他采用软木塞系统的产品完成主封口。可靠选型取决于瓶口、塞子材质、塞子尺寸和压入方式之间的配合，不能默认同一台设备适配所有瓶塞组合。

## 在生产线中的位置

**灌装 → 理塞供塞 → 压入软木塞 → 封口检查 → 按需胶帽热缩 → 贴标 → 装箱**

联线采购时，打塞机需要与灌装机和后端输送同步；单机采购时，则要单独明确上瓶、定位和操作人员的工作方式。

## 瓶与塞的适配资料

技术确认应包括：

- 玻璃瓶图纸、瓶口公差和瓶体稳定性
- 天然软木塞、合成塞或其他经送样确认的塞体
- 塞子尺寸、存储状态及买方规定的前处理
- 成品压入位置和允许的瓶身痕迹
- 人工上塞、辅助供塞或全自动理塞
- 泄漏测试方法和后续是否套胶帽

## 影响设备价格的采购范围

- 手动、半自动或全自动运行方式
- 理塞、供塞及缺塞检测是否包含
- 瓶型、塞型数量及配套工装
- 输送、分瓶、防护和控制接口
- 与灌装机联动，还是作为独立单机采购
- 工厂试机、出口包装、运输、安装和培训范围

## 报价资料清单

请提供瓶型图与样瓶、塞子规格与样品、目标产量、班次、前端灌装机、后端缩帽或贴标工序、公用工程、布局和目的地，并写明成品打塞状态及拟采用的验收方法。

## FAT、安装与售后

FAT应使用约定瓶塞样品，检查过瓶、供塞、压入一致性、瓶体损伤、卡机、换型和联锁。试机耗材、输送线、安装人工、差旅、当地吊装、调试、培训和推荐备件由哪方承担，必须在报价中逐项说明。质保和响应条款以签署的商务文件为准。
