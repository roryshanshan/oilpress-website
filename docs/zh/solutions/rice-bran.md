# 米糠油加工方案

鲜米糠在碾米后会因自身酶活性快速劣变，项目必须从收集时间和稳定化开始，再选择机械预榨、连续压榨或专用提取路线。直接液压压榨不是米糠商业生产线的默认方案。

![现有稻米类物料压实参考，不等同于米糠完整工艺](/images/cold-pressing-process-of-glutinous-rice-77cef64384.webp)

## 原料与产能口径

请注明稻米类型、碾米工段、鲜米糠或已稳定米糠、稻壳和细粉夹带、含水状态、碾米后停留时间、储存情况及现有游离脂肪酸数据。报价应按稳定化后的米糠核算，或在合同中明确鲜糠基准和稳定化损失。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 接收基准 | 鲜米糠或已稳定米糠及碾米到稳定化时间 |
| 核心前处理 | 快速稳定化、干燥/调质、冷却、筛理和密闭转运 |
| 提油路线 | 预榨、连续机械压榨或专用提取研究 |
| 后处理 | 过滤、脱胶、精炼、脱蜡、储罐和包装 |
| 成品验收 | 游离脂肪酸取样、固形物、蜡和低温/储存澄清度 |

## 推荐前处理

1. 碾米后及时收集和称量米糠。
2. 采用经验证的热处理及时稳定化。
3. 干燥或调质到选定提油状态并冷却。
4. 筛除稻壳、金属和大颗粒污染物。
5. 在受控条件下转运和储存稳定米糠。

## 压榨或专用提取路线

根据稳定米糠分析、处理量、细粉行为、油品目标和项目经济性，在预榨、连续机械压榨或专用提取路线之间选择。液压样品试验可用于观察压实和过滤，但不能作为通用米糠线。毛油通常还需过滤、精炼和脱蜡，才能按约定温度获得稳定澄清的成品。

## 过滤、精炼与脱蜡目标

应明确毛油或精炼油、固形物、游离脂肪酸取样、色泽、气味、除蜡及约定储存或冷却条件下的澄清度。报价逐项标明过滤、脱胶、精炼、脱蜡、储罐和包装，并为合同内每个阶段设置取样点。

## 报价所需资料

- 鲜糠或稳定糠样品、稻米及碾米来源、碾米到稳定化时间、含水状态、稻壳/细粉和游离脂肪酸数据
- 每小时或每日米糠产生量、碾米计划、班次和连续供料条件
- 现有稳定化方式及预榨、机械压榨或专用提取研究要求
- 毛油、精炼油或脱蜡油目标，以及固形物、蜡、澄清度、储存和检测范围
- 蒸汽或热源、电、水、输送、场地、目的地和交货条款

## FAT/SAT 与书面验收

验收记录从米糠接收开始：记录碾米时间、到料时间、含水状态、稳定化温度和停留时间、稳定后状态、进料、毛油和残渣，并在约定取样点记录游离脂肪酸。合同包含过滤、精炼或脱蜡时，应按指定冷却或储存试验评价固形物和澄清度，不能只观察热油。FAT/SAT 的原料责任、连续运行范围和实验室方法应预先书面确定。
