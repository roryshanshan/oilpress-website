# 花生油压榨方案

花生油设备应按清洁花生仁选型，而不是按带壳花生重量选型。采购前还需明确产品路线：低温压榨油、炒制浓香油，或进入后续精炼的毛油。黄曲霉毒素控制始于原料分批、取样和实验室检测，炒制或压榨不能作为去除依据。

![花生液压榨油设备参考](/images/300-325-series.webp)

![液压压榨工作参考](/images/325hydraulic.webp)

## 原料与产能口径

请注明带壳花生或花生仁、品种、壳比例、含水状态、杂质、破损或霉变比例、储存记录和现有黄曲霉毒素报告。可疑批次按采购方取样计划隔离；压榨段产能按分选后的净花生仁核算。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 进料基准 | 清洁花生仁，不含壳和分选剔除物 |
| 产品路线 | 低温、炒制浓香、液压批次、螺旋连续或预榨 |
| 产能依据 | 净仁投入、装料/进料、完整周期、过滤和清洗时间 |
| 成品目标 | 沉降/过滤、色泽、自然或炒香、焦糊味及检测 |
| 供货边界 | 脱壳、分选、破碎、蒸炒、压榨、过滤、饼粕和灌装 |

## 推荐前处理

1. 脱壳并分离壳、石块、金属和异物。
2. 剔除霉变、虫蛀、变色或酸败花生仁。
3. 实测并均衡含水状态。
4. 将花生仁破碎、轧片或制成一致粒度。
5. 浓香路线按记录配方炒制或蒸炒；低温路线独立备料。

![花生油工艺流程参考](/images/Peanut-oil-process-flow.webp)

## 压榨路线与配置边界

液压批次压榨适合配方明确的炒香油和特色批次产品。连续商业处理量应比较螺旋压榨或预榨路线。两种路线应使用同一批准批次，记录净仁投入、油、饼、过滤负荷、风味和总运行时间。

## 过滤与成品油目标

应明确沉降油或过滤油、可见沉淀、澄清度、色泽、自然香或炒香、焦糊气味以及是否包含精炼。取样时间、储罐、包装和实验室检测应与压榨设备验收分开列示。

## 报价所需资料

- 带壳或花生仁样品、壳比例、含水状态、杂质、破损/霉变比例、储存情况和黄曲霉毒素报告
- 每批、每小时或每日净花生仁投入、班次、季节和仓储计划
- 低温、炒香、液压批次、螺旋连续或预榨路线
- 沉降、过滤、精炼、储罐、包装、饼粕、取样和检测范围
- 热源、电源、场地、目的地和交货条款

## FAT/SAT 与书面验收

验收应关联批准的花生批次及其检测报告，并记录脱壳和分选损失、花生仁含水状态、破碎/轧片、炒制或蒸炒曲线、装料/进料、周期、油温、毛油、净滤油和饼粕。FAT 应写明试料批次、过滤终点和连续运行范围；SAT 如实施，应核对现场热源、公用工程、清洗、出饼和约定节拍。污染物验收仍以实验室结果为准。
