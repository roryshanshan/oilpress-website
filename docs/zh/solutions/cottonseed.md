# 棉籽油加工方案

原棉籽带有短绒和较高壳比例。食用油项目通常需要清理、脱绒、脱壳、制片、蒸炒调质、压榨或提取、过滤、精炼和成品检测，不能把直接冷榨写成完整棉籽油路线。

![棉籽提油前处理参考](/images/process-image-c32ca90dab.webp)

## 原料与产能口径

请区分毛棉籽、脱绒棉籽、脱壳仁或其他已制备物料，并记录短绒和壳比例、含水状态、杂质、储存情况、现有油脂分析以及油和粕的用途。毛棉籽油经过压榨或过滤，并不自动成为可食用成品油。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 进料状态 | 毛籽、脱绒籽或棉仁，分别核算 |
| 前处理 | 清理、脱绒、脱壳、制片和热湿调质 |
| 提油路线 | 连续螺旋、预榨或专用提取；液压仅用于制备料试验 |
| 成品范围 | 过滤毛油，或含脱胶、脱酸、脱色、脱臭的精炼油 |
| 合规与副产物 | 棉酚等检测、棉籽粕/饼用途和处置边界 |

## 推荐前处理

1. 清理石块、金属和异物。
2. 接收毛籽时配置脱绒。
3. 脱壳并按约定控制壳仁分离程度。
4. 将棉仁破碎或制片。
5. 为选定提油路线进行蒸炒或热湿调质。

## 压榨或专用路线

商业项目应根据处理量、油品目标和粕价值比较连续螺旋压榨、预榨或专用提取路线。液压批次试料可用于了解已制备棉仁的压实与过滤特性，但不是默认完整工艺。毛油需进入与适用成品标准相匹配的固形物去除和精炼环节。

## 过滤、精炼与成品目标

采购规格应区分过滤毛油和精炼食用油，并列出固形物、色泽、气味、水分、取样点及适用产品标准要求的棉酚检测。脱胶、脱酸、脱色、脱臭、储罐和包装按合同范围逐项确认；粕或饼的用途需另行评价。

## 报价所需资料

- 毛籽、脱绒籽或棉仁样品，短绒、壳、含水状态、杂质及可用油脂和棉酚数据
- 每小时或每日籽料量、班次、自动化及壳、短绒和粕的利用方式
- 脱绒、脱壳、制片、调质、压榨/提取和毛油/精炼油目标
- 过滤、精炼、成品检测、储罐和包装范围
- 蒸汽或热源、电、输送、场地、目的地和交货条款

## FAT/SAT 与书面验收

记录清理损失、脱绒和脱壳结果、壳夹带、片状条件、调质后的含水和温度、进料速度或装料、毛油、净滤油、壳和粕/饼。FAT/SAT 文件应标明精炼前后取样点，并附合同约定的实验室结果，包括适用时的棉酚项目；压榨现场目测不能作为食用成品油验收。
