# 荞麦籽油试料与加工方案

荞麦油项目在商业设备选型前需要代表性样品和经济性核算。品种、壳比例、含水状态、细粉比例及原料批次会改变压实、过滤和少量油流的利用价值。

## 原料与产能口径

请区分整粒荞麦、脱壳米、破碎料或制粉副产物，并记录品种、壳比例、含水状态、杂质、储存情况和现有油脂分析。高细粉副产物或混合制粉废料不等同于清洁籽粒，应单独做输送、成型和过滤试验。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 进料状态 | 整籽、脱壳米或特定制粉组分 |
| 前处理 | 清理、脱壳、控粉、调湿和破碎 |
| 路线选择 | 低温或温和调质试验；必要时评估其他提取路线 |
| 产能依据 | 可用干料、批次周期、净滤油和过滤负荷 |
| 商业边界 | 试料量、样油用途、残渣去向及包装范围 |

## 推荐前处理

1. 筛除石块、金属、粉尘和异物。
2. 测量壳比例，并按试料方案决定是否脱壳。
3. 控制过量细粉，避免堵塞过滤或影响料饼成型。
4. 只根据样品试验调整含水状态。
5. 压榨前形成可重复的破碎结构。

## 压榨路线与配置边界

可按需要比较低温与温和调质试料，记录油释放、色泽、气味、料饼和过滤负荷。液压批次压榨可能适合小批量特色油，但在可用进料、完整周期和净滤油结果未确认前，不应锁定机型或商业产能；低含油或高细粉物料也可能更适合其他提取方案。

## 过滤与样油目标

应先明确试料需要获得的样油量、沉降时间、过滤等级、可见沉淀、澄清度、色泽、气味及检测项目。商业测算以批准样品的净滤油质量和实际总工时为依据，不以设备名义参数替代。

## 报价所需资料

- 整籽、荞麦米或制粉组分样品，含壳和细粉比例、含水状态、杂质及现有分析
- 每日干料量、供应季节、批次规模和所需样油量
- 低温或温和调质对比要求及油品用途
- 沉降、过滤、样油、储罐或包装及检测要求
- 电源、热源、场地、目的地和交货条款

## FAT/SAT 与书面验收

书面记录应覆盖进料状态、清理和脱壳损失、含水状态、破碎粒度、调质条件、装料量、周期、油温、毛油、净滤油、残渣和滤材负荷。FAT 是否带料、样品量和重复批次数应在合同中先确定；SAT 如实施，应核对现场输送、粉尘、过滤清洗和实际节拍。所有处理量或油量结论只适用于记录中的样品和方法。
