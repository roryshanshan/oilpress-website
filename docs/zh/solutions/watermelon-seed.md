# 西瓜籽油压榨方案

西瓜籽设备选型必须区分果蔬加工后的湿籽、干整籽和脱壳籽仁。三种进料在清洗、干燥、壳仁分离、装料和油品要求上不同。

## 原料与产能口径

请注明籽型、整籽或籽仁基准、壳比例、含水状态、杂质、储存情况和用途，并剔除空籽、霉变、虫蛀、焦糊或酸败物料。湿籽应及时清洗和干燥，不能作为高含水压榨进料储存。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 进料状态 | 湿籽、干整籽或脱壳籽仁 |
| 前处理 | 去果肉、清洗、干燥、脱壳、分选和破碎 |
| 产品路线 | 低温轻味油，或独立轻烘烤/调质风味油 |
| 产能依据 | 干料基准、壳仁损失、装料密度和周期 |
| 成品目标 | 沉降/过滤、色泽、香气、沉淀和检测 |

## 推荐前处理

1. 从湿籽中分离果肉和异物。
2. 按需要清洗，然后均匀干燥并冷却。
3. 产品需要籽仁时脱壳。
4. 分选并去除石块、金属和缺陷籽。
5. 对干料破碎或轻度调质后试压。

## 压榨路线与配置边界

轻味油可从低温液压批次试料开始；需要更强香气时另做轻烘烤或调质试料。整籽与籽仁属于不同试料规格，机型按实测装料密度和周期选择。

## 过滤与成品油目标

应明确沉降油或过滤油、可见沉淀、澄清度、色泽、香气、取样时间和产品检测。需要控制光照和氧接触时，把储罐与包装列入成品范围。

## 报价所需资料

- 湿籽、干整籽或籽仁样品，壳比例、含水状态、杂质、受损比例和储存情况
- 每批或每日投入基准、班次、季节及清洗/干燥/脱壳范围
- 低温或轻烘烤产品目标及用途
- 沉降、过滤、储罐、包装、取样和检测
- 热源、电、场地、目的地和交货条款

## FAT/SAT 与书面验收

记录投入基准、果肉和杂质去除、干燥后含水状态、壳仁分离和仁损失、破碎/调质、装料、周期、油温、毛油、净滤油和饼粕，并检查色泽、香气、澄清度、出饼、产品残留和清洗。FAT/SAT 文件应明确湿籽预处理是否在供货范围，并区分整籽与籽仁结果。
