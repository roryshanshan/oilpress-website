# 南瓜籽油压榨方案

南瓜籽项目必须说明进入压榨段的是整籽还是脱壳籽仁。壳比例、干燥状态和受损籽会改变可用进料、装料密度、过滤负荷和成品油风味。

![南瓜籽压榨前处理参考](/images/an-overview-of-the-cold-pressing-process-of-pumpki-c206ee35aa.webp)

## 原料与产能口径

请注明籽型、整籽或籽仁基准、壳比例、含水状态、杂质、储存记录和用途，并剔除霉变、虫蛀、空籽、焦糊或酸败物料。果蔬加工后取得的湿籽需要清洗和受控干燥，不能直接作为高含水压榨进料。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 进料状态 | 湿籽、干整籽或脱壳籽仁 |
| 前处理 | 清洗/干清、干燥、脱壳、分选和轻破碎 |
| 产品路线 | 低温油，或独立的轻烘烤/调质风味油 |
| 产能依据 | 整籽或籽仁基准、装料密度、周期和净滤油 |
| 成品目标 | 沉降/过滤、色泽、籽香、沉淀和包装 |

## 推荐前处理

1. 根据来料状态选择水洗或干清。
2. 均匀干燥并冷却后储存。
3. 产品和试料需要时脱壳。
4. 分选并去除异物。
5. 按选定路线轻破碎或调质。

## 压榨路线与配置边界

可比较低温液压批次试料与单独的轻烘烤或调质试料。整籽和脱壳籽仁应分别试压，因为装料密度与饼粕状态不同。进料基准和试料记录未固定前，不锁定机型或处理量。

## 过滤与成品油目标

设定沉降或过滤方法、可见沉淀、澄清度、色泽、籽香和取样时间。储罐与包装按避光和控氧要求配置，并注明报价是否止于过滤油或包含后续精炼。

## 报价所需资料

- 湿籽、干整籽或籽仁样品，壳比例、含水状态、杂质、受损比例和储存情况
- 每批或每日进料基准与数量、班次、季节和清洗/干燥/脱壳范围
- 低温或烘烤风味目标及色泽、香气要求
- 沉降、过滤、储罐、包装、取样和检测要求
- 热源、电、场地、目的地和交货条款

## FAT/SAT 与书面验收

记录整籽或籽仁基准、脱壳结果和仁损失、干燥后含水状态、破碎/调质条件、装料、周期、油温、毛油、净滤油和饼粕。FAT/SAT 应按约定时间检查色泽、香气、澄清度、出饼、产品残留和清洗，并在文件中区分整籽与籽仁结果。
