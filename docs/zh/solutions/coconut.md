# 椰子油加工方案

干椰肉、受控干燥鲜椰肉、鲜椰蓉、椰浆和椰子水需要不同设备。液压压榨报价必须写明进入榨筒的是哪一种已制备固体物料；椰浆、椰汁或高含水果泥不能作为标准液压榨油机的直接进料。

![椰子物料路线选择参考](/images/coconut-puree-e2083a9300.webp)

## 原料与产能口径

干法压榨线应注明干椰肉或计划干燥到可压榨状态的椰肉，并记录含水状态、霉变或焦糊比例、储存时间及现有酸价等资料。湿法初榨椰子油项目则应明确椰浆提取以及油、水、固形物分离路线。产能必须标注按整椰、鲜椰肉、干椰肉还是椰浆核算。

## 推荐前处理

### 干椰肉或受控干燥椰肉

1. 剔除霉变、焦糊或受污染物料。
2. 核对含水状态并切成一致尺寸。
3. 粉碎或制片，形成可重复的压榨装料。
4. 按产品需要比较低温与温和调质试料。

### 鲜椰肉或湿法路线

1. 按产品要求去壳、去褐衣并卫生清洗。
2. 将鲜椰肉切碎。
3. 选择受控低温脱水后压榨，或提取椰浆后走专用湿法分离。
4. 不将椰子水、椰浆或高含水椰蓉直接装入标准榨筒。

## 压榨或专用路线

干椰肉或干燥椰肉可进行液压批次试料。湿法路线需要制浆后分离油、乳相、水和固形物。两条路线的储罐、清洗、物料衡算和成品定义不同，报价应分模块列示。

## 过滤与成品油目标

压榨油应明确可见水分、沉淀、澄清度、气味以及毛油、过滤油或精炼油范围。过滤、储罐和管路应考虑项目所在地环境温度下椰子油凝固的影响。湿法油还需书面定义油水分离终点和入罐前游离水检查。

## 报价所需资料

- 干椰肉、鲜椰肉、椰蓉或椰浆样品，含水状态、霉变/焦糊比例、储存时间和现有分析
- 按整椰、鲜椰肉、干椰肉或椰浆中的哪一种核算产能，以及班次
- 干料压榨或湿法分离路线和目标椰香
- 干燥、粉碎、分离、过滤、保温储罐/管路和包装范围
- 热源、电、水、废水方案、环境温度、场地、目的地和交货条款

## FAT/SAT 与书面验收

验收记录应标明投入基准，并记录剔除物、压榨前含水状态或椰浆状态、切碎/粉碎粒度、装料或分离机设定、油温、毛油、分离水和固形物、净滤油及饼粕。FAT 是否带料和是否包含低温过滤应写入合同；SAT 如实施，应核对约定温度下的过滤流动、产品残留和所有椰子接触面的清洗。
