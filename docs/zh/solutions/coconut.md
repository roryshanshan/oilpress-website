# 椰子油生产线方案

本页面对应鲜成熟椰子的完整加工项目，可同时规划椰子水、椰浆、干椰蓉、毛椰子油、精炼椰子油和瓶装成品。它不是单纯“干椰肉进液压榨油机”的报价页；设备定型前，需要先确认工厂真正销售哪些产品。

![椰子物料路线选择参考](/images/coconut-puree-e2083a9300.webp)

## 整线范围

完整路线包括椰子去毛、输送、人工去硬壳、椰子水过滤与储存、椰肉清洗、椰肉粉碎、液压压椰浆、干燥、混合、螺旋榨油、离心分离、可选精炼，以及最终灌装、旋盖、贴标和喷码。

可用完整产线视频核对物料流向、人工工位、湿区与干燥区隔离、储罐位置、通风、清洗空间、地面排水、废水处理和包装动线。

## 产品路线

| 路线 | 商业产品 | 主要工序 | 需要确认 |
| --- | --- | --- | --- |
| 湿法液体段 | 椰子水、椰浆 | 收集并过滤椰子水；清洗粉碎椰肉；用液压机压椰浆；储存或灌装液体产品 | 卫生等级、储罐容量、滤材、椰浆提取率口径、清洗方式 |
| 干燥榨油段 | 干椰蓉、毛油、精炼油、瓶装油 | 压榨后的椰肉干燥、混合、提升、螺旋榨油、分离、储存、按需精炼和包装 | 进出料水分、出油率口径、油温、沉淀、精炼工段和包装规格 |

## 工厂流程

1. 椰子去毛、输送并去硬壳。
2. 椰子水收集、过滤和储存。
3. 椰肉清洗、粉碎，并液压压取椰浆。
4. 剩余椰肉干燥、混合、提升并螺旋榨油。
5. 椰子油分离、储存，并按需要精炼。
6. 对选定成品进行灌装、旋盖、贴标和喷码。

## 产能平衡问题

| 工段 | 公开参考 | 工程设计前需要回答 |
| --- | --- | --- |
| 椰肉清洗 | 10吨/天 | 对应多少工作小时和多少合格椰肉出料？ |
| 液压压椰浆 | 80%提取率参考 | 是质量收率、液体回收率，还是其他口径？ |
| 椰蓉干燥 | 5吨/天与350 kg湿料/小时 | 进料水分、出料水分和工作小时如何统一？ |
| 两台128型螺旋榨油机 | 每台160 kg/小时 | 干燥机和提升机能否连续供给两台压榨机？ |
| 卧螺离心机 | 100 kg/小时 | 该流量对应液体、毛油还是混合物料？ |
| S600精炼 | 500 kg/24 h | 毛油缓冲量多少，精炼批次多久运行一次？ |
| 总装机功率 | 约130-150 kW，视配置和负荷而定 | 需提供最终电机清单和同时运行负荷估算。 |

## 报价所需资料

- 产品计划：椰子水、椰浆、干椰蓉、毛油、精炼油或瓶装油
- 产能口径：整椰、椰肉、椰浆、干椰蓉、毛油或成品油
- 工作小时、原椰尺寸范围、当地人工配置和自动化要求
- 干燥前水分、榨油前水分和目标出油/出浆口径
- 油品气味、澄清度、沉淀、水分限值和精炼工段
- 瓶型、盖型、标签、喷码内容和最终包装形式
- 电力、热源、清水、废水、排水、通风、场地、目的地和交货条款

## FAT/SAT 与验收记录

验收应记录投入基准、剔除椰子、椰子水回收、椰肉清洗结果、粉碎粒度、液压压榨装料、椰浆产出、干燥前后水分、螺旋榨进料量、毛油、分离水和固形物、精炼油、包装精度，以及所有椰子接触面的清洗情况。
