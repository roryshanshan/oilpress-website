# 辣椒籽油压榨方案

辣椒籽通常来自制粉、酱料或干燥工序，可能夹带果皮、果肉、梗、粉尘、盐或其他调味物。生产线除提油外，还需控制刺激性粉尘、气味、交叉污染和换产清洁。

![辣椒籽调质与压榨工艺参考](/images/hot-pressing-process-of-chili-seeds-c9c009d0eb.webp)

## 原料与产能口径

请注明辣椒品种、籽料回收工序、含水状态、残留果肉和梗、粉尘、盐或添加物、储存情况及油品用途。清洁干籽与湿酱渣或混合香辛料废料不是同一种进料；产能应按去除非籽物后的净干籽核算。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 进料状态 | 清洁干籽，或含湿残渣并另配分离干燥 |
| 调质路线 | 蒸制、轻烘烤或较低温对照试料 |
| 环境控制 | 粉尘收集、通风、气味和交叉污染控制 |
| 成品目标 | 沉降/过滤、色泽、澄清度、辣感或香气 |
| 产能依据 | 净干籽、实际装料/周期、净滤油和清洗时间 |

## 推荐前处理

1. 分离梗、皮、果肉、石块和金属。
2. 均匀干燥并冷却后储存。
3. 在输送和粉碎点控制刺激性粉尘。
4. 形成可重复的破碎粒度。
5. 根据目标色泽和香气比较蒸制、轻烘烤或低温路线。

## 压榨路线与配置边界

清理和调质后的辣椒籽可做液压批次试料。应在同批物料上比较不同调质条件，并记录装料、周期、油温、净滤油、料饼、过滤负荷、气味控制和清洗。与其他油品共线时，应配置专用设备或经书面验证的换产清洁程序。

## 过滤与成品油目标

需明确沉降油或过滤油、可见沉淀、澄清度、色泽、辣感或香气、取样时点及食用或工业检测。接触材质、通风、储罐、包装和换产前清洁终点应列入供货及验收范围。

## 报价所需资料

- 代表性回收籽样、品种、含水状态、果肉和梗残留、粉尘、盐或添加物及储存情况
- 每批或每日净干籽投入、季节、班次和干燥范围
- 蒸制、轻烘烤或低温路线，以及目标色泽、香气和用途
- 除尘、通风、专机或换产清洁、过滤、储罐和包装范围
- 热源、电源、场地、目的地和交货条款

## FAT/SAT 与书面验收

带料 FAT 应记录原料与清洁干籽重量、剔除物、干燥后含水状态、破碎粒度、调质条件、装料量、周期、油温、毛油、净滤油和饼粕，并检查色泽、气味或辣感、澄清度、粉尘收集和滤机清洗。SAT 如包含换产，应按书面卫生程序确认残留和气味终点；视频或单次试压不能替代合同验收记录。
