# 葡萄籽油加工方案

葡萄籽通常夹在酿酒或制汁后的湿葡萄渣中，同时含果皮、果梗、果肉和发酵残留。报价必须明确进料是湿葡萄渣还是已分离干燥的葡萄籽；两者不能使用同一产能基准。

![葡萄籽分离、干燥和压榨参考](/images/hot-pressing-process-of-grape-seeds-9fc9a8f225.webp)

## 原料与产能口径

请记录葡萄渣来源、压榨后停留时间、果皮和果梗比例、籽回收基准、含水状态、储存情况以及霉变或氧化迹象。已洗净干燥籽与需要回收设备的湿葡萄渣应分别报价；季节性干燥能力也应纳入整线节拍。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 进料基准 | 湿葡萄渣或干葡萄籽，必须分开 |
| 前处理 | 籽渣分离、按需清洗、快速干燥、筛理和破碎 |
| 产品路线 | 低温特色油，或同批温和调质对照 |
| 产能依据 | 湿渣回收量、干籽量、干燥时数、批次周期和净滤油 |
| 成品目标 | 沉降/精滤、色泽、香气、氧化检测和避光包装 |

## 推荐前处理

1. 从果皮、果梗、果肉和异物中分离葡萄籽。
2. 根据残留和废水方案决定是否清洗。
3. 及时受控干燥并冷却后储存。
4. 再次筛理并去除金属或硬质污染物。
5. 临近压榨时将干籽均匀破碎。

## 压榨路线与配置边界

食品或化妆品特色油可先做低温液压批次试料；需要时在同批干籽上进行温和调质对照，并记录色泽、气味、氧化指标、过滤负荷和料饼。项目经济性应包含湿渣分离、干燥和季节性运行，而不是只比较压榨机名义能力。

## 过滤与成品油目标

应明确沉降和精滤方法、可见沉淀、澄清度、色泽、气味、氧化检测方法以及避光包装。取样基准必须标明毛油、沉降油还是净滤油。

## 报价所需资料

- 湿葡萄渣或干籽样品、果皮和果梗残留、籽回收基准、含水状态、储存时间及霉变/氧化情况
- 产能按湿渣或干籽核算、季节总量、每日干燥时数和压榨班次
- 低温或温和调质试料、食品/化妆品用途及油温记录要求
- 沉降、过滤、储罐、包装和氧化检测要求
- 干燥热源、电、水与废水、场地、目的地和交货条款

## FAT/SAT 与书面验收

湿葡萄渣和回收干籽应分别称量，记录杂质去除、干燥后含水状态、破碎粒度、装料量、周期、油温、毛油、净滤油和饼粕。FAT 的样料状态、干燥是否在供货范围及检测方法应先写入合同；SAT 如实施，应在约定沉降或过滤后核对澄清度、色泽、气味和氧化检测，并保留对应样品与运行条件。
