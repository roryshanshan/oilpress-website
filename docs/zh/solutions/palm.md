# 鲜棕榈果油与棕榈仁油生产线

鲜棕榈果肉生产棕榈油，果核内的棕榈仁生产棕榈仁油，两者是独立工艺。设备报价前必须明确进料是鲜果串、散果、回收棕榈坚果还是清洁棕榈仁。

![鲜棕榈果肉与棕榈仁物料参考](/images/hot-pressing-process-of-palm-pulp-palm-kernel-7153ac8a85.webp)

## 原料与产能口径

**鲜果路线：** 记录鲜果串或散果、采收到进厂时间、成熟度、污染和每日到料节奏。

**棕榈仁路线：** 记录回收坚果或已分离棕榈仁、壳比例、含水状态、破仁比例和储存情况。

鲜棕榈果不是干油料，棕榈仁也不应并入鲜果压榨物料衡算。两条路线必须分别报价、分别验收。

## 采购参数表

| 采购参数 | 鲜棕榈果油线 | 棕榈仁油线 |
| --- | --- | --- |
| 进料 | 鲜果串或散果 | 坚果或清洁棕榈仁 |
| 核心前处理 | 蒸汽灭酶、脱果、捣碎 | 干燥、破壳、壳仁分离、调质 |
| 压榨设备 | 专用棕榈果螺旋压榨机 | 独立仁料机械压榨线 |
| 后处理 | 筛分、澄清、净化、干燥和储存 | 固形物去除、过滤及后续精炼 |
| 产能依据 | 鲜果到料和整线连续物料衡算 | 净仁量、壳夹带和连续试验 |

## 正确前处理

### 鲜棕榈果

1. 及时接收、称量鲜果串。
2. 采用受控蒸汽周期进行蒸煮灭酶。
3. 脱果，将果实与空果串分离。
4. 捣碎果肉。
5. 将制备果肉送入专用棕榈油螺旋压榨机。

### 棕榈仁

1. 回收并干燥棕榈坚果。
2. 破壳并分离壳与仁。
3. 清理、干燥和分级棕榈仁。
4. 为选定的仁料压榨路线进行调质。

## 专用压榨路线与供货边界

鲜果路线为：

**蒸煮灭酶 -> 脱果 -> 捣碎 -> 专用螺旋压榨 -> 筛分与澄清 -> 油净化和干燥 -> 毛棕榈油储存**

标准 300-500 系列液压榨油机不用于鲜棕榈果。完整项目还需分别处理空果串、纤维、坚果、冷凝液、污泥和废水。

棕榈仁使用独立的破壳分离、调质、机械压榨和过滤线；设备根据代表性净仁试验和连续处理量选型。

## 澄清、过滤与成品目标

毛棕榈油应明确澄清和干燥后的取样点、可见固形物、水分、储存温度控制、储罐及是否包含精炼。棕榈仁油则单独定义毛油固形物、过滤等级、水分、储存和下游精炼。

## 报价所需资料

- 鲜果串、散果、棕榈坚果或棕榈仁的照片、代表性样品及现有质量资料
- 鲜果每小时/每日到料、到料节奏、季节和采收到进厂时间，或净仁量及壳比例
- 毛棕榈油或精炼油目标、棕榈仁回收和全部副产物边界
- 蒸汽、水、电、燃料、储罐、废水/污泥方案和厂房面积
- 目的地、当地安装条件、自动化和交货条款

## FAT/SAT 与书面验收

鲜果线应记录接收时间和重量、蒸煮周期、脱果效果、捣碎与螺旋压榨负荷，并按约定方法记录油、纤维、坚果、空果串、冷凝液、污泥和废水的物料衡算；澄清与干燥后检测固形物和水分。棕榈仁线则独立记录壳仁分离、仁料含水状态、进料、油、饼、过滤和取样。FAT/SAT 的运行时长、原料责任和公用工程边界必须写入合同。
