# 腰果仁油与腰果壳液加工方案

腰果仁和腰果壳是两种不同的工业原料。可食用核仁可评估食品或化妆品油路线；腰果壳含腰果壳液（CNSL），需要独立的工业安全、材料兼容、密闭收集和清洗方案，不能套用食品油生产线。

![腰果壳料专用工业路线参考](/images/hot-pressing-process-of-cashew-peel-def65fdf7a.webp)

![脱壳腰果仁低温试压参考](/images/cold-pressing-process-of-cashew-kernels-f8ff465cd8.webp)

## 原料与产能口径

**核仁线：** 使用已安全脱壳的整仁或碎仁，并控制残壳及 CNSL 污染。

**壳料线：** 提供代表性腰果壳样品、安全资料、含水状态、粒形和目标工业液规格。壳料不得进入食品油线；如考虑共用设备，必须先形成交叉污染评估和书面清洁边界。

## 采购参数表

| 采购参数 | 核仁线 | 壳料/CNSL 线 |
| --- | --- | --- |
| 产品用途 | 食品、化妆品或约定用途 | 工业原料 |
| 主要前处理 | 分选、控水、破碎 | 破碎、加热、通风、密闭收集 |
| 压榨入口 | 低温液压批次试料 | 经安全与兼容验证的专用提取路线 |
| 后处理 | 沉降、过滤、储存 | 固液分离、耐介质管路与储罐 |
| 验收重点 | 净滤油、气味、清洁 | 泄漏、材料状态、残渣与职业防护 |

## 推荐前处理

### 腰果仁

1. 剔除残壳、焦糊、霉变和酸败核仁。
2. 核对含水状态和储存情况。
3. 临近压榨时均匀破碎。
4. 食品、化妆品和工业批次分别储存与清洁。

### 腰果壳

1. 明确接收、储存、破碎、加热、气体控制和密闭收集方案。
2. 用实际 CNSL 规格核对密封、软管、储罐和接触面材质。
3. 在选型前书面确定人员防护、泄漏控制、残渣处置和清洗流程。

## 压榨或专用路线

核仁可先做低温液压批次试料，评估净滤油、出饼和可清洁性。壳料不得复制核仁路线，也不能默认标准食用油压榨机适用；应在物料、安全和兼容性试验后确定专用工业提取设备。

## 成品与过滤边界

核仁油应明确沉降或过滤等级、可见沉淀、色泽、气味、用途和检测项目。CNSL 则应明确工业固形物、水分、收集温度、管路与储罐兼容性及下游用途。两条路线必须使用独立的取样和验收标准。

## 报价所需资料

- 原料是整腰果、壳、原始核仁还是碎仁，含水状态、污染、储存情况和代表性样品
- 核仁油用途或 CNSL 工业用途，以及现有安全和产品规格
- 每批或每日投入、班次，以及脱壳或粒度处理范围
- 加热、通风、密闭收集、过滤、储罐、残渣、清洗和人员防护范围
- 电、热源、场地隔离、目的地和交货条款

## FAT/SAT 与书面验收

核仁 FAT 记录应包括残壳、含水状态、破碎、装料、周期、油温、毛油、净滤油、饼粕和清洗。壳料 FAT/SAT 应记录批准物料、调质参数、密闭收集、液体与残渣重量、泄漏检查、过滤结果、接触材质状态和残渣处置。合同应分别列明两条路线的样料、测试和验收文件；一条路线验收通过不代表另一条路线合格。
