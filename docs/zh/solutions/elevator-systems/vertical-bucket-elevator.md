# 垂直斗式提升机

![垂直斗式提升机](/images/elevator-systems/vertical-bucket-elevator.webp)

垂直斗式提升机是按垂直转运目的归类的系列入口，可采用胶带、板链或环链等不同牵引构件。选型不应先固定结构再寻找用途，而应先确认物料、输送量、提升高度、进料连续性和出料方向，再比较各类料斗与牵引方式的适配性。

## 选型逻辑

粉体和细颗粒更需注意密封、扬尘和回料；颗粒和小块物料则还要评估进料冲击、料斗强度和卸料路径。易碎物料要控制带速和跌落，易磨物料则要核对接触部件的耐磨余量。只有当这些条件明确后，才能确定机头、机筒、底座、驱动和张紧配置。

## 三类常见牵引结构

垂直斗式提升机可采用胶带、板链或环链牵引。胶带结构常用于运行较平稳且物料冲击相对可控的场景；板链结构更适合持续负载与较大料斗受力的配置；环链结构则需重点核对链条、链轮、张紧和润滑。三者没有脱离物料和布局条件的绝对优劣，选择依据是工况匹配、维护条件和项目边界。

| 设计环节 | 需要回答的问题 | 对设备的影响 |
| --- | --- | --- |
| 物料接收 | 来料是否连续，是否含杂物或大块料 | 决定进料口、缓冲和底部防堵设计 |
| 垂直提升 | 提升高度与目标流量是多少 | 决定牵引件、料斗、驱动和机体总高 |
| 顶部卸料 | 下游设备在何处，允许落差多大 | 决定机头、出料方向和导料结构 |
| 清理检修 | 是否要换料、清洁或频繁维护 | 决定观察门、清理口、平台和通道 |
| 控制保护 | 何时允许启动，异常如何停机 | 决定料位、堵料、跑偏、速度与急停联锁 |

## 现场工艺布置

工程图应同时显示接料斗、前端输送、提升机、出料溜管、缓冲仓和下游设备，不能只标出提升高度。对于粉料，要标出除尘接口和密封边界；对于颗粒和种子，要标出转运落差和可能产生破碎的部位。设备周围还应保留换料斗、检修驱动、清理底座和平台扶梯的操作空间。

## 操作与保养

开机前确认检查门关闭、保护装置完好、底部无积料和上游物料状态正常。运行中观察电流、噪声、振动、出料和检测信号。计划维护时，按设备实际运行条件检查牵引件、料斗紧固、链轮或滚筒、轴承、减速机和密封；对发现的磨损应记录位置和趋势，以便安排备件和停机窗口。

## 不能忽略的风险点

如果上游突然大量来料，底部可能积料并造成堵塞；若出料端受阻，则机头附近可能出现回料或溢料；若维护前未停止上游进料，人员进入检修区域会面临物料继续落下的风险。这些风险应通过工艺联锁、机械防护、现场程序和培训一起处理。

## 项目接口

- 进料设备的出料高度、流量波动和是否存在大块杂物。
- 出料口标高、下游仓位、水平偏移和允许的落差。
- 机体总高、平台扶梯、检修门、基础载荷和厂房净空。
- 堵料、跑偏、速度、料位和急停等保护信号的联锁边界。

## 验收与交付边界

验收应以双方约定的物料检查负载运行、输送量、溢料、回料、振动、噪声及检修通道。报价应明确是单机、带平台的机组还是含前后端接口的成套范围，并列明驱动、料斗、传感器、防护、备件和服务内容。
