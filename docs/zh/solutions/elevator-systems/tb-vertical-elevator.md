# TB 系列垂直提升机

![TB 系列垂直提升机](/images/elevator-systems/tb-vertical-elevator.webp)

TB 系列垂直提升机适合围绕厂房高度、进出料方向和下游设备布置来确定的物料转运任务。设备形式、料斗排布和牵引结构需要与物料及接口共同确认。较大提升高度或紧凑安装空间会同时影响总高、基础载荷、平台、驱动布置和检修路径。

## 布局先于型号

项目开始时应绘出进料口、出料口、设备中心线和人员通道，确认是否存在梁柱、楼板开口、管线和相邻设备干涉。定制接口还应说明法兰或料斗口形状、出料方向、下游落料点、平台扶梯和防护边界。没有这些资料，型号无法对应到真实现场。

## 工艺布置的确认步骤

首先确定进料点与出料点的实际中心标高，再确认设备机体可占用的平面范围和顶部净空。随后把上游给料、下游仓体或设备、溜管、除尘、平台和人员通道放进同一张图中核对。这样可以在制造前发现出料方向与下游冲突、检修门无法开启、平台被管线占用或底部清理空间不足等问题。

## 主要配置项目

| 配置 | 对项目的作用 | 订货时需要明确 |
| --- | --- | --- |
| 牵引与料斗 | 决定物料的承接和垂直运输方式 | 物料特性、料斗尺寸、间距和耐磨要求 |
| 机头与出料口 | 决定驱动位置和下游交接 | 出料方向、中心高、落料空间和检修面 |
| 机筒与底座 | 决定总高、密封与底部接料 | 分段长度、观察门、清理口和支撑方式 |
| 平台与扶梯 | 提供维护和检查通道 | 高度、宽度、护栏、开口和现场边界 |
| 传感与控制 | 处理堵料、速度或料位异常 | 检测点、联锁逻辑、电源与信号接口 |

## 安装调试关注点

安装过程应验证基础尺寸、设备垂直度、分段连接、进出料法兰和平台连接。调试先进行空载检查，确认牵引件运行轨迹、驱动方向、检测信号和急停逻辑；随后按约定物料逐步加载，检查给料、提升、卸料、回料、振动和出料承接。任何因现场条件改变而新增的溜管、支架或防护，应在变更中明确责任范围。

## 运行和检修安排

长期运行应有检查记录，至少覆盖驱动、牵引件、料斗紧固、底部积料、传感器、密封和平台护栏。检修前要停止上游来料、让设备排空、断开电源并采取现场规定的隔离措施。若设备用于多种物料，应按物料切换要求确定清理方法，避免残料进入下一批次。

## 需要确认的配置

- 物料颗粒、堆积密度、温度、含水率、磨蚀性和允许落差。
- 提升高度、总高、进出料中心标高、水平偏移和基础尺寸。
- 目标处理量、给料方式、出料方向及上下游设备控制关系。
- 驱动、牵引件、料斗、密封、观察门、平台和传感器要求。

## 验收与交付边界

现场或出厂验证应关注布置尺寸、负载运行、卸料路径、积料、振动、联锁和检修可达性。商务文件应区分主机、平台、扶梯、防护、控制、土建、吊装、安装、调试和培训，避免把非标准接口或现场工作默认包含在单机报价中。
