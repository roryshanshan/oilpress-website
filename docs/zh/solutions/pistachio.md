# 开心果油压榨方案

开心果油项目应按生的脱壳核仁或明确定义的带壳原料核算。烘烤、盐焗、调味或混合零食料与生核仁不同，需要单独评估污染、过敏原和清洁边界。

## 原料与产能口径

请注明品种、产地、壳比例、含水状态、储存记录及食品或化妆品用途，并剔除霉变、虫蛀、变色、焦糊或酸败核仁。需要污染物检测时，压榨不能替代代表性取样和实验室分析。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 压榨进料 | 生核仁，或明确配方的烘烤核仁 |
| 产能基准 | 可用核仁，不以带壳吨位核算 |
| 产品路线 | 低温轻味油，或独立烘烤风味油 |
| 成品目标 | 沉降/精滤、色泽、香气、沉淀和包装 |
| 卫生边界 | 食品接触材质、产品回收、过敏原和可清洁性 |

## 推荐前处理

1. 脱壳并分离硬壳碎片。
2. 分选生核仁，剔除缺陷料。
3. 实测含水状态，仅在必要时缓和干燥或调质。
4. 均匀破碎并减少空气暴露。
5. 烘烤试料与低温路线隔离。

## 压榨路线与配置边界

高价值轻味油可先评估液压批次低温压榨。需要烘烤风味时，应以独立前处理配方比较色泽、香气、净滤油和出饼。机型按照可用核仁和批次记录确定，不按带壳名义处理量选型。

## 过滤与成品油目标

应明确沉降或精滤、可见沉淀、澄清度、色泽、香气、取样时间及避光控氧包装。采购规格还应包含食品接触材质、管线产品回收和清洗要求。

## 报价所需资料

- 带壳或生核仁样品、壳比例、含水状态、缺陷比例、储存记录和检测报告
- 每批或每日可用核仁投入、班次、追溯和脱壳范围
- 低温或烘烤风味目标及食品/化妆品用途
- 沉降、过滤、储罐、包装和油品检测要求
- 公用工程、场地、卫生与过敏原控制、目的地和交货条款

## FAT/SAT 与书面验收

记录壳和剔除重量、核仁含水状态、破碎粒度、装料、周期、油温、毛油、净滤油、饼粕和设备内残留，并检查色泽、香气、焦糊/酸败气味、约定时间后的澄清度和清洗。FAT/SAT 应写明贵价原料的样料数量、产品回收和损耗计量方法。
