# 葵花籽油加工方案

油用葵花籽和食葵品种的壳比例及压榨行为可能不同。报价应说明进料是整籽、脱壳籽仁还是已制备料，并区分低温特色油与进入精炼的毛油。

![葵花籽调质与压榨工艺参考](/images/sunflower-seed-hot-pressing-process.webp)

## 原料与产能口径

请记录品种、壳比例、含水状态、杂质、储存情况和现有油脂分析，并剔除石块、金属、空籽、霉变和酸败物料。产能按清洁整籽或净籽仁核算，脱壳损失单独记录。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 进料状态 | 油用/食葵、整籽/籽仁或已制备料 |
| 前处理 | 清理、按需脱壳、破碎/轧片和热湿调质 |
| 工艺路线 | 低温特色油，或温榨连续毛油路线 |
| 后处理 | 过滤、精炼及按成品要求的脱蜡 |
| 产能依据 | 清洁料、脱壳损失、批次/连续记录和物料衡算 |

## 推荐前处理

1. 清理并去除石块和金属。
2. 测量壳比例，根据产品和工艺决定是否脱壳。
3. 破碎、轧坯或制片。
4. 温榨路线进行热湿调质；低温路线另留对照批次。
5. 稳定向压榨段供料。

## 压榨路线与配置边界

低温路线可用于特色油试料；商业毛油通常需要比较温和调质后的连续机械压榨。液压批次可适用于定义明确的小批产品，但不能在缺少周期记录时外推产能。若成品要求在较低储存温度下保持澄清，后处理需评估脱蜡。

## 过滤、精炼与脱蜡目标

应明确过滤毛油、精炼油或脱蜡油，以及可见固形物、水分、色泽、气味、蜡评价和约定冷却/储存条件下的澄清度。取样点及储罐、冷却、过滤、精炼和灌装边界逐项列入报价。

## 报价所需资料

- 油用或食葵品种、整籽或籽仁样品、壳比例、含水状态、杂质、储存和油脂资料
- 每批、每小时或每日清洁料投入、班次及脱壳/连续输送要求
- 低温特色油或温榨毛油目标和后续精炼计划
- 过滤、蜡/冷却试验、精炼、储罐和包装要求
- 热源、电、场地、目的地和交货条款

## FAT/SAT 与书面验收

记录清理与脱壳结果、籽仁损失、含水状态、轧坯/片状条件、调质参数、进料或装料、油温、毛油、净滤油和饼粕。合同包含过滤或脱蜡时，应按约定冷却时间和温度检查固形物与澄清度，并附油品检测。FAT/SAT 的原料品种和进料基准必须一致。
