# 油菜籽/卡诺拉菜籽油加工方案

油菜籽与卡诺拉类型不能视为相同的成品规格。品种组成、芥酸资料、目标风味、处理量和粕用途明确后，才能选择低温批次、温榨螺旋、预榨或精炼范围。

![油菜籽调质与压榨工艺参考](/images/process-image-55d72f15da.webp)

## 原料与产能口径

请注明品种和产地、油菜籽或卡诺拉分类、含水状态、杂质、储存情况、现有油脂分析，以及适用时的芥酸资料。压榨段产能按清洁籽核算。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 原料身份 | 油菜籽或卡诺拉、品种、来源和分析 |
| 工艺路线 | 特色低温、温榨螺旋、预榨或后续精炼 |
| 前处理 | 清理、破碎/轧坯和热湿调质 |
| 产能依据 | 清洁籽、批次周期或连续进料和物料衡算 |
| 成品与粕 | 过滤毛油/精炼油及粕的取样、用途和检测 |

## 推荐前处理

1. 筛理、风选并去除石块和金属。
2. 破碎或轧坯。
3. 为温榨路线调节水分和热量。
4. 需要低温特色油时另留清洁对照批次。
5. 稳定向压榨段供料。

## 压榨路线与配置边界

低温批次压榨仅用于定义明确的特色产品和经验证籽料。商业毛油应根据处理量和粕目标比较温和调质后的连续螺旋压榨或预榨。液压批次数据不能在没有周期记录时外推为连续产能；毛油还可能需要过滤、脱胶和精炼。

## 过滤与成品油目标

应区分过滤毛油和精炼油，并列出固形物、水分、色泽、气味、脱胶/精炼范围及目标品种和市场所需的实验室项目。油和粕分别设取样点。

## 报价所需资料

- 籽样、品种、产地、含水状态、杂质、储存情况、油脂及芥酸资料
- 每批、每小时或每日清洁籽投入、班次及批次/连续要求
- 低温特色油、温榨毛油、螺旋或预榨路线和粕用途
- 过滤、脱胶、精炼、储罐、包装、取样和检测范围
- 蒸汽或热源、电、输送、场地、目的地和交货条款

## FAT/SAT 与书面验收

记录清理损失、破碎或轧坯状态、调质后的含水和温度、进料或装料、周期、油温、毛油、净滤油和饼粕。FAT/SAT 应标明油和粕的取样点并附约定成分检测；设备运行不能替代对品种相关化学指标的实验室确认。
