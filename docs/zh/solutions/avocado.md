# 牛油果油加工方案

整果不是标准液压榨油机的直接进料。项目必须先完成清洗、去皮和去核，再在湿法果浆分离与受控脱水果肉机械压榨之间选择路线；两种路线的设备、清洗、物料衡算和成品油定义不同。

## 原料与产能口径

请注明进料是整果、鲜果肉、冷冻果肉还是干燥果肉，并记录品种、成熟度、可用果肉比例、含水或干物质、储存时间及发酵、褐变、腐败情况。果皮和果核属于独立副产物，不应计入压榨段处理量。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 产能基准 | 整果、湿果肉或干果肉，必须选定一种并列损耗 |
| 工艺路线 | 湿法果浆分离，或受控脱水后的机械压榨 |
| 压榨适用性 | 标准液压机仅在干燥果肉试料通过后选型 |
| 成品目标 | 游离水、悬浮固形物、澄清度、色泽、气味和氧化检测 |
| 供货边界 | 清洗、去皮去核、打浆、脱水/干燥、分离、过滤、储罐和灌装 |

## 推荐前处理

1. 清洗并分选整果。
2. 去皮、去核，避免硬质碎片混入果肉。
3. 将可用果肉破碎或打浆。
4. 湿法路线按试验条件进行搅拌调质和油、水、固形物分离。
5. 压榨路线先受控脱水或低温干燥，再粉碎或调质后做压实试验。

## 湿法或干果肉路线

**湿法路线：** 清洗 -> 去皮去核 -> 果肉打浆 -> 受控搅拌调质 -> 固液分离 -> 油水分离 -> 精滤 -> 密闭储存。

**干果肉路线：** 去皮去核 -> 受控脱水或低温干燥 -> 粒度处理 -> 调质试验 -> 机械压榨 -> 油水与固形物分离 -> 过滤。

鲜果肉含水高，不应直接装入标准液压榨筒。湿法路线需要专用分离设备；液压机型号只能依据干燥果肉的装料密度、周期、净滤油和清洁记录确定。

## 分离、过滤与成品油目标

应明确分离或过滤后的取样点、游离水、沉淀、澄清度、色泽、气味及约定的氧化相关检测。报价还应写明密闭储罐、食品接触材质、果肉接触面的清洗方式和产品残留回收边界。

## 报价所需资料

- 整果或果肉样品、品种、成熟度、果肉比例、含水或干物质、储存时间和到料状态
- 产能按整果、湿果肉或干果肉中的哪一种核算，以及每日进料和班次
- 湿法分离或干果肉压榨路线及过程温度限制
- 游离水、沉淀、澄清度、色泽、气味、检测、储罐和包装要求
- 水、电、干燥热源、场地、清洗排水、目的地和交货条款

## FAT/SAT 与书面验收

FAT 或试料记录必须标明每个重量是整果、湿果肉还是干果肉，并记录去皮去核损失、果肉干物质或含水状态、干燥或搅拌条件、进料、设备设定、油温、毛油、分离水、固形物和净滤油。SAT 应在现场公用工程与清洗条件具备后，按合同核对游离水、沉淀、澄清度、可清洁性和产品残留；湿法与干果肉路线不能共用一份含糊的验收结论。
