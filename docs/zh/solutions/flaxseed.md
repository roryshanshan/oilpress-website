# 亚麻籽/胡麻油压榨方案

亚麻籽粒径小，破碎料和油品都需要控制热量、空气暴露和等待时间。低温压榨油与加热调质油属于不同产品路线，应分样试料、分别报价和验收。

![亚麻籽热调质路线参考](/images/flaxseed-hot-pressing-process.webp)

![亚麻籽低温压榨路线参考](/images/an-overview-of-the-cold-pressing-process-of-flaxse-0ea1b504ce.webp)

## 原料与产能口径

请注明品种、产地、含水状态、杂质、破损或霉变、储存时间以及食品或工业用途。清理损失单独记录，压榨段产能按清洁干籽核算。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 产品路线 | 低温轻味油，或加热调质风味油 |
| 前处理 | 精细清理、按需干燥、临近压榨破碎 |
| 氧化控制 | 破碎到压榨、压榨到过滤/封罐的时间 |
| 产能依据 | 净干籽、批次周期或连续进料、净滤油和清洗 |
| 成品目标 | 沉降/精滤、色泽、气味、氧化检测和避光包装 |

## 推荐前处理

1. 筛理并风选细小异物。
2. 去除石块和金属。
3. 仅在需要时缓和干燥。
4. 临近压榨时形成一致破碎粒度。
5. 缩短破碎、压榨、过滤和封罐之间的开放等待。

## 压榨路线与配置边界

特色低温油可采用液压批次试料并快速处理破碎籽。温榨或热调质可能改变压榨行为，但也会改变风味和氧化状态，必须用同批原料单独评价。连续商业处理量应比较螺旋压榨及后续固形物处理，不能只按液压批次数量推算。

## 过滤与成品油目标

应明确沉降或精滤、可见沉淀、澄清度、色泽、气味、氧化检测方法和取样时间。需要时把密闭储罐、避光包装及压榨到最终封闭的最长允许间隔写入采购规格。

## 报价所需资料

- 代表性清洁籽样、品种、含水状态、杂质、储存时间和氧化状态
- 每批或每日干籽投入、班次及批次或连续运行要求
- 低温或加热调质产品目标及油温记录要求
- 沉降、过滤、储罐、包装、取样和氧化检测范围
- 电、热源、场地、目的地和交货条款

## FAT/SAT 与书面验收

记录清理损失、籽料含水状态、破碎粒度、调质条件、装料或进料速度、周期、油温、毛油、净滤油和饼粕，并记录破碎到压榨、压榨到密闭储存的时间。FAT/SAT 应分别标明低温与加热路线，按约定样品比较澄清度、色泽、气味和氧化检测，不使用一条路线的结果替代另一条路线。
