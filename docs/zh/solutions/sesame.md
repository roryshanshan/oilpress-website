# 芝麻油压榨方案

芝麻油设备应围绕目标产品配置：低温轻味油、炒籽浓香油，或当地定义的其他风格。白芝麻或黑芝麻、脱皮或带皮、湿法清洗或干清路线需要分别试料和记录。

![芝麻清理、炒制与压榨工艺参考](/images/process-image-dfc1cdf2c9.webp)

## 原料与产能口径

请注明籽色和品种、脱皮状态、含水状态、砂石、空籽或受损籽、储存情况和目标产品。产能按完成约定清洗、干燥和分选后的清洁芝麻核算。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 原料身份 | 白/黑芝麻、带皮/脱皮、清洗方式 |
| 产品路线 | 低温轻味，或记录炒制配方的浓香油 |
| 前处理 | 筛理、去石、按需水洗、干燥/调质和炒制冷却 |
| 成品目标 | 传统沉降油或过滤清油、沉淀、色泽和香气 |
| 产能依据 | 清洁籽、装料/周期或连续进料、过滤和清洗时间 |

## 推荐前处理

1. 筛理、风选并去除石块和金属。
2. 只有产品配方和废水方案需要时才水洗。
3. 干燥或调质到可重复状态。
4. 浓香路线按书面时间、温度和冷却曲线炒籽。
5. 低温路线与炒制路线分开备料。

## 压榨路线与配置边界

液压批次压榨适合依赖炒籽配方的产品，也可用于定义明确的低温试料。两种产品不能共用一项处理量结论。更大连续产量可比较螺旋压榨，但仍使用相同的香气、色泽、沉淀和饼粕验收标准。

## 沉降、过滤与成品油目标

应明确传统沉降油或过滤清油、允许沉淀、沉降时间、色泽、炒香强度、焦糊气味和包装。过滤配置应服务于所选产品风格，所有取样都要注明压榨后的时间。

## 报价所需资料

- 白或黑芝麻样品、脱皮状态、含水状态、砂石、受损比例和储存情况
- 每批或每日清洁籽投入、班次及水洗/干燥范围
- 低温或炒香目标、色泽和香气要求及炒制热源
- 沉降/过滤方法、沉淀目标、储罐、包装、取样和检测
- 电、热、水与废水、场地、目的地和交货条款

## FAT/SAT 与书面验收

记录芝麻身份、清理损失、含水状态、水洗和干燥条件、炒制与冷却曲线、装料、周期、油温、毛油、净滤油和饼粕。FAT/SAT 应按约定时间评价色泽、香气、焦糊味、澄清度或沉淀，并检查炒锅、压榨机和过滤器的清洁。低温与炒香路线分别签署。
