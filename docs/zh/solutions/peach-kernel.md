# 桃核仁油压榨方案

本方案针对从桃核硬壳中分离出的核仁。整桃核、碎硬壳和湿果渣需要配置破核、壳仁分离及干燥模块，不能按清洁核仁直接选型。

![桃核仁低温压榨工艺参考](/images/an-overview-of-the-cold-pressing-process-of-peach--4e146541fe.webp)

## 原料与产能口径

请确认核仁来源、品种、追溯、含水状态、残壳和食品、化妆品或工业用途，并剔除破损、霉变、变色或酸败核仁。提取设备不能替代原料安全评价和成品油检测；产能按净核仁而不是整桃核重量核算。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 进料状态 | 整桃核或已分离核仁，分别核算 |
| 压榨基准 | 清洁核仁、约定含水状态和破碎粒度 |
| 产品路线 | 低温液压试压；温和调质另做同批对照 |
| 成品目标 | 沉降/过滤后的水分、沉淀、色泽、气味和检测 |
| 供货边界 | 破核、壳仁分离、干燥、粉碎、压榨、过滤和包装 |

## 推荐前处理

1. 破开桃核并分离核仁和硬壳。
2. 筛理、分选并去除残壳和缺陷核仁。
3. 仅在实测需要时进行受控干燥或调质。
4. 临近压榨时均匀破碎。
5. 按来源和用途分批留样。

## 压榨路线与配置边界

清洁破碎核仁可从低温液压批次试料开始。温和加热路线应使用同批样品比较油品色泽、气味、过滤、出饼和净滤油。机型和处理量依据核仁装料记录确定，不按整桃核投入换算。

## 过滤与成品油目标

应定义沉降时间、过滤等级、可见水分和沉淀、色泽、气味以及目标用途所需的实验室检测。需要控制光照和氧接触时，把密闭储存与避光包装列入供货范围。

## 报价所需资料

- 整桃核或核仁样品、残壳、含水状态、杂质、来源、储存和安全资料
- 每批或每日净核仁投入、班次、季节性及破核/分离范围
- 目标用途、低温或温和调质路线及监测要求
- 过滤、储罐、包装、取样和检测范围
- 公用工程、场地、清洁标准、目的地和交货条款

## FAT/SAT 与书面验收

记录批准批次、整核到核仁的计量基准、残壳、含水状态、破碎粒度、装料、周期、油温、毛油、净滤油和饼粕，并保留约定样品或实验室报告。FAT 是否带料和样品责任应先写入合同；SAT 如实施，应核对清洗、产品残留、出饼和连续批次节拍。
