# 工业蓖麻油压榨方案

蓖麻籽和蓖麻饼粕需要专用的工业处理边界。本方案不是食用油生产线；压榨机、过滤器、工具、储罐和清洗设施应与食品生产隔离。

![蓖麻籽调质与压榨工艺参考](/images/hot-pressing-process-of-castor-seeds-png-89a6227aab.webp)

## 原料与安全边界

请注明整籽、部分脱壳籽或已制备物料，并提供含水状态、杂质、来源、储存情况和可用安全资料。蓖麻籽及压榨饼粕具有毒性风险；压榨不能完成脱毒，也不能据此把饼粕作为饲料使用。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 生产属性 | 独立工业线，不与食品油线混用 |
| 前处理 | 清理、控尘、脱壳/破碎及热湿调质 |
| 产品目标 | 毛蓖麻油或过滤工业油及下游处理要求 |
| 副产物边界 | 饼粕密闭收集、标识、储存和处置 |
| 选型依据 | 代表性样品、安全方案、批次/连续需求和试料记录 |

## 推荐前处理

1. 在受控工业区域接收和储存原料。
2. 筛除异物并控制粉尘。
3. 按试料结果确定脱壳、分级或破碎。
4. 根据目标毛油规格调节热量和水分。
5. 配置专用收油、饼粕容器和清洗工具。

## 工业压榨与配置边界

采用带防护进料、受控调质、封闭收油和明确出饼程序的专用工业路线。批次液压或连续机械压榨的选择，应在代表性试料、处理量、人员防护和下游处理范围明确后确定。

## 过滤与工业油目标

应明确毛油或过滤工业油、固形物、可见水分、取样点、储罐和密封材质，以及后续精炼或化工处理范围。饼粕密闭、标识储存、废弃物、通风和去污边界必须写入采购规格。

## 报价所需资料

- 代表性籽样、整籽或脱壳状态、含水状态、杂质、储存情况和安全资料
- 每批或每日投入、班次、进料方式及自动化要求
- 工业用途、毛油规格、调质与下游处理范围
- 过滤、储罐、管路、饼粕容器、控尘、通风和清洗要求
- 电、热源、隔离场地、目的地和交货条款

## FAT/SAT 与书面验收

加载试验前应核对区域隔离、防护、控尘、个人防护程序、专用工具和饼粕容器。带料记录包括含水状态、脱壳或破碎、调质条件、装料或进料速度、周期、油温、毛油、净滤油和饼粕，并记录泄漏、过滤、残渣处理和清洗。SAT 如包含现场运行，应按当地安全制度和合同文件执行，不得把压榨验收表述为脱毒验证。
