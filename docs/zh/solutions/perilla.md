# 苏子/紫苏籽油压榨方案

苏子油对不必要的加热、空气暴露和长时间停留较敏感。低温油与炒制风味油应作为两种产品路线，分别试料、记录和报价。

![苏子热调质路线参考](/images/an-overview-of-the-hot-pressing-process-of-perilla-a2e7edd577.webp)

![苏子低温路线参考](/images/an-overview-of-the-cold-pressing-process-of-perill-76371f15c4.webp)

## 原料与产能口径

请注明品种、产地、含水状态、杂质、储存时间、破损或霉变比例和用途。压榨段按清洁干籽核算，陈旧、酸败或混合药材残渣不能视为正常油料。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 产品路线 | 低温轻味油，或炒制/温和调质风味油 |
| 前处理 | 小籽清理、按需干燥、破碎和分路线调质 |
| 氧化控制 | 开放时间、油温、过滤与密闭储存 |
| 产能依据 | 净干籽、装料/周期或连续进料及净滤油 |
| 成品目标 | 沉降/过滤、色泽、香气、酸败气味和氧化检测 |

## 推荐前处理

1. 筛理和清洁小粒籽料。
2. 去除石块、金属、粉尘和受损籽。
3. 仅在含水状态需要时缓和干燥。
4. 形成一致破碎结构，减少开放存放。
5. 低温和炒制试料分别备料。

## 压榨路线与配置边界

目标为轻味和控制氧化时，可优先做低温液压批次试料。需要更强香气时，对同批另行炒制或温和调质。较大连续处理量应比较螺旋压榨，并沿用相同的色泽、香气、沉淀和饼粕验收标准。

## 过滤与成品油目标

设定沉降或过滤时间、可见沉淀、澄清度、色泽、香气、氧化检测方法及进入密闭储罐的时点。储罐和避光包装按约定的油品处理计划配置。

## 报价所需资料

- 籽样、品种、含水状态、杂质、破损比例、储存时间和氧化情况
- 每批或每日干籽投入、班次和运行节拍
- 低温或炒香产品目标及油温记录要求
- 沉降、过滤、储罐、包装、取样和氧化检测
- 电、热源、场地、储存条件、目的地和交货条款

## FAT/SAT 与书面验收

记录籽料含水状态、清理损失、破碎、炒制或调质条件、装料、周期、油温、毛油、净滤油、饼粕和开放暴露时间，并检查澄清度、色泽、香气、酸败气味、储罐封闭和清洗。FAT/SAT 应分别签署低温与炒制路线，不以视频或另一配方的结果替代。
