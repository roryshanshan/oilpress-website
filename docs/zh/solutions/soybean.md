# 大豆油加工方案

大豆商业提油通常需要清理、按需脱皮、破碎或轧片以及热湿调质。直接液压冷榨不是默认工业路线；处理量、油回收和豆粕目标应一起评估。

![大豆制备料液压试验参考](/images/process-image-bc91f2194d.webp)

![大豆热湿调质物料参考](/images/process-image-ce959e498e.webp)

## 原料与产能口径

请注明整豆或已制备豆仁、品种、含水状态、杂质、储存情况、现有油脂和蛋白资料，以及油和粕的用途。产能按清洁豆或明确的制备料基准报价。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 进料状态 | 整豆、脱皮豆仁或已轧片物料 |
| 前处理 | 清理、按需脱皮、破碎/轧片和热湿调质 |
| 提油路线 | 连续螺旋、预榨或专用提取；液压用于制备料试验 |
| 油品范围 | 过滤毛油，或含脱胶和精炼的成品油 |
| 粕目标 | 残油、蛋白、组织状态及后续用途是否验收 |

## 推荐前处理

1. 清理并去除石块、金属和异物。
2. 根据豆粕或工艺要求决定是否脱皮。
3. 破碎并轧片，或制成约定结构。
4. 调节热量和水分以配合提油及豆粕目标。
5. 稳定向压榨或提取段供料。

## 压榨或专用路线

商业处理量应比较连续螺旋压榨、预榨或专用提取路线。液压批次试料可了解制备大豆料的压实和过滤特性，但不能在缺少周期和物料衡算时外推为连续工厂产能。毛豆油按成品规格进入固形物去除、脱胶和精炼。

## 过滤、脱胶与成品油目标

应区分过滤毛油和精炼油，列出固形物、水分、脱胶、色泽、气味和实验室检测。豆粕或饼的目标也应明确，包括是否评价残油、蛋白、组织状态和后续饲料加工。

## 报价所需资料

- 整豆或脱皮豆仁样品、含水状态、杂质、油脂/蛋白资料和储存情况
- 每小时或每日清洁豆投入、班次、连续运行要求和豆粕用途
- 脱皮、轧片、调质、液压试料、螺旋、预榨或专用提取范围
- 毛油或精炼油、过滤、脱胶、精炼、储罐和包装范围
- 蒸汽或热源、电、输送、场地、目的地和交货条款

## FAT/SAT 与书面验收

记录清理和脱皮损失、片厚或破碎状态、调质后的含水和温度、进料或装料、毛油、净滤油和粕/饼，并标明油和粕的取样点。FAT/SAT 只对合同所含的输送、压榨、过滤、脱胶或精炼模块签署；粕残油与精炼效果按约定方法检测。
