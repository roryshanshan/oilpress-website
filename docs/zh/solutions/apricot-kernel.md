# 杏核仁油压榨方案

本方案针对从杏核硬壳中分离出的核仁。整杏核、碎硬壳和湿果渣需要增加破壳、壳仁分离及干燥模块，不能按清洁核仁直接选型；采购方还应明确油品用于食品、化妆品还是工业用途。

![杏核仁低温压榨工艺对照图](/images/an-overview-of-the-cold-pressing-process-of-almond-d7174b6360.webp)

## 原料与产能口径

需确认核仁来源、品种或商业名称、追溯资料、残壳比例、含水状态和储存情况，并剔除霉变、虫蛀、变色或酸败物料。压榨只是提取环节，不能替代原料安全评价、用途合规判断或成品油检测。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 进料状态 | 整杏核或已分离核仁，分别核算 |
| 压榨基准 | 清洁核仁重量，不以整核重量代替 |
| 工艺路线 | 低温液压试压；温和调质另做同批对照 |
| 成品目标 | 沉降或精滤后的色泽、气味、可见沉淀及检测项目 |
| 供货边界 | 破核、壳仁分离、粉碎、压榨、过滤、储存和包装 |

## 推荐前处理

1. 破开杏核并分离硬壳和核仁。
2. 筛理、清洁并分选核仁。
3. 按实测含水状态决定是否缓和干燥或调质。
4. 临近压榨时均匀破碎，减少氧化暴露。
5. 按来源和终端用途分别留样、试料和标识。

## 压榨路线与配置边界

清洁核仁可从低温液压批次试压开始。任何加温调质都应在同批样品上比较色泽、气味、过滤行为和出饼情况。机型与产能依据核仁装料密度、周期和净滤油记录确定，不能按整杏核投入直接换算。

## 过滤与成品油目标

采购规格应列明沉降时间、过滤等级、可见水分与沉淀、色泽、气味及目标市场要求的实验室项目。需要控制光照和空气暴露时，应同步确认密闭储罐和包装方式。

## 报价所需资料

- 原料是整杏核还是核仁，残壳、含水状态、杂质、来源和安全资料
- 每批或每日净核仁投入、季节性，以及破核和壳仁分离范围
- 终端用途、低温或温和调质路线及油温记录要求
- 过滤、储罐、包装、取样和实验室检测范围
- 电源、场地、卫生条件、目的地和交货条款

## FAT/SAT 与书面验收

FAT 文件应注明使用的核仁批次、整核到核仁的计量基准、残壳、含水状态、破碎粒度、装料量、周期、油温、毛油、净滤油和饼粕重量，并附双方约定的留样或检测结果。若 SAT 包含现场带料运行，还应按实际公用工程核对清洁、残留、出饼和连续批次节拍。设备运行合格不等于自动确认原料或油品适合某一法定用途。
