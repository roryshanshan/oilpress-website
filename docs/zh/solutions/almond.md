# 杏仁（杏仁油）压榨方案

杏仁油项目应按实际进入压榨段的脱壳杏仁核仁核算，而不是按带壳坚果、杏仁酱或混合食品边角料核算。核仁状态、目标风味和终端用途会改变清理、破碎、调质、过滤及包装配置。

![杏仁核仁低温压榨工艺参考](/images/an-overview-of-the-cold-pressing-process-of-almond-d7174b6360.webp)

## 原料与产能口径

请注明原料是带壳杏仁还是已脱壳核仁，并提供品种、产地、含水状态、储存时间、破损或异味比例及食用、化妆品或工业用途。霉变、虫蛀、焦糊和酸败核仁应在试料及产能核算前剔除；脱壳损失不得计入压榨段处理量。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 压榨进料 | 清洁杏仁核仁及约定的破碎粒度 |
| 产品路线 | 低温轻味油，或单独验证的烘烤风味油 |
| 产能依据 | 代表性样品的装料量、批次周期、清理时间和净滤油记录 |
| 成品定义 | 沉降油、精滤油或后续精炼用毛油 |
| 供货边界 | 脱壳、分选、粉碎、压榨、过滤、储罐和灌装逐项列明 |

## 推荐前处理

1. 脱壳并分离硬壳、石块和金属。
2. 分选受损核仁，检测代表性批次的含水状态。
3. 仅在试料显示需要时进行缓和干燥或调质。
4. 临近压榨时均匀破碎，减少长时间暴露。
5. 需要烘烤香气时，另设同批对照样，不与低温路线共用结果。

## 压榨路线与配置边界

高价值轻味杏仁油可先做液压批次低温试压；温和调质或烘烤路线应按另一成品规格比较色泽、气味、过滤负荷和饼粕状态。连续商业产量应同时评估螺旋压榨，不应把单批数据直接倍增为整线产能。

## 过滤与成品油目标

报价应写明沉降时间、过滤等级、可见水分与沉淀判定、色泽、气味、取样时点及所需实验室项目。若产品需要限制光照和氧接触，还应列入密闭储罐、管路排空和避光包装。

## 报价所需资料

- 原料照片和代表性样品，含核仁含水状态、杂质、受损比例及储存记录
- 每批或每日净核仁投入、工作班次，以及脱壳和分选是否在供货范围
- 低温或烘烤风味目标、用途及油温记录要求
- 沉降、过滤、储罐、灌装和检测范围
- 电源、场地、清洁要求、交货地点和贸易条款

## FAT/SAT 与书面验收

合同应写明 FAT 是否包含带料试压、样料责任、称量方法、过滤终点和留样；未约定带料 FAT 时，空载或功能检查不能替代工艺验收。带料记录至少包括进料与净核仁重量、含水状态、破碎粒度、装料量、周期、油温、毛油、净滤油和饼粕重量。SAT 如在现场实施，还应核对公用工程、安装、清洗、产品残留和连续批次节拍，并由双方签署记录。
