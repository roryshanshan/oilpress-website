# 茶籽/油茶籽油压榨方案

茶籽或油茶籽应明确物种或商业名称、采收年份、整籽或籽仁基准和储存情况。壳比例、陈籽和霉变核仁会改变压榨、风味、过滤和设备选型的可用进料。

![茶籽清理、破碎与压榨工艺参考](/images/process-image-0901d2dd53.webp)

## 原料与产能口径

请注明整籽或籽仁、物种/商业名称、产地、含水状态、壳比例、杂质、采收和储存记录及用途，并剔除霉变、虫蛀、变黑或酸败籽。产能按清洁整籽或清洁籽仁分别核算。

## 采购参数表

| 采购参数 | 需书面确认的口径 |
| --- | --- |
| 原料身份 | 物种/商品名、采收年份、整籽或籽仁 |
| 前处理 | 干燥/调质、按需脱壳、分选和破碎 |
| 产品路线 | 低温或温和调质路线，分别试料 |
| 后处理 | 沉降、过滤、按成品需要脱蜡或轻度精炼 |
| 产能依据 | 进料基准、壳仁损失、装料/周期或连续记录 |

## 推荐前处理

1. 将整籽干燥或调质到稳定状态。
2. 产品需要籽仁压榨时脱壳并分离。
3. 分选和清理籽仁。
4. 形成可重复的破碎粒度。
5. 低温与温和调质批次分开。

## 压榨路线与配置边界

可先对清洁破碎籽仁或明确定义的整籽做液压批次试料。用同批物料比较低温与温和调质路线，记录色泽、香气、过滤、饼粕和周期。更高连续处理量应比较螺旋压榨；成品澄清度有要求时，后处理可包含脱蜡或轻度精炼。

## 过滤、脱蜡与成品油目标

应明确沉降油、过滤油、脱蜡油或轻度精炼油，以及可见沉淀、色泽、香气、蜡析出和约定冷却/储存条件下的澄清度。取样点、储罐材质和包装要求写入采购规格。

## 报价所需资料

- 整籽或籽仁样品、物种/商品名、壳比例、含水状态、杂质、采收年份和储存情况
- 每批或每日投入基准、班次、季节及干燥/脱壳范围
- 低温或温和调质产品目标及用途
- 沉降、过滤、脱蜡/精炼、储罐、包装、取样和检测
- 热源、电、场地、目的地和交货条款

## FAT/SAT 与书面验收

记录籽料身份、壳仁分离和仁损失、籽仁含水状态、破碎粒度、调质条件、装料、周期、油温、毛油、净滤油和饼粕。合同包含过滤或脱蜡时，应按约定冷却试验记录色泽、香气、沉淀和澄清度，并检查出饼、产品残留和清洗。FAT/SAT 应区分整籽与籽仁路线。
