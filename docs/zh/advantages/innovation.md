# 技术设计与验证

## 可配置的技术特征

功能会随型号和订单变化。每项功能应在分项报价、电气与液压图、控制说明、物料清单和工厂验收测试中确认。

### 控制系统

- 可配置 PLC 和触摸屏，用于自动顺序、状态显示、报警和运行记录。
- 应核对控制器与触摸屏型号、I/O 清单、传感器类型、报警清单、用户权限、语言、配方管理、数据保留和备份方式。
- 在工厂验收时验证每个自动动作、联锁、急停、报警和手动后备操作。

### 压力控制

- 可通过多段压力配方控制不同物料的接近、压榨、保压和回程步骤。
- 如果方案标注 0.1 MPa 等压力分辨率或控制精度，应索取传感器量程、仪器精度、校准证书、控制允许偏差、采样频率和验收方法。显示分辨率不等于闭环控制精度。
- 应在所购设备上确认可用压力范围、溢流设定、保压稳定性、泄漏判据和记录的压力曲线。
- 采用某一配方前，应通过有代表性的重复试料比较油脂回收、饼残油、周期、温度和质量。

### 能源与环保条件

- 变频器、分级泵、加热器、保温和自动待机属于可选配置，实际效果取决于工况周期。
- 比较配置时，应在相同物料、产出、周期边界和运行时段内测量电能及热能。没有基准数据和明确测量方法时，不使用固定节能比例。
- 营养保留、排放、废水、噪声、食品接触状态和环保合规需要相应取样、实验室测试、现场控制及适用监管文件。“零污染”等表述不能替代这些记录。

## 应索取的工程记录

- 受版本控制的图纸、适用的计算资料、物料清单、软件或配方版本及变更历史
- 技术规格要求的材料和零部件证书
- 仪器校准记录及工厂测试数据
- 样品试料方案、原始数据、实验室报告、偏差和复测结果
- 操作说明书、维护计划、备件清单、电气备份和液压图

## 研发与知识产权表述

年度研发投入比例、团队经验年限、实验基地或项目数量，只有在明确统计周期、计算口径和可审计记录时才可引用；本页不将这些数字作为设备性能证据。

如引用专利或软件著作权，应索取登记号、名称、权利人、法域、法律状态、到期日，并说明所购功能与该权利的对应关系。应在相关官方数据库核验，不依赖专利总数等汇总表述。

## 验收重点

采购决策应基于所购配置、见证测试、可追溯测量、完整文件和书面验收标准。任何出油、能耗、人工、质量或开机率改善，都应在采购方物料和运行条件下验证前视为测试目标。
