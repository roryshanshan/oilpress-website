# 液压榨油机工厂核验

山东盛世赫程机械有限公司展示液压榨油机及食用油生产线设备供采购询价。选择供应商前，应针对具体订单核验签约主体、制造范围、设备配置、工厂测试能力、随机文件和售后条款。

## 应确认的制造范围

- 机架制作、机加工、焊接、液压装配、电气装配、表面处理、总装、测试和出口包装
- 报价所列液压压榨机、油料前处理、过滤、精炼或脱蜡、灌装及其他产线设备
- 自制设备、外购部件和外协工序的边界
- 接触物料材质、电机与电气品牌、控制、安全装置、公用工程及目的地电压
- 图纸确认、物料清单、检验计划、工厂验收、说明书、备件和包装文件

## 工厂参观检查清单

- 核对公司名称、营业执照、工厂地址、签约主体、收款主体和出口主体。
- 抽选在制设备，从图纸和物料清单追溯至装配、测试、铭牌及包装。
- 检查机加工、焊接、液压与电气装配、防护、测试仪器、校准状态和不合格处理记录。
- 如果交期或制造能力会影响采购，应查看当前排产和脱敏后的发运记录。
- 对约定证据拍照，并记录未决项、整改、复测要求和责任人。

## 文件与证书核对

如引用 ISO、CE、专利、高新资质、食品接触合规、奖项或其他资格，应索取当前有效副本，核对持有人、编号、颁发机构、适用范围、覆盖场所或产品及有效期，并尽可能向颁发机构或官方数据库核验。网页标志或清单不能替代证据文件。

## 样品试料与工厂验收

使用有代表性的原料样品，并书面约定前处理、单批装料、压力程序、周期、测量、重复测试和验收标准。工厂验收计划应覆盖配置、液压压力与泄漏、控制、联锁、急停、防护、随机附件、试料结果、文件和包装。

## 获取出口项目报价

请提供原料、样品情况、目标产品、计划工时、目的地电压与频率、所需产线范围、现场公用工程、包装方式、目的港、贸易术语及所需证书或检验。报价中应明确假设、除外项、交期、验收、质保、备件及合同范围内的持续技术支持。
