# 证书、资质与文件核验

本页不把资质、奖项、专利数量或标志视为设备质量证据。应索取适用于本订单签约主体、工厂、型号、工艺和目的地的文件。

## 公司与工厂文件

- 营业执照和登记经营范围
- 工厂地址及其与签约主体的关系
- 供应商作为出口方时的出口或海关登记信息
- 与签署合同一致的收款主体和开票主体

## 管理体系证书

如引用 ISO 9001、ISO 14001 或其他管理体系证书，应核对：

- 证书编号、持有人、场所地址、颁发机构和认可信息
- 活动范围及是否包含制造
- 签发、到期、暂停和撤销状态
- 通过颁发机构或认可数据库进行核验

管理体系证书不代表某一台设备的性能或合规状态。

## CE 与目的地合规

设备拟进入欧洲经济区时，应索取适用的欧盟符合性声明，核对制造商、设备型号、适用指令或法规、协调标准、授权签字人、日期、铭牌、说明书和所需技术文件，并明确符合性评估和目的地语言文件由哪一方负责。

其他目的地应在生产前确认电气、压力、食品接触、安全、标签、检验和进口文件要求。

## 专利、奖项与资格

- 专利或软件权利应核对登记号、权利人、法域、法律状态、到期日及其与所购功能的关系。
- 高新、专精特新、行业、纳税、社会责任或其他资格，应索取证书、颁发机构、评定条件、适用范围和有效期。
- 奖项应索取名称、主办方、规则、日期、获奖主体和可核验公告或证书。

这些文件只能证明其明确覆盖的事项，不能替代样品试料、工厂验机或工厂验收测试。

## 订单质量记录

- 已批准图纸和物料清单
- 技术规格要求的材料与零部件证明
- 适用的焊接、热处理、校准、压力、电气和安全测试记录
- 试料报告、工厂验收报告、说明书、备件清单和装箱单
