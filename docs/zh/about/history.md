# 供应商记录与采购核验

成立年限、生产能力、出口覆盖和技术领先等表述，只有在有当前可核验记录时才可用于采购判断。采购方可按以下证据路径核对供应商和所购设备。

## 法律主体记录

- 当前营业执照和注册公司名称
- 统一社会信用代码、注册地址、法定代表人和经营范围
- 签约主体、开票主体、收款主体和出口主体
- 工厂地址，以及工厂经营方与签约公司的关系

可用时应通过官方登记系统或独立企业查询核验，不能仅从营销文案推定成立年份或经营历史。

## 产品与工程版本记录

- 型号命名记录和受版本控制的总图
- 液压图与电气图版本
- 物料清单变更、零部件替代及软件或配方版本
- 测试流程、校准记录、不合格报告和整改措施
- 将交付设备与记录关联的序列号或订单标识

## 制造与交付证据

- 当前排产和脱敏订单状态记录
- 在允许披露时查看带日期的工厂测试报告、装箱单、商业发票和发运文件
- 能显示设备铭牌、测试仪器、测试流程、包装和装柜的照片或未剪辑视频
- 含日期、型号和验收结果的采购方或第三方验货报告

只有在底层记录和公开授权齐备时，才可表述出口目的地、发运数量或市场覆盖。

## 采购节点

1. 确认法律与商务主体。
2. 确认型号、范围、图纸、公用工程和目的地要求。
3. 进行代表性样品试料并约定验收标准。
4. 审核生产和文件节点。
5. 见证工厂验收并关闭整改项。
6. 确认包装、发运文件、备件、质保和支持范围。
